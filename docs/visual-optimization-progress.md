### 3. 伤害数字分级 ✅

**状态**: 已完成  
**实现时间**: 2026-05-06

**修改内容**:
- 文件: `src/scenes/GameScene.ts` (第3004-3048行)
- 增强现有route-specific命中特效系统

**实现方案**:
游戏已有命中特效系统（routeHitFlash），直接增强视觉效果实现分级：

**暴击 (Crit)**:
- 颜色: 红色 (#ff4444) + 亮橙 (#ffaa55)
- 效果: 三层爆炸环 + 核心闪光
- 特点: 最强视觉冲击，多层扩散环营造爆炸感

**穿透 (Pierce)**:
- 颜色: 青色 (#00d4ff) + 亮青 (#88f0ff)
- 效果: 十字穿刺线 + 中心亮点
- 特点: 强调贯穿感，双层十字交叉

**Dash**:
- 颜色: 橙色 (#ff8844) + 亮橙 (#ffbb66)
- 效果: 多层冲击波 + 四向粒子
- 特点: 动态扩散，方向性强

**技术细节**:
- 持续时间: 0.18秒 (enemy.routeHitFlashSec)
- 透明度: 基于flashRatio动态计算
- 性能: 纯Graphics API绘制，无额外粒子开销
- 触发: 由RunEngine在伤害计算时设置routeHitKind

**效果**:
- 三种伤害类型有明显的视觉区分
- 暴击红色爆炸最醒目
- 穿透青色十字强调贯穿
- Dash橙色冲击波体现动态感

## 🎯 设计原则

1. **信息清晰 > 视觉华丽**: 所有特效不应干扰玩家判断
2. **渐进式反馈**: 重要事件有明显反馈，次要事件保持克制
3. **性能优先**: 所有特效必须在60fps下流畅运行
4. **一致性**: 相同类型的事件使用相同的视觉语言

# START HERE

## 这是什么项目

这是一个基于 Phaser + TypeScript + Vite 的 Web 端短局节点推进自动射击原型。

仓库名虽然叫 `unity-learning`，但当前重建版本不是 Unity 项目。后续所有实现、文档和接手判断，都必须以仓库真实技术栈和代码现状为准。

## 一句话目标

验证“手动走位 + 自动攻击 + 战斗内升级 + 轻量节点推进”能否在 `8~12` 分钟内支撑三条清晰、可复玩的流派路线。

## 当前阶段

- 当前阶段：`1.0 第一阶段`
- 当前轮次口径：`第 8 轮候选签收复检`
- 当前主线：压缩前段到中段的路线承接噪音，让路线更早露头、更稳站住，但不提前锁死
- 当前主要残余风险：`屏卫主核` 的后段火线阶段在普通构筑样本里覆盖率偏低

## 只需要记住的五件事

- 这是原型项目，不是完整商业版本。
- 目标不是堆系统，而是验证单局体验是否清楚、能否成型、能否让人想重开。
- 三条主路线必须都能在真实整局里成立：暴击、穿透、穿梭。
- 路线设计不是开局立刻锁死，而是“前段给方向，中段站稳，后段兑现”。
- 任何开发都要先说明本轮要验证什么，再改代码，再留下复盘文档。

## 接手后第一步

- 不要先改代码。
- 先确认本轮只要解决哪一个问题。
- 如果这个问题已经能在当前文档里定位，再进入实现。
- 如果当前文档还不能支撑实现，先补文档再改代码。

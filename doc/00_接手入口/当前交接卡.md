## 当前项目是什么
- 一个基于 `Vite + TypeScript + Phaser` 的俯视角轻量化 Roguelite 飞行射击原型。
- 玩家在节点地图中选择路线，进入战斗，拾取 XP，获得升级，并通过 `crit / pierce / dash` 三条路线形成不同战斗倾向。
- 当前版本继续坚持“程序化表现优先”：先把读局、手感、反馈和节奏做扎实，不急着替换大规模正式美术和音频资产。

## 当前最需要解决的问题
- 操控手感：起步、转向、停手和拾取已经顺了一拍，但自然样本仍容易在第 2~3 节点被打断，后续需要继续看普通玩家是否能稳定进入中后段。
- 打击手感：命中、击杀、拾取的连续回报链已更清楚，但自然样本里升级/节点打断频繁，仍需观察是否影响“继续开火”的节奏感。
- 音效反馈：基础战斗链与危险链已重新分层，后续重点是实机听感复检，确认 `kill` 不盖过 `hurt / pressure`。
- 音效多样性：流派特殊 buff 的伤害声纹已经开始拆分，后续还要继续复检自然样本，确认三条路线都能稳定听出自己的性格。
- 提示和文字：已清掉当前已知玩家可见乱码，后续新增 toast、节点、升级、结算文案时仍必须跑乱码扫描。
- 页面统一性：开始页、局内 HUD、节点/升级页、结算页已经可用，但仍需要减少“测试版”感和信息噪声。

## 下一轮建议
优先做一轮“全链路游玩体验补强”，而不是继续扩路线内容池。

建议开发顺序：
1. 先清理玩家可见乱码和过度技术化提示。
2. 再小步调移动、拾取、射击、命中、击杀反馈。
3. 然后补音效层级，并单独拆出流派特殊 buff 的伤害声纹。
4. 最后补完暂停、音量、结果页的体验收口，并用 full-flow 与自然战斗样本验证，确认没有破坏精英、Boss、三路线差异。

## 2026-04-28 体验问题修复与 Boss/精英小步补强

本轮针对实机可见问题做了收口：运行时接入的玩家、普通敌、XP 球 SVG 预览素材已去掉黑色底板，保持透明背景叠在程序化战场上；玩家子弹与敌方子弹拖尾改为更短、更细、更低透明度的线段，减少“长线段乱飞”的视觉噪声。

UI 层修复了两个阻塞问题：开始页音量面板通过显式层级保证在开始页之上，滑杆和关闭按钮可以正常响应；局内暂停后点击“继续作战”会立即清理暂停面板，不再出现游戏继续但暂停窗口残留的状态。

数值展示规则同步调整：强化卡牌和局内摘要不再展示 `+0.51x` 这类小数倍率。暴击伤害加成统一显示为百分比，例如 `暴击伤害 +51%`；最终暴伤摘要显示为总倍率百分比，例如 `暴伤 216%`。底层公式仍为 `暴击伤害 = 子弹基础伤害 × 暴击伤害倍率`，期望伤害约为 `基础伤害 × (1 + 暴击率 × (暴击伤害倍率 - 1))`。

Boss/精英体验做了小步机制化修正：Boss 弹幕墙数量和远程齐射频率下调，安全窗尺寸与停留时间上调，避免玩家被过密弹幕压到无法移动；精英和 Boss 在压力阶段切换时获得短暂横移/机动提升，并通过既有的 `frontline / screened / kiting / summoner` 行为切换强化“会拉扯、会护线、会转段”的感觉，不再只依赖血量变厚。

下一步建议优先做一次自然样本复检：重点看 Boss 终盘是否从“不可躲”回到“高压但可读”，以及精英战是否因为机动提升导致近战压迫过强。如弹幕回落后难度过低，再优先补 Boss 阶段提示和精英技能节奏，而不是直接把弹幕密度加回去。

- `dash` 的路线听感和持续视觉签名仍弱于 `crit / pierce`，后续路线专项可优先补。
- `屏卫主核` 的后段火线阶段仍是 Boss 监控项，避免在战斗打磨中被带坏。

- 本轮按照 `doc/40_AI协作/战斗手感与音效优化对接文档.md` 做了真实落地。

## 当前仍保留的风险

- `pierceFlow` 仍是程序化临时表现，不是正式资产签收态。
- `dash` 的路线听感和持续视觉签名仍需要后续专项补强。
- 精英 / Boss 的正式记忆点仍依赖后续资产和更稳定的自然样本验收。
- 自然路线样本仍可能受路线抽取和长局路径影响，后续需要更稳定的定向 route smoke。
- `屏卫主核` 火线阶段仍要持续监控，不要因为局部手感优化导致 Boss 收尾变薄。

## 下一步建议优先级

1. 继续用自然 full-flow 验证 `pierceFlow` 是否稳定可感但不过强。
2. 为 `dash` 补一轮更明确的“换位 -> 反打”视觉和音频签名。
3. 继续复检精英裂口是否稳定读成“拆屏 -> 追本体”。
4. 继续监控 `屏卫主核` 的火线阶段覆盖率。
5. 每轮开发后新增复盘，并同步更新本文件。

## 当前不应该做

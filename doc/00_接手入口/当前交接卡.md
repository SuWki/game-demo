## 当前主要待办

主问题已经从「路线单点补强」转到「整局体验顺不顺、清不清楚、想不想再开一局」。重点关注：

- 普通战「击杀 → 掉落 → 吸附 → 升级 → 继续追击」回报链顺不顺
- 移动、开火、命中、击杀、拾取是不是连成一气的身体感
- `shoot / hit / kill / pickup / hurt / nearMiss / pressure / enemyShot` 八个音效在混战里能不能分开
- `crit / pierce / dash` 三条路线是不是真的靠多张牌搭出来，而不是一张高价值牌就杀穿
- 精英战和 Boss 战是不是考验不同路线的解法，而不只是血更厚
- 背景、路线特效、Boss 安全区、敌弹、XP 球是不是同时能看清，不互相抢
- 镜头、全屏闪、边框脉冲会不会让人晕
- 玩家可见文字不能有乱码、英文占位或过度技术化

### 还需要玩起来确认的

- 路线成型验收：三路线是不是真的靠多张牌组合，而不是单张高价值牌就成路线
- 关卡和敌人职责：普通战、精英战、生存战、Boss 战要给玩家不同任务，不能都只是清怪
- 操控和舒适度：移动、拾取、镜头、背景、全屏反馈要先过人工体感
- 表现层画面：路线特效、Boss 安全区、敌弹、XP 球、背景贴片不能混成视觉噪音
- 求职作品素材：要能展示「问题 → 设计假设 → 改法 → 验证数据/截图 → 复盘」的链路

## 下一轮建议

等用户实机反馈当前最新版本。不要让 Kimi 继续改代码，也不要继续做作品集，先确认三件事在真实游玩里是不是成立：

1. 流派成型（拿到几张牌才算一条路线，而不是一张就杀穿）
2. 敌人出题（Boss 和精英是不是考验不同路线的解法）
3. 表现干净（画面没有无意义线条和文字干扰）

建议顺序：

1. 用户先人工实机 3 局（`crit / pierce / dash` 各一局），记录每局路线牌数量、成型时机、精英/Boss 是否被快速秒杀、画面是否干净
2. 如果路线仍然 1 到 2 张牌就杀穿，先拆解路线收益来源，再给定向骨架改 `upgrades.ts / contentSelectors.ts / RunEngine.ts`
3. 如果 Boss 和精英仍像木桩，先拆解出题缺口，再给 `battleTemplates.ts / RunEngine.ts` 的护卫职责、阶段窗口、弱点和安全窗骨架
4. 如果表现仍乱，先拆解哪些文字、线条、遮罩该删，再给 `GameScene.ts / PilotAudio.ts / OverlayController.ts` 的表现收口骨架
5. 素材和音效接入继续服务读局，只接入能增强敌我识别、路线命中和危险反馈的素材，不为了好看增加遮挡
6. 作品集截图和视频整理继续后置

## 当前正在解决的问题

- 普通战的“击杀 -> 掉落 -> 吸附 -> 升级”回报链和家族人格已经基本站稳，但仍要防回退
- 当前主问题已经收窄成：精英战要更稳定读成“护卫成屏 -> 裂口 -> 追击本体”的解题型高压层
- `crit / pierce` 在精英窗口里的 live mini-high 还要继续验证自然样本里的稳定度
- 首领收尾里，`屏卫主核` 的后段火线阶段仍保留为持续监控项，避免在战斗打磨中被带坏

## 这轮已经确认的结论

- 战场整体已经比之前更像游戏现场，而不是静态网页叠层
- 路线场地特效、子弹拖迹、敌人受击火花和玩家动作辉光已经能稳定抬高即时读感
- 经验掉落现在更适合继续往“击杀兑现 + 吸附回收 + 追下一只”这条回报链上打磨
- 当前主问题已经从“主循环能不能成立”转成“核心战斗是不是足够爽、足够愿意再打一局”

## 当前不应该做的事

- 不要重写 `RunEngine`
- 不要把项目重新改成复杂大地图
- 不要在没有明确理由时扩新系统
- 不要为了追求爽感去堆纯数值或堆满屏特效
- 不要忽略文档同步，只改代码

## 下一步建议优先级

1. 继续验证精英战里的护卫联动、裂口窗口和自然样本可读性

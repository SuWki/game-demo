# 当前交接卡

## 更新时间

- `2026-04-14`

## 当前版本状态

- 当前项目状态：可运行、可继续开发、可验证
- 当前主阶段：`1.0 第一阶段`
- 当前工作性质：核心循环与核心战斗打磨轮，不是地图扩写轮，不是重构轮

## 当前正在解决的问题

- 普通战已经能打，但“击杀 -> 掉落 -> 吸附 -> 升级”的回报链还需要继续压实
- 战斗爽感当前更依赖命中反馈，击杀兑现和拾取追击欲仍要继续补强
- 首领收尾里，`屏卫主核` 的后段火线阶段仍保留为持续监控项，避免在战斗打磨中被带坏

## 这轮已经确认的结论

- 战场整体已经比之前更像游戏现场，而不是静态网页叠层
- 路线场地特效、子弹拖迹、敌人受击火花和玩家动作辉光已经能稳定抬高即时读感
- 经验掉落现在更适合继续往“击杀兑现 + 吸附回收 + 追下一只”这条回报链上打磨
- 当前主问题已经从“主循环能不能成立”转成“核心战斗是不是足够爽、足够愿意再打一局”

## 当前不应该做的事

- 不要重写 `RunEngine`
- 不要把项目重新改成复杂大地图
- 不要在没有明确理由时扩新系统
- 不要为了追求爽感去堆纯数值或堆满屏特效
- 不要忽略文档同步，只改代码

## 下一步建议优先级

1. 继续压实“击杀 -> 掉落 -> 拾取 -> 升级”的战斗回报链
2. 继续让普通战家族在不加新系统的前提下更有爽感和区分度
3. 顺手复检 `屏卫主核` 火线监控项和路线连续性，避免回退
4. 每次开发后新增复盘，并同步更新本文件

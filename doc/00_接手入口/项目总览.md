# 项目总览

## 项目定位

一个短局、节点推进、自动射击的网页原型。玩家在一局里通过走位、击杀、拾取经验、三选一升级和节点选择，慢慢把一条流派路线搭起来，最后在 Boss 战里验证这套路线成不成。

## 当前产品目标

- 前 30 秒让玩家明白怎么玩
- 前 2 分钟让玩家感觉到自己在往某条路线走
- 中段让玩家明显感到路线成型
- 后段给出收尾感和 Boss 战压力变化
- 结算后让玩家有马上再开一局的冲动

## 核心循环

开始页 → 进入一局 → 战斗 / 整备 / 异常节点推进 → 击杀掉经验 → 拾取经验 → 升级三选一 → 路线慢慢成型 → 最终整备 → Boss 战 → 结算 → 重开

## 三条主路线

- 暴击路线（`crit`）：升温、爆发、连续命中后集中输出
- 穿透路线（`pierce`）：拆线、贯穿、清线和扩面
- 穿梭路线（`dash`）：换位、擦身、蓄能反击和节奏循环

## 设计边界

- 不做复杂大地图
- 不把原型做成长线数值手游
- 不让路线在前段直接锁死
- 不把异常节点退化成普通补给事件
- 不把 Boss 战做成只是血更厚的普通战

- `Boss-bastion` 的后段火线阶段需要持续监控，不能在战斗打磨中被带薄。火线职责已经在 2026-07 拆到 [PressureWindowController.ts](file:///d:/codex/codex/auto-shooter-demo/src/systems/battle/PressureWindowController.ts)，但仍需实机验证
- `dash` 的路线听感和视觉特征仍弱于 `crit / pierce`。Dash 时刻埋点已经在 2026-07 拆到 [DashMomentMonitor.ts](file:///d:/codex/codex/auto-shooter-demo/src/systems/battle/DashMomentMonitor.ts)，但路线成型仍需人工实机
- `pierce` 的蓝色裂纹在混战里能不能看清，仍是人工实机的重点

# 项目总览

## 项目定位

这是一个短局、节点推进、自动射击的玩法原型。玩家在一局中通过移动走位、击杀敌人、拾取经验、进行三选一升级和节点选择，逐步把一条流派路线扶到站稳，并在首领战完成收尾。

## 当前产品目标

- 前 `30` 秒让玩家明白怎么玩
- 前 `2` 分钟让玩家感到自己在往某条路线走
- 中段让玩家明显感受到路线开始站稳
- 后段给出收尾感和首领战压力变化
- 结算后让玩家有马上再开一局的动机

## 核心循环

开始页 -> 进入一局 -> 战斗 / 整备 / 异常节点推进 -> 战斗内击杀掉经验 -> 拾取经验 -> 升级三选一 -> 路线逐步站稳 -> 最终整备 -> 首领战 -> 结算 -> 重开

## 三条主路线

- 暴击路线
  关键词是升温、爆发、连续命中后的集中兑现。
- 穿透路线
  关键词是拆线、贯穿、清线和扩面。
- 穿梭路线
  关键词是换位、擦身、蓄能反打和节奏循环。

## 设计边界

- 不做复杂大地图。
- 不把原型做成长线数值手游。
- 不让路线在前段普遍直接锁死。
- 不把异常节点退化成普通补给事件。
- 不把首领战做成只是更厚血的普通战。

## 当前实现方式

- 运行时：Phaser
- 语言：TypeScript
- 构建：Vite
- 单局推进：`RunEngine`
- 表现与面板：`OverlayController`
- 场景：`MainMenuScene / GameScene / ResultScene`
- 数据层：`src/data/*`
- 埋点：`MetricsTracker`

## 当前阶段判断

- `0.9` 阶段已经达到可测试版状态。
- 当前处于 `1.0 第一阶段` 的体验收口阶段。
- 当前工作的重点不是重写系统，而是继续提高核心战斗手感、即时回报链、路线实战签名和收尾质量。

## 当前最大风险

- `屏卫主核` 的后段火线阶段仍是持续监控项，不能在战斗打磨中被带薄。
- `dash` 的路线听感和持续视觉签名仍弱于 `crit / pierce`，后续路线专项需要继续补强。
- `pierceFlow` 已经提升穿透路线体感，但仍是程序化临时表现，需要继续看自然样本是否稳定可感但不过强。

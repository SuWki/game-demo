# 技术架构总览

## 技术栈

- 前端运行：Phaser 3
- 语言：TypeScript
- 构建工具：Vite
- 数据存储：浏览器 `localStorage`

## 代码分层

### 1. 入口层

- `src/main.ts`
  负责创建 Phaser 实例、注册场景、初始化服务对象。

### 2. 场景层

- `src/scenes/MainMenuScene.ts`
  开始页、开始按钮、埋点导入口。
- `src/scenes/GameScene.ts`
  主运行场景，负责输入、渲染、同步界面和驱动单局更新。
  历史上是 5300+ 行的 God Class，2026-07 重构后已将以下职责外移：
  - **粒子/特效** → `src/scenes/ParticleDirector.ts`（175 行）：暴击闪光环、命中火花、暴击爆发、穿透波纹、Dash 拖尾。GameScene 保留薄委托方法。
  - **HUD 快照构建** → `src/scenes/HudComposer.ts`（413 行）：`createHudSnapshot`、`getBattleStatusText`、`getObjectiveSnapshot`、`getEliteObjectiveSnapshot`、`getRouteStatusText`、`getRunProgressSnapshot`、`getPanelProgressSnapshot` 等 11 个方法。
  - **渲染辅助纯函数** → `src/scenes/renderHelpers.ts`：颜色混合、坐标转换、摄像机判定、地形噪声、面板属性摘要。
- `src/scenes/ResultScene.ts`
  结算页和重开逻辑。

### 3. 系统层

- `src/systems/RunEngine.ts`
  单局状态机和主循环，负责节点推进、战斗状态、升级、异常、路线状态和结算。
  历史上是 9600+ 行的 God Class，2026-07 重构后已降至 8700 行，并将以下职责外移：
  - **SafeZone 状态机** → `src/systems/battle/SafeZoneController.ts`（388 行）：覆盖攻击安全区生命周期、敌人位移、覆盖攻击伤害结算。通过 `SafeZoneHost` 接口回访 RunEngine 共享方法。
  - **压力窗口控制器** → `src/systems/battle/PressureWindowController.ts`（845 行）：压力阶段状态机、压力签名/模式脉冲、Boss 安全区几何与宽限期、Boss 火线监控、压力弹幕（墙壁射击 / 口袋射击）生成。通过 `PressureWindowHost` 接口回访 RunEngine 共享方法。
  - **Dash 时刻监控器** → `src/systems/battle/DashMomentMonitor.ts`（91 行）：记录 5 类战斗"时刻"（late dash window / dash counter / elite crack follow-through / kill-pickup continue）+ 冷却推进。通过 `DashMomentHost` 接口读取 `RunState.phase`。
  RunEngine 仍保留：敌人 AI、Elite 脉冲、QA Smoke、路线叙事文本生成、节点/升级/异常推进等职责，后续可继续拆分。
- `src/systems/ConfigLoader.ts`
  配置加载器。2026-07 重构后**改为静态 TS 导入**：`src/data/*.ts` 是唯一事实源，运行时不再 fetch `public/data/*.json`。`public/data/*.json` 仅作为 Excel 工作流的导出产物存在。
  暴露 `getBattleTemplate(id)` / `getEnemyArchetype(id)` / `getUpgrade(id)` 三个按 ID 查找方法，找不到时 fail-fast。
- `src/systems/MetricsTracker.ts`
  本地埋点收集、导出和局内摘要。
- `src/systems/PilotAudio.ts`
  最低限度程序音频系统。
- `src/systems/MetaProgression.ts`
  记录累计局数、胜场和最近路线。

#### 3.1 子系统目录

- `src/systems/spawn/` - 敌人生成子系统
  - `PressureCurve.ts` - 敌人 HP/速度/间隔/数量上限计算
  - `EnemySpawner.ts` - 敌人生成、archetype 选择、位置计算
  - `SpawnPatternEngine.ts` - 压力模式生成逻辑（安全区/墙壁射击/口袋射击）
- `src/systems/combat/` - 战斗子系统
  - `DamageCalculator.ts` - 伤害计算纯函数包装
  - `BulletSystem.ts` - 子弹移动和生命周期管理
  - `CombatResolver.ts` - 子弹命中判定、暴击判定、伤害计算
  - `DashSystem.ts` - Dash 触发逻辑、脉冲伤害、敌人标记
- `src/systems/route/` - 路线子系统
  - `CritRoutePassive.ts` - Crit 路线被动逻辑（破绽累积/终结打击/爆发连锁）。2026-07 P1-2 后，`applyCritPassiveOnHit` 是暴击命中被动的唯一入口
  - `PierceRoutePassive.ts` - Pierce 路线被动逻辑（穿透印记/连锁累积/裂纹扩散）
  - `DashRoutePassive.ts` - Dash 路线被动逻辑（幽灵打击/动量累积/反击窗口）
  - `RouteManager.ts` - 路线管理统一入口
  - `RouteProgression.ts` - 路线阶段推进、叙事文本生成
- `src/systems/progression/` - 成长子系统
  - `KillStreakSystem.ts` - 连杀/拾取流/击杀流/穿透流计算
  - `ExperienceSystem.ts` - 经验球拾取、磁铁吸引、升级触发
  - `UpgradeEngine.ts` - 升级应用逻辑
- `src/systems/ai/` - AI 子系统
  - `EnemyAI.ts` - 敌人 AI 行为、投射物更新、碰撞检测
  - `EliteBehavior.ts` - 精英敌人行为、压力脉冲、护卫同步
  - `BossBehavior.ts` - Boss 火战线监控、安全区惩罚
- `src/systems/state/` - 状态工厂
  - `BattleStateFactory.ts` - BattleState 初始化
  - `RunStateFactory.ts` - RunState 初始化
- `src/systems/battle/` - 战斗纯函数与控制器模块
  - `pressureSafeWindowMath.ts` - 压力安全窗口几何计算（视口边界、安全区中心选择、槽位收集、区内判定）
  - `SafeZoneController.ts` - **2026-07 新增**。覆盖攻击安全区状态机（warning → active → transition → 下一轮）。通过 `SafeZoneHost` 接口委托回 RunEngine 访问共享方法（`getEliteEnemy` / `getActivePressurePhase` / `applyCoverAttackDamage` 等）。包含 `clearBossSafeWindowBlockers`：清理 Boss 火线里挡路的小怪。
  - `PressureWindowController.ts` - **2026-07 新增**。压力阶段状态机（HP/时间触发推进）+ 签名/模式脉冲 + Boss 安全窗口几何 + 火线监控 + 压力弹幕生成。通过 `PressureWindowHost` 接口委托回 RunEngine 访问 template / escort 生成 / 投射物 / metrics。
  - `DashMomentMonitor.ts` - **2026-07 新增**。5 类战斗时刻的强度阈值与冷却计数器（late dash window / dash counter / elite crack follow-through / kill-pickup continue）。通过 `DashMomentHost` 接口读取 `RunState.phase`。
  - `resultAnalysis.ts` - 结果分析（路线证据计数、构建阶段判定、属性差异计算）
  - `index.ts` - 模块索引

进度跟踪见 [当前交接卡.md](file:///d:/codex/codex/auto-shooter-demo/doc/00_接手入口/当前交接卡.md)。

## 当前架构原则

- 主流程尽量稳定，不频繁重写。
- 迭代主要通过数据层扩写和权重微调完成。
- 首领和异常已经在语义上独立，但运行时仍分别复用战斗和事件主流程。
- 文档必须能解释“为什么这样分层”，而不是只罗列文件名。

## 接手时最常改的文件

- 调路线成型：`src/data/contentSelectors.ts`、`src/data/upgrades.ts`、`src/data/events.ts`、`src/data/nodes.ts`
- 调战斗压力或首领体验：`src/data/battleTemplates.ts`、`src/systems/battle/PressureWindowController.ts`（压力阶段/签名/模式脉冲/安全窗口几何）
- 调覆盖攻击安全区（蓝色提示框、覆盖伤害、Boss 火线挡路清理）：`src/systems/battle/SafeZoneController.ts`、`src/systems/battle/pressureSafeWindowMath.ts`
- 调 Boss 安全区宽限期、墙壁射击/口袋射击生成：`src/systems/battle/PressureWindowController.ts`
- 调 Dash 路线时刻埋点的阈值/冷却：`src/systems/battle/DashMomentMonitor.ts`
- 调 HUD 文案、目标提示、路线状态文本：`src/scenes/HudComposer.ts`
- 调粒子特效（命中火花、暴击爆发、穿透波纹、Dash 拖尾）：`src/scenes/ParticleDirector.ts`
- 调 HUD 和结果表达：`src/ui/OverlayController.ts`、`src/scenes/GameScene.ts`
- 调表现层特效/动画：`src/scenes/GameScene.ts`（Boss 入场、连击数、低血量警告）、`src/ui/OverlayController.ts`（面板动画、CSS 样式）
- 调观测口径：`src/systems/MetricsTracker.ts`

## 接手时最不该轻易动的文件

- `src/systems/RunEngine.ts`
  除非本轮目标明确需要，否则不要大改主流程。敌人 AI、Elite 脉冲、QA Smoke、路线叙事均在此文件中。压力窗口/安全区/Dash 时刻已拆到 `src/systems/battle/*Controller.ts` / `*Monitor.ts`，改这些职责请优先去对应模块。
- `src/game/types.ts`
  这里是语义地基，改动要同步文档。
- `src/systems/ConfigLoader.ts`
  静态导入工作流，改它等于改数据接入方式。

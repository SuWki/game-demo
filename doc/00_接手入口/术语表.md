# 术语表

本项目对外和对内都统一使用中文描述，必要时保留代码字段对照，避免文档语言与代码语言脱节。

## 核心术语

- 流派路线
  代码字段：`route`
  含义：当前构筑的主要方向。

- 路线倾向
  代码字段：`hinted`
  含义：玩家已经能感到某条路线在露头，但还没完全站稳。

- 路线站稳
  代码字段：`committed`
  含义：中段开始明显围绕某条路线构筑，主读法已经成立。

- 路线成型
  代码字段：`matured`
  含义：后段或收尾阶段，路线已经拥有清晰的兑现方式。

- 前段 / 中段 / 后段 / 最终整备 / 最终战
  代码字段：`opening / mid / late / finalPrep / finalBattle`
  含义：单局推进中的阶段标签。

- 节点
  含义：每次推进后可选择的下一站。

- 战斗节点
  代码字段：`battle`
  含义：主要成长来源，承担经验掉落与模板体验。

- 整备节点
  代码字段：`upgrade`
  含义：提供更稳、更高品质的三选一强化。

- 异常节点
  代码字段：`anomaly`
  含义：低频高记忆点内容，承担扰动、扭转、混搭和首领前预示。

- 首领节点
  代码字段：`boss`
  含义：最终固定收尾节点。

- 起手内容
  代码字段常见语义：`starter`
  含义：前段负责把路线信号露出来的内容。

- 承接内容
  代码字段常见语义：`bridge`
  含义：把“有信号”继续推向“开始站稳”的中段内容。

- 收尾兑现
  代码字段常见语义：`payoff`
  含义：后段让路线读法拉开的高辨识度内容。

- 改道窗口
  代码字段常见语义：`redirect`
  含义：允许玩家从当前路线切向别的路线，但不应抢占主路线主体。

- 混合构筑
  代码字段常见语义：`hybrid`
  含义：解释两条路线或通用效果在中后段混合成立的内容。

- 首领残响
  代码字段常见语义：`bossEcho`
  含义：首领前的预示性异常内容。

## 术语使用要求

- 文档默认使用中文。
- 代码字段第一次出现时可在括号中标注英文。
- 面向用户、面向面试和面向项目管理的文档，不直接使用英文术语作为主称呼。

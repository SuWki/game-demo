## 一、玩家基础参数

### 1.1 生存属性

| 参数名 | 数据类型 | 当前值 | 取值范围 | 设计意图 | 改动风险 |
|--------|----------|--------|----------|----------|----------|
| baseHealth | number | 100 | 80-150 | 决定容错次数，基础TTK的反面 | 过低会导致前期挫败感过高 |
| healthRegen | number | 0 | 0-5 | 战后恢复，影响节奏喘息感 | 过高会弱化治疗升级价值 |
| invincibleTimeAfterHit | number | 0.5 | 0.3-1.0 | 受击后无敌时间，防止秒杀 | 过长会降低危险感知 |

### 1.2 移动属性

| 参数名 | 数据类型 | 当前值 | 取值范围 | 设计意图 | 改动风险 |
|--------|----------|--------|----------|----------|----------|
| moveSpeed | number | 180 | 150-250 | 走位空间，与敌人速度的比值决定压力 | 过高会弱化dash路线价值，过低会导致无法躲避 |
| pickupRadius | number | 80 | 60-120 | 经验球吸附范围，影响流畅度 | 过大降低走位成本，过小增加操作负担 |
| dashCooldown | number | 3.0 | 2.0-5.0 | dash间隔，决定位移作为资源的珍贵程度 | 过低会让dash流过强 |
| dashDistance | number | 200 | 150-300 | 单次位移距离，决定穿越火线的能力 | 需与敌弹速度匹配 |

### 1.3 输出属性

| 参数名 | 数据类型 | 当前值 | 取值范围 | 设计意图 | 改动风险 |
|--------|----------|--------|----------|----------|----------|
| baseDamage | number | 25 | 20-40 | 基础击杀时间(TTK)，决定前期节奏 | 影响所有路线前期手感 |
| fireRate | number | 2.0 | 1.5-3.0 | 每秒攻击次数，决定输出密度 | 与单发伤害共同决定DPS |
| projectileSpeed | number | 400 | 300-600 | 弹速，影响命中率和提前量要求 | 过低会导致远距离难以命中 |
| projectileRange | number | 600 | 500-800 | 射程，决定安全输出距离 | 过长会弱化近战敌人威胁 |

## 二、三路线核心参数

### 2.1 Crit路线（暴击爆发流）

**核心理念**：找短窗 → 压热区 → 爆发输出

| 参数名 | 数据类型 | 当前值 | 取值范围 | 设计意图 | 改动风险 |
|--------|----------|--------|----------|----------|----------|
| critChance | number | 5% | 5%-50% | 触发频率，决定"期待感"节奏 | 过高会失去"暴击"的惊喜感 |
| critDamageMultiplier | number | 2.0 | 1.5-4.0 | 爆发幅度，决定窗口价值 | 过高会让非暴击伤害失去意义 |
| heatWindowDuration | number | 3.0 | 2-5 | 热区持续时长，决定输出时机把握难度 | 过短难以利用，过长失去紧迫感 |
| heatWindowDamageBonus | number | 50% | 30%-100% | 热区内额外伤害加成 | 决定crit流的 payoff 幅度 |
| markDuration | number | 4.0 | 3-6 | 破绽标记持续时间 | 决定玩家有多少时间组织爆发 |
| markStackLimit | number | 3 | 1-5 | 标记叠加上限 | 决定 crit 流的叠层策略深度 |

### 2.2 Pierce路线（穿透清线流）

**核心理念**：找敌线 → 拆屏清场 → 连锁回响

| 参数名 | 数据类型 | 当前值 | 取值范围 | 设计意图 | 改动风险 |
|--------|----------|--------|----------|----------|----------|
| pierceCount | number | 1 | 1-5 | 穿透敌人数量，决定清线能力 | 过高会让单点伤害失去价值 |
| pierceDamageDecay | number | 20% | 0%-50% | 每穿透一个敌人后伤害衰减比例 | 0%为线性清线，过高则后续无力 |
| crackSpreadRange | number | 150 | 100-250 | 裂纹扩散范围，决定AOE能力 | 决定pierce流的空间控制感 |
| crackDamagePerTick | number | 10 | 5-20 | 裂纹持续伤害，决定"区域封锁"价值 | 与直接伤害的比例关系 |
| echoTriggerInterval | number | 0.5 | 0.3-1.0 | 回响触发间隔，决定连锁节奏 | 过快会视觉混乱，过慢失去联动感 |

### 2.3 Dash路线（穿梭反击流）

**核心理念**：擦身充能 → 脉冲爆发 → 换位反打

| 参数名 | 数据类型 | 当前值 | 取值范围 | 设计意图 | 改动风险 |
|--------|----------|--------|----------|----------|----------|
| dashInvincibleFrames | number | 15 | 10-30 | 冲刺无敌帧数(按60fps计) | 决定"穿弹"的操作窗口 |
| grazeChargePerFrame | number | 2 | 1-5 | 擦身时每帧充能值 | 决定dash流的主动充能效率 |
| pulseDamage | number | 50 | 30-100 | dash结束时脉冲伤害 | 决定dash不只是位移，也是输出 |
| pulseRange | number | 120 | 100-200 | 脉冲伤害范围 | 决定dash落点的策略性 |
| driveCooldownReduction | number | 0.5 | 0.3-1.0 | 成功擦身后减少的dash冷却 | 决定高风险高回报循环的流畅度 |
| counterWindowDuration | number | 1.0 | 0.5-2.0 | 反击窗口持续时间 | 决定玩家有多少时间组织反击 |

## 三、敌人参数

### 3.1 普通敌家族

#### Standard（标准型）- 基准敌人

| 参数名 | 数据类型 | 当前值 | 设计意图 |
|--------|----------|--------|----------|
| hpMultiplier | number | 1.0 | 基准血量，其他敌人以此为参照 |
| speedMultiplier | number | 1.0 | 基准移速，决定基础压力 |
| damage | number | 10 | 接触伤害，决定错误走位成本 |
| expValue | number | 10 | 击杀奖励，决定farm价值 |
| threatPriority | number | 1 | 威胁优先级，决定自动瞄准权重 |

#### Brute（厚血型）- 肉盾/阻拦

| 参数名 | 数据类型 | 当前值 | 设计意图 |
|--------|----------|--------|----------|
| hpMultiplier | number | 3.0 | 高血量，作为移动障碍物 |
| speedMultiplier | number | 0.6 | 低速，给玩家时间决策 |
| damage | number | 20 | 高伤害，强化"不能碰"感知 |
| expValue | number | 25 | 高奖励，鼓励击杀 |
| threatPriority | number | 2 | 较高优先级，需要处理但不能被忽视 |

#### Skirmisher（高速型）- 骚扰/侧翼

| 参数名 | 数据类型 | 当前值 | 设计意图 |
|--------|----------|--------|----------|
| hpMultiplier | number | 0.6 | 脆皮，鼓励快速点杀 |
| speedMultiplier | number | 1.4 | 高速，制造紧迫感 |
| damage | number | 8 | 低伤害但高频，累积威胁 |
| expValue | number | 8 | 低奖励，不farm也能接受 |
| threatPriority | number | 3 | 高优先级，必须优先处理 |

#### Ranged（远程型）- 压制/区域控制

| 参数名 | 数据类型 | 当前值 | 设计意图 |
|--------|----------|--------|----------|
| hpMultiplier | number | 0.8 | 中等血量 |
| projectileSpeed | number | 300 | 弹速，决定躲避难度 |
| fireInterval | number | 2.0 | 射击间隔，决定压制密度 |
| projectileDamage | number | 15 | 弹丸伤害 |
| threatPriority | number | 2 | 需要及时处理但不用panic |

### 3.2 精英敌人

**核心理念**：本体 + 护卫 + 裂口窗口 = 小高潮

| 参数名 | 数据类型 | 当前值 | 取值范围 | 设计意图 |
|--------|----------|--------|----------|----------|
| eliteType | enum | "anchor"/"lure" | - | 精英模板类型 |
| baseHp | number | 500 | 300-800 | 本体血量，决定战斗时长 |
| guardCount | number | 4 | 2-6 | 护卫数量，决定清理压力 |
| guardHp | number | 80 | 50-120 | 护卫血量，决定拆屏时间 |
| guardRespawnInterval | number | 8.0 | 5-12 | 护卫恢复间隔，决定裂口窗口时长 |
| crackWindowDuration | number | 3.0 | 2-5 | 裂口持续时间，决定追击时机 |
| oppressionPulseInterval | number | 5.0 | 3-8 | 压迫脉冲间隔，决定压力节奏 |

### 3.3 Boss敌人

**核心理念**：多阶段 + 明确主压力 + 路线差异化考验

| 参数名 | 数据类型 | 当前值 | 取值范围 | 设计意图 |
|--------|----------|--------|----------|----------|
| bossType | enum | "hunt"/"lockdown"/"bastion"/"collapse" | - | Boss模板类型 |
| phaseCount | number | 3 | 2-4 | 阶段数量，决定战斗节奏变化次数 |
| phaseHpThreshold | number[] | [0.7, 0.4] | - | 阶段转换血量比例 |
| baseHp | number | 2000 | 1500-3000 | 总血量，决定战斗时长 |
| fireLineCoverageTarget | number | 0.4 | 0.3-0.6 | 火线覆盖率目标，决定安全窗频率 |
| safeWindowMinDuration | number | 2.0 | 1.5-3.0 | 安全窗最小时长，给玩家喘息 |
| summonInterval | number | 10.0 | 8-15 | 召怪间隔，决定杂兵压力 |
| summonCount | number | 3 | 2-5 | 每次召怪数量 |
| phaseSignatureAbility | string[] | - | - | 每阶段标志性能力（如：全场火、定点轰炸） |

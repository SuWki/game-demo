# Tool Shortlist

This reference condenses the PDF into the pieces that are actually useful for game development.

## Highest-Value Items From The PDF

- `full-stack AI dev toolkit and core prompt library`
  - Most directly relevant item in the whole PDF.
  - Likely useful for coding workflow, prompt patterns, and tool chaining.
- `Claude Code local assistant config guide`
  - Strong value for coding-heavy game work.
  - Useful for repo-aware implementation and local iteration.
- `0011.ai`
  - Best fit when the team wants stable coding-model access and heavy day-to-day usage.
- `Nova AI`
  - Best fit when the team only needs API access and wants to wire its own clients or scripts.

## Tool Matrix By Job

### Code And Systems

- `Codex` / `Claude Code`
  - Best for implementation, refactors, debugging, and project-aware iteration.
- `Gemini`
  - Best for long design docs, logs, PDFs, and context-heavy summaries.
- `DeepSeek`
  - Best low-cost backup for code and reasoning.
- `Kimi`
  - Best backup for long Chinese documents and PDF digestion.

### Research

- `Perplexity`
  - Best for finding references, comparable systems, and sources quickly.
- `Gemini`
  - Best when the research material is large and mixed-format.

### Concept Art And Style Exploration

- `Midjourney`
  - Best for premium key art, moodboards, and polished style targets.
- `LiblibAI`
  - Best for China-friendly Stable Diffusion workflows and model browsing.
- `Civitai`
  - Best for open model discovery and style experimentation.
- `NovelAI`
  - Best when the visual target is clearly anime or stylized 2D.

### Audio

- `Fish Audio`
  - Best for Chinese narration, NPC voice drafts, and local-market content.
- `ElevenLabs`
  - Best for multilingual VO and more natural international delivery.
- `Suno`
  - Best for temporary BGM, theme sketches, and quick music iteration.

### Video And Marketing

- `Kling`
  - Strong option for AI video generation in China-accessible workflows.
- `Runway`
  - Strong option for controlled promo and motion experiments.
- `Sora`
  - High-end option for cinematic concept shots and trailer exploration.
- `Veo`
  - Useful for strong camera and lighting references.
- `Jimeng`
  - Good for domestic-friendly fast video ideation.
- `Vidu`
  - Good for fast, accessible video generation.
- `HeyGen`
  - Useful mainly for presenter-led promo videos, not core game development.

## Recommended Stacks

### Solo Developer Prototype Stack

- Code: `Codex` or `Claude Code`
- Research: `Gemini` + `Perplexity`
- Art: `Midjourney` or `LiblibAI`
- Voice: `Fish Audio`
- Music: `Suno`

### China-First Indie Stack

- Code: `Codex` or `Claude Code`, `DeepSeek` as backup
- Research: `Kimi`, `Gemini`
- Art: `LiblibAI`, `Civitai`, `Midjourney`
- Voice: `Fish Audio`
- Video promo: `Kling`, `Jimeng`, `Vidu`

### Global Launch Stack

- Code: `Codex` or `Claude Code`
- Research: `Perplexity`, `Gemini`
- Art: `Midjourney`
- Voice: `ElevenLabs`
- Video promo: `Runway`, `Sora`, `Veo`

## Low-Priority Items For Core Game Development

These appeared in the PDF but are usually not worth prioritizing early:

- digital humans as a first-step production tool
- self-media monetization workflows
- streaming/media subscription bundles
- traffic-focused no-face video workflows
- expensive promo-video tooling before the game loop is proven

## Good Sequencing

Use this order unless the user asks otherwise:

1. design brief
2. coding workflow
3. playable prototype
4. visual direction
5. voice and BGM drafts
6. trailer and promo assets

# 指标与观测说明

## 观测目的

这个项目的很多问题不能只靠主观感受判断，例如：

- 路线信号是不是出现得太晚
- 路线是不是稳定不下来
- 是否经常中途被带偏
- 稀有内容是否根本刷不出来
- 首领后段是否大多数自然样本都没有看到

所以必须保留最小但有效的观测体系。

## 当前观测方式

- 本地 `localStorage`
- 页面内导出 JSON
- 浏览器自动化截图和摘要
- 局内摘要字段

## 当前重点指标

### 主循环

- 首次升级时间
- 单局时长
- 结局类型

### 路线状态

- 首次出现路线倾向的时间
- 路线开始稳定的时间
- 路线成型时点
- 是否发生转线

### 内容分发

- 路线强化是否看到了
- 稀有内容是否看到了
- 混合构筑与改道内容是否出现并被选择

### 首领与收尾

- 首领模板是否进入
- 首领阶段是否命中
- 首领持续压迫模式是否命中
- 最终结局摘要是否完整

## 当前关键判断口径

- 如果路线倾向出现很早，但路线长期稳定不下来，说明组合内容不足
- 如果路线稳定太快但总是锁死，说明前段过强
- 如果稀有内容长期不可见，说明后段变化感不足
- 如果首领后段长期低覆盖，说明收尾体验不稳定

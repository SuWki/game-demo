# 版本目标与验收标准

## 0.9 阶段目标

### 目标

- 主循环跑通
- 三条主路线可玩
- 首领与异常语义成立
- 最低限度表现层与音效成立
- 可完成本地验证和结果导出

### 当前结论

- 已达到可测试版状态
- 不代表无风险，只代表没有阻断封版的系统问题

## 1.0 第一阶段目标

### 目标

- 在 `0.9` 稳定骨架上继续补内容和读法
- 提高自然样本中的路线连续性
- 提高不同局之间的差异感和重开动机
- 不重写主流程

### 当前阶段重点

- 核心循环的即时回报链打磨
- 普通战的击杀、掉落、吸附和升级衔接提纯
- 在继续打磨战斗爽感时守住路线连续性和首领监控项不回退

## 当前轮次验收标准

### 当前轮次：核心循环与核心战斗打磨

判断当前轮次是否签收，至少看三件事：

- 普通战里是否更容易读出“打中 -> 打死 -> 掉落 -> 拾取 -> 继续追击”的回报链
- 战斗爽感提升是否主要来自战斗本身，而不是单纯 UI 包装
- 路线连续性和首领监控项是否没有明显回退

### 当前判断

- 当前已经进入以核心战斗和回报链打磨为主的阶段
- 旧的路线收口工作不再是唯一主线，但仍需要作为回归项持续观察
- 当前是否签收，应以后续战斗实测和 Boss 监控回归结果共同判断

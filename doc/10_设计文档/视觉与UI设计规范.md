# 视觉与 UI 设计规范

## 文档状态

- 状态：`当前生效 / 方向母稿`

- 下游引用：`UI页面固定规则.md`、`界面线框与落地清单.md`、`画面与UI验收清单.md`

## 当前结论

当前项目的 UI 方向已经重新锁定。

旧的这些方向，全部废弃：

- `黑框黑底大面板`
- `科技终端感首页`
- `大面积暗色玻璃浮层`
- `右侧信息盒 + 左侧标题卡` 这类明显偏网页或偏工具的结构
- `选择界面堆很多说明、phase track、progress summary、额外状态条`

后续页面开发不允许再回到这些做法。

## 新的 UI 总方向

这款游戏的 UI 现在走的是：

`轻卡通 / 粗块面 / 高识别 / 强功能 / 非黑盒`

也就是：

- 开始页像真正的游戏开始页，不像工具首页。
- 结算页像游戏结算页，不像数据报表页。
- 战斗 HUD 像《土豆兄弟》一类生存射击的简洁功能 HUD。
- 选择界面只保留核心选择，不再堆额外说明组件。

这不是要照搬参考图的题材，而是要继承它们的页面逻辑：

- 画面先成立，UI 后压上去
- 主要操作一眼可见
- 主按钮像“游戏按钮”，不是“产品按钮”
- 页面结构先让玩家秒懂，再谈包装

## 风格关键词

- 居中
- 大标题
- 粗字重
- 彩色按钮
- 亮色功能牌
- 非黑色重面板
- 直接
- 游戏感
- 插画背景
- 厚边和切板感
- 少容器
- 强轮廓

## 样式锚点

### 1. 背景

- 开始页优先使用完整场景背景，不允许拿纯黑渐变当背景
- 结算页允许背景虚化或压暗，但中间结果板必须保持明亮
- 选择界面背景可适度压暗，但不能出现大面积黑色遮罩板

### 2. 标题

- 标题优先白字或浅色高亮字
- 必须有足够体积和存在感，不能退成小号说明文
- 标题的位置优先“上中区域”或“页面中上部”

### 3. 主按钮

- 主按钮必须是厚块、亮色、强对比
- 每个主按钮要有清楚的边缘、内阴影或下压感
- 默认不使用纯黑、纯灰、透明玻璃按钮
- 允许木牌、彩牌、卷轴牌、厚色块，但不允许科技终端扁按钮

### 4. 数据面板

- 数据面板只在结算页允许成为主结构
- 面板优先浅色、暖色或中性色结果板
- 面板任务是承载“这一局结果”，不是做复杂控制台

### 5. HUD

- HUD 组件必须轻，不能用厚面板把战斗区切碎
- HUD 文本以高对比可读为第一优先
- 左上条带和顶部文字必须让出中场战斗区域

### 6. 选择框

- 选择框是“卡片本体”，不是卡片 + 大量外围辅助模块
- 选择框之间要有明确间距和统一尺寸
- 单卡视觉要足够独立，让玩家一眼扫完四张

## 风格禁区

下面这些元素默认禁止使用，除非用户明确批准：

- 大面积纯黑矩形底板
- 深色玻璃拟态大卡片
- 首页右侧说明栏
- 结算页第三按钮
- 选择页顶部进度总结块
- 选择页 phase track
- 选择页 mode hint / progress hint / 额外副标题盒
- 右上角任务盒、目标盒、路线盒
- 把 HUD 做成网页式信息栏

## 页面视觉原则

### 1. 开始页

- 全屏背景优先使用场景画面或带环境感的背景。
- 标题居中或上中居中，不做左右分栏式信息结构。
- 按钮必须居中纵向排列，像真正的游戏主菜单。
- 按钮要有明显配色差异和强点击感。
- 不允许再做黑底内容框把页面切成左右两块。
- 标题和按钮应直接压在背景上，不额外套一整块黑色外框。

### 2. 结算页

- 结算信息集中在中间主区域。
- 允许使用单个结算板或中间结算容器。
- 必须一眼看到“胜利/失败”和两枚主按钮。
- 不允许再做左右两栏的“主卡 + 侧卡”结构。
- 页面底部只允许保留“返回主界面 / 重新开始游戏”两个主操作。

### 3. 战斗 HUD

- 只保留必要信息。
- 左上：HP、EXP 和对应进度条。
- 顶部中间：波次。
- 波次下方：关卡玩法类型，例如 `歼灭`、`生存`。
- 玩家头顶必须有血条。
- 不允许再加右上目标框、路线框、大提示框。
- 不允许再出现“黑底 HUD 大容器”或“网页仪表盘式 HUD”。

### 4. 选择界面

- 选择界面必须回到“标题 + 4 个选择框”的极简结构。
- 所有多余说明块全部删除。
- 不允许有顶部总结卡、phase track、进度摘要、右侧辅助信息。
- 玩家只需要看到“在选什么”和“4 个选项”。
- 所有选择类型统一这套结构，不允许某个选择页单独长出侧栏或附加面板。

## 字体与按钮

- 标题：高字重、粗块、强对比。
- 按钮文字：全大写或粗中文，重点突出主行动词。
- 按钮底色：明亮、可区分、非统一深灰。
- 按钮轮廓：可使用木牌、色块牌、厚边牌、卡通切板，但不能再做黑色扁平按钮。
- 字体整体要偏“游戏标题字”和“功能大字”，不走终端码字风。

## 和玩法的关系

这次调整锁定的是 `页面 UI 规则`，不是重做全部战斗美术风格。

也就是说：

- 敌人、弹道、背景的战斗可读性要求继续保留。
- 但页面 UI 的主风格，必须改成更像真正游戏页面的表达。
- 以后任何人做开始页、结算页、选择页、HUD，都先看 `UI页面固定规则.md`。

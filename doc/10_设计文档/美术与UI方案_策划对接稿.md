# 美术与 UI 方案策划对接稿

## 文档状态

- 状态：`评审稿 / 策划判断用`
- 上游依据：`视觉与UI设计规范.md`、`界面线框与落地清单.md`、`美术资产与画面设计规范.md`
- 配套文档：`美术资产规格表.md`、`画面与UI验收清单.md`

## 文档目的

这份文档不是给美术执行的细则，也不是给程序直接照抄的线框，而是给策划做方案判断用的对接稿。

它要回答的是：

- 这次重定美术与 UI，到底想解决什么问题
- 新方案和当前实现相比，核心变化是什么
- 这些变化是否更贴合当前玩法
- 哪些点需要策划确认
- 用什么标准判断这套方向是否成立

## 当前项目前提

本项目当前不是在做「完整商业化包装」，而是在做一个可验证体验的短局节点推进自动射击原型。

当前策划前提不变：

- 单局时长 `8~12` 分钟
- 核心是 `走位 + 自动攻击 + 战斗内成长 + 节点推进`
- 三条路线必须成立：`暴击 / 穿透 / 穿梭`
- 中后段要能读出稳定、压力上升、收尾临近
- 精英与 Boss 要承担更高层级的战斗打法，不只是血更厚

## 当前设计的主要问题

现有实现的判断如下：

### 1. 太像「信息型原型」，不像「战斗型游戏」

- 当前界面已经做到整洁、清楚、不过载。
- 但它更像一个被包在深色壳子里的原型终端，而不是一个真正会打起来的游戏。

### 2. UI 能读，但不够刺激

- 菜单、结果页、选择页都偏平静。
- 玩家能看懂，但很难被激发出「马上开一局」「这次我想试另一条路线」的冲动。

### 3. 敌我识别有，但层级不够强

- 当前整体视觉还处在「同一类冷色体系」里。
- 这让画面稳定，但会削弱战斗里的危险感和压迫感。

### 4. 面板更像卡片浏览，不像战术抉择

- 当前路线选择、强化选择、异常处理都已经做了区分。
- 但整体还是更像信息卡差异，而不是「不同类型的作战决策」。

### 5. 画面整体有秩序，但危险没有真正长进世界里

- 危险目前更多靠说明、短提示、轻表现补出来。
- 而不是靠整套视觉系统天然传达「火线在逼近」「屏卫正在成型」「现在是追击窗口」。

## 这次新方案的核心立场

### 一句话结论

新方案主张把项目从：

`极简科技终端原型`

改成：

`冷核机体 vs 热态火线 的高压节点作战`

也就是说：

- 玩家是冷色高亮核心
- 敌人是热色压制单元
- 场地是压力分布，而不是中性背景
- UI 是战斗系统的一部分，而不是覆盖层

## 这次重定后，哪些东西会变

### 1. 玩家与敌人的视觉关系会被拉开

#### 新方案

- 玩家：冷白、冷青、冷蓝
- 普通敌人：洋红、砖红、亮粉、紫
- 精英 / Boss：橙红、琥珀、金橙、紫色屏卫

#### 策划含义

这样做不是单纯为了「更好看」，而是为了让玩家更快完成四个判断：

1. 哪个是我
2. 哪个是普通危险
3. 哪个是高压对象
4. 哪个方向是火线

#### 预期收益

- 危险识别更直观
- Boss 和精英不需要靠数值说明来抬层级
- 裂口、火线、屏卫这些战斗打法更容易被看到

### 2. UI 会从「原型面板」变成「战术界面」

#### 新方案

- 开始页：从「干净首页」改成「战前终端」
- 结果页：从「整洁总结页」改成「战斗结案页」
- 路线选择：改成「作战路线指令」
- 强化选择：改成「机体挂载模组」
- 异常处理：改成「风险协议」
- 最终整备：改成「战前校准」

#### 策划含义

这不是文案换皮，而是要让不同类型的选择被玩家感受到「性质不同」：

- 路线选择是在选下一段战斗
- 强化选择是在补构筑
- 异常处理是在押注
- 最终整备是在准备 Boss

#### 预期收益

- 节点系统的差异感更强
- 选择的心理重量更大
- 路线倾向会更容易被玩家记住

### 3. 背景会从「中性底板」变成「压力几何」

#### 新方案

- 不做复杂地图
- 仍然保持低资产、程序化方向
- 但背景会更主动表达：
  - 压边
  - 火线
  - 侧压
  - 扫线
  - 安全口袋

#### 策划含义

这会让战斗模板之间的差异不只存在于数值和敌人生成逻辑里，也存在于第一眼画面感里。

#### 预期收益

- 普通战 / 火线战 / 精英战 / Boss 战更容易一眼区分
- 路线优势场景更容易被玩家感知
- 低成本情况下也能提升模板记忆度

### 4. 战斗反馈会更强调「危险」和「机会」

#### 新方案

- 低血时不只是红框，而是整套画面热度上升
- 精英裂口不只靠提示，而是护卫退让、弹幕回落、楔形追击一起出现
- Boss 火线不是普通红弹加强版，而是更明显的区域压迫语言

#### 策划含义

这会直接服务当前最重视的两个体验目标：

- 危险感要更容易读到
- 裂口窗口要更容易被读成「现在能追」

#### 预期收益

- 普通战更有即时张力
- 精英战更像「解题型高压战」
- Boss 收尾更像阶段战，而不是普通战加量

## 这次方案没有改变什么

为了避免误判，这里明确写出没有改变的前提：

- 不改项目类型
- 不改三路线结构
- 不改轻量节点推进
- 不改当前 Phaser 原型技术路线
- 不要求高成本角色插画
- 不要求重资产地图
- 不新增和玩法脱节的新系统

这次改的是：

- 美术气质
- 敌我颜色层级
- UI 语言
- 战斗反馈表达方式

不是在改主玩法。

## 新方案是否更贴当前玩法

判断是：更贴。

原因如下。

### 1. 自动射击玩法非常依赖「局势体感」

因为玩家不是靠复杂主动技能表达自己，所以玩家对「危险在哪里」「窗口在哪里」的视觉依赖更强。

新的敌我色层和火线表达更符合这一点。

### 2. 三路线都需要被「打出来」，不能只被「选出来」

- 暴击要读成升温和爆点
- 穿透要读成拆线和贯穿
- 穿梭要读成擦边和反打

如果视觉系统太平，路线差异就会继续只停留在面板层。

### 3. 精英和 Boss 的设计目标本来就不是堆数值

当前策划文档反复强调：

- 精英应该读成「护卫成屏 -> 裂口 -> 追本体」
- Boss 应该读成阶段变化和场地压力

那么视觉系统就应该主动服务这些打法，而不是保持中性。

### 4. 节点推进玩法需要「决策类型感」

如果路线选择、强化、异常、最终整备看起来都差不多，玩家只会读到「又是三张卡」。

新方案把四种决策做成不同性质的 UI 语义，更符合节点制玩法。

## 需要策划确认的关键问题

下面这些问题是这次对接最需要策划判断的。

### 问题 1：项目是否接受从「极简冷静」转向「高压热态」

#### 需要判断的不是

- 颜色喜不喜欢

#### 需要判断的是

- 这款游戏要不要更有危险感和攻击性
- 是否接受画面情绪变得更「战斗化」

### 问题 2：玩家与敌人的强温差是否符合玩法目标

#### 方案主张

- 玩家冷
- 敌人热
- Boss 更热

#### 需要策划判断

- 这种强敌我分层，是否有助于当前最看重的战斗可读性

### 问题 3：选择界面是否应该更偏「作战语义」而不是「信息语义」

#### 方案主张

- 路线页像路线指令
- 强化页像模组挂载
- 异常页像风险协议
- 最终整备页像战前校准

#### 需要策划判断

- 这种更游戏化的区分，是否更符合节点系统的定位

### 问题 4：背景是否应该更主动承担战斗模板表达

#### 方案主张

- 背景不做地图美术
- 但要做压力几何和模板签名

#### 需要策划判断

- 是否认同「背景也应该帮助玩家读局势」，而不是只做静态底板

### 问题 5：结果页是否应该更强调重开情绪

#### 方案主张

- 当前结果页太收
- 新结果页要更像「战斗刚结束」

#### 需要策划判断

- 是否认同结果页应服务重开动机，而不只是展示结果

## 策划判断标准

这次方案是否成立，不建议用「审美好不好看」作为主标准，而建议用下面五条判断：

### 标准 1：是否更利于读局势

- 玩家是否更容易区分自己、敌人、火线、Boss 危险

### 标准 2：是否更利于读路线

- 暴击 / 穿透 / 穿梭是否更容易被打出来，而不只是面板里成立

### 标准 3：是否更利于读精英与 Boss

- 精英的「屏卫 / 裂口 / 追击」
- Boss 的「火线 / 阶段 / 收尾」
- 是否更容易被看到

### 标准 4：是否更利于节点决策

- 四类节点是否更像四种不同性质的选择

### 标准 5：是否符合当前原型阶段

- 有没有明显把项目拉向高资产和重包装

## 当前建议结论

一个偏结论性的建议：

### 可以先原则性通过

通过项：

- 冷核玩家 vs 热态火线
- 敌我颜色重分层
- 选择界面改成作战语义
- 精英 / Boss 反馈更主动服务裂口与火线
- 结果页更强调重开情绪

### 但建议控制强度

需要控制的项：

- 不要把背景做得太花
- 不要让 UI 变成重工业装饰板
- 不要为了「战斗感」把界面信息变复杂

## 对接后的下一步建议

如果策划判断总体通过，后续建议按下面顺序推进：

1. 先确认敌我颜色体系和整体气质
2. 再确认菜单 / 结果页 / 四类选择面板的语言重定
3. 再进入敌人轮廓、弹道、火线和裂口的实现细化

如果策划判断需要收敛，也建议只收敛强度，不建议退回当前那种偏网页、偏终端的方向。

## 当前结论

这份方案的核心不是「做得更炫」，而是：

- 让画面更贴玩法
- 让危险更容易读到
- 让路线更容易被打出来
- 让节点选择更有性质差异
- 让结果页更能驱动重开

换句话说，这次重定的目标不是包装，而是把这款游戏真正拉回到它应有的战斗气质上。

# 美术资产规格表

## 文档状态

- 状态：`当前生效 / 制作规格`
- 上游依据：`视觉与UI设计规范.md`、`美术资产与画面设计规范.md`
- 使用对象：美术、UI、程序、协作 GPT

## 使用说明

- 这份文档解决“做什么尺寸、分几层、导什么格式、动画预算多少”。
- 所有比例都按当前 `960x540` 主视口和 Phaser 2D 实现考虑。
- 当前项目优先轻资产、几何化、可程序控制，不以大贴图和重骨骼动画为目标。

## 弹道与危险规格

| 对象 | 交付物 | 屏幕相对尺寸 | 动画预算 | 分层建议 | 导出建议 |
| --- | --- | --- | --- | --- | --- |
| 玩家基础弹道 | 1 个基础弹芯 + 1 个短尾迹 | 极细，宽度不超过玩家宽度 `0.12x` | 程序化优先 | `core / glow / trail` | 程序绘制优先，必要时 `PNG` 小图 |
| 暴击路线弹道 | 1 套热爆命中特效 | 比基础弹略厚 `1.1x` | `6~8` 帧 | `flash / spark / impact` | `PNG` 序列或 sprite sheet |
| 穿透路线弹道 | 1 套贯穿残线特效 | 比基础弹更细更长 | `4~6` 帧 | `beam / streak / impact` | 程序绘制优先 |
| 穿梭路线弹道 | 1 套偏移残影特效 | 与基础弹相近 | `6~8` 帧 | `core / echo / impact` | 程序绘制优先 |
| 普通敌弹 | 1 个弹体 + 1 个短高亮 | 宽度不超过玩家宽度 `0.14x` | `4~6` 帧 | `core / edge / glow` | 程序绘制优先 |
| Boss 弹道 | 1 个弹体 + 1 个预热环 + 1 个命中特效 | 比普通敌弹厚 `1.3x~1.6x` | `6~10` 帧 | `core / warning / glow / impact` | 程序绘制 + 小图件混合 |
| Boss 火线 | 1 套扫线纹理 + 1 套边缘高亮 + 1 套预热遮罩 | 以战场宽度为单位 | 程序滚动优先 | `line / edge / warning / fade` | 半透明 `PNG` 或程序材质 |
| XP 球 | 1 个主球体 + 1 个吸附态 | 直径约为玩家宽度 `0.18x` | `4~6` 帧 | `core / ring / trail` | `PNG`，单体不超过 `128x128` |
| 危险区 / 安全窗 | 1 套边界图形件 | 以区域为单位 | 程序化优先 | `mask / border / pulse` | 半透明 `PNG` 或程序绘制 |

## UI 图形件规格

| 组件 | 交付物 | 尺寸建议 | 动画预算 | 分层建议 | 导出建议 |
| --- | --- | --- | --- | --- | --- |
| 主按钮 | 默认 / hover / 按下 / 禁用 | 高度 `44~56px` | `3~4` 态 | `base / edge / glow / label` | `SVG` 或 9-slice `PNG` |
| 次按钮 | 默认 / hover / 按下 | 高度 `36~44px` | `3` 态 | `base / edge / label` | `SVG` 或 9-slice `PNG` |

| 选择面板底板 | 路线、强化、异常、最终整备共用 | 宽度约视口 `0.62x~0.74x` | `2~3` 态 | `back / frame / cut / accent` | 9-slice `PNG` 或 CSS 图形 |
| 标签条 | 路线标签、危险标签、节点标签 | 高度 `18~24px` | 无需复杂动画 | `base / text` | `SVG` |

| 结果页锚点 | 结案盘、回顾刻线、CTA 托底 | 右侧局部使用 | 程序补间优先 | `grid / arc / markers / glow` | `SVG` 或程序绘制 |

## 命名与分层规则

- 文件命名统一使用英文小写加短横线。
- 角色与敌人命名格式：`unit-player-core`、`enemy-standard-a`、`boss-bastion-main`
- 特效命名格式：`fx-player-crit-impact`、`fx-boss-lockdown-sweep`
- UI 命名格式：`ui-button-primary`、`ui-panel-route`、`ui-hud-strip`
- 图层顺序建议统一为：`back -> body -> core -> edge -> glow -> hit -> trail`

## 导出规则

- 静态图使用透明底 `PNG`。
- 重复拉伸底板优先 `9-slice`。
- 可程序绘制的线条、环、遮罩优先不出位图。
- 单张资源不追求高分辨率堆叠，优先保证轮廓和对比。

## 当前不建议投入的资源

- 大尺寸角色立绘。
- 长剧情插画。
- 写实场景大图。
- 需要额外复杂播放系统的重骨骼动画。

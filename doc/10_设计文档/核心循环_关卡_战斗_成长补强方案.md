# 核心循环、关卡、战斗与成长补强方案

## 文档状态

- 状态：`当前生效 / 专项补强稿`
- 适用对象：策划、开发、技术策划、接手协作者
- 文档目标：把当前版本在核心循环、关卡体验、战斗体验和属性成长曲线上的补强方向汇总成一份可执行方案，避免各层各改各的。

## 这份文档回答什么

这份文档只回答四个问题：

1. 当前核心循环哪里已经成立，哪里还偏虚。
2. 当前关卡 / 节点 / 战斗节奏还该怎么补。
3. 当前属性成长曲线该怎么补，才能让路线更稳而不是更早锁死。
4. 开发和策划下一步应该优先改哪里，为什么先改那里。

## 当前总判断

项目当前已经不是「系统不够」，而是「体验链条还不够紧」。

现在真正要补强的，不是继续加新节点类型、新页面、新玩法层，而是把这一条链压得更顺：

开始进入一局 -> 第一场普通战读懂移动与击杀 -> 愿意追掉落 -> 升级看到方向 -> 节点判断这一局往哪走 -> 中段路线稳定 -> 精英战出现小高潮和解题窗口 -> 后段形成收尾 -> Boss 给句号 -> 结果页推动重开

当前四个最关键的缺口是：

- 普通战回报链虽然已经成立，但「局内一拍接一拍往前滚」的强度还可以继续增强。
- 五轮节点结构已经清楚，但中段和后段的「这一拍为什么值得选、为什么是这类战斗」还可以更鲜明。
- 三条路线都有基础签名，但 `dash` 仍偏弱，`pierce` 刚补出持续感，仍要防「逻辑成立、体感不稳」。
- 成长曲线在方向上是对的，但桥接层和收尾层还需要更明确地服务「中段稳定」和「后段收尾」。

## 一、核心循环还该怎么补

### 当前已经成立的部分

- 玩家已经能很快理解：移动、自动攻击、击杀掉经验、追过去捡、升级三选一。
- 普通战已经能读出基本回报链：打中 -> 打死 -> 掉落 -> 吸附 -> 继续追。
- 节点推进已经足够轻，不会把节奏拖成地图阅读。
- 结果页已经不是纯空页，单局闭环基本成立。

### 当前仍偏虚的部分

#### 1. 第一拍和第二拍之间的黏性还可以更强

当前玩家已经能感到「打到了、捡到了」，但还需要更稳定感到：

- 现在值得继续压下一只。
- 这一拍的风险和回报是连着的。
- 这次升级和刚刚那场战斗是直接连上的。

这一段决定普通战是变成「工作流」，还是变成「愿意继续滚」的战斗主链。一局里玩家经历次数最多的不是 Boss，而是普通战和普通升级，所以这里偏软，整局就发虚。

#### 2. 路线露头到稳定之间还需要更清楚的过桥感

当前设计已经有「露头 -> 稳定 -> 收尾」的分层，但中段仍容易出现：

- 看起来开始偏某条路线。
- 但体感上还没有「这把已经进这条线了」的明确转折。

这是整局构筑体验最容易塌掉的地方。如果中段一直飘，后段再强也会显得像临时拉高。

#### 3. 收尾前的「要去打最终检定了」还需要更强心理坡度

当前有最终整备和 Boss 结构，这是对的。但后段到最终整备的心理坡度还可以更明确：

- 后段越来越像收尾，而不是继续打普通战换皮。
- 最终整备更像最后拼图，而不是又一次普通升级。
- Boss 更像整局的句号，而不是长一点的大怪战。

这直接决定结果页有没有重开动力。短局项目最怕「打完了，但感觉只是结束了，不是收完了」。

### 当前核心循环补强方向

#### 优先级 P0：把普通战回报链继续压紧

重点补：

- 击杀后的追击冲动
- 掉落吸附后的短暂推进感
- 升级三选一对上一场战斗的直接回应感

不建议靠这些补：

- 不建议靠长说明文本补。
- 不建议靠更复杂的局外成长补。
- 不建议靠大量新页面补。

#### 优先级 P1：把路线稳定点做得更明确

重点补：

- 让中段第一次「这把真的开始走这条路了」的时刻更稳定可感。
- 让这个稳定点出现在战斗内，而不是只出现在选项文字上。

#### 优先级 P1：把后段和 Boss 的收尾关系做得更清楚

重点补：

- 生存战和尾段高压战更像整局收尾。
- 最终整备更像终局补正。
- Boss 更像「验证 build 是否完整成立」的最后一战。

## 二、关卡体验还该怎么补

### 当前结构判断

当前只保留四类节点、五轮结构是对的：

- 战斗
- 整备
- 异常
- Boss

五轮结构也是对的：

- `opening`
- `mid`
- `late`
- `finalPrep`
- `finalBattle`

当前问题不是结构不够，而是每轮的体验职责还可以再拉开。

### 各轮还需要补强什么

#### 第一轮：前段露头

当前应该继续补：

- 让第一轮更快建立「移动有用、掉落值得追、升级真会改变这局」的信任感。
- 第一轮战斗模板之间的差异要服务基础看局势，不要过早变成方向锁死。

当前不该做：

- 不要在第一轮就大量发强路线收尾牌。
- 不要让第一轮异常节点过于像高风险赌局。

#### 第二轮：中段稳定

这是当前最应该继续补的一轮。

要补的不是更多节点，而是更强的节点职责差异：

- 战斗节点：更明确检定当前 build 是否开始稳住。
- 整备节点：更明确服务「补桥接、补稳定」，而不是无脑发大牌。
- 异常节点：更明确服务「改道、并轨、预读、押注」，而不是普通补给。

核心构筑体验几乎都在这里定型。如果第二轮不够清楚，第三轮只能被迫补救。

#### 第三轮：后段收尾

当前第三轮最该补的是「后段越来越像收尾」：

- 生存战要更像「在更少空档里维持路线打法」。
- 尾段异常要更像「终局改写」，而不是又一次中段异常。
- 尾段整备要更像「补最后一块板子」，而不是继续发稳定器。

#### 第四轮：最终整备

当前判断：

- 结构上已经对。
- 需要继续控制它的内容分发，不要让它长成「万能救场牌池」。

应该强化的体验：

- 玩家明确知道接下来是最终检定。
- 这一次选择是在补短板或补终局拼图。

#### 第五轮：Boss

当前不需要扩更多 Boss 类型。更需要补的是：

- 各 Boss 更稳定地对位自己的主路线。
- 阶段感和压力切换更明确。
- 结果页能更好解释「我是怎么赢/输的」。

### 关卡体验补强建议

#### 优先级 P0：继续做节点职责清晰化

重点不是更多节点，而是：

- 节点标题更像这拍的体验摘要
- 节点说明更像风险/收益判断
- 节点实际内容更贴标题，而不是只改词

#### 优先级 P1：把第二轮和第三轮差异做大

应该让玩家明确感到：

- 第二轮是在稳定
- 第三轮是在收尾

而不是都读成「继续选点继续打」

#### 优先级 P1：让异常节点继续保有低频记忆点

异常节点要继续承担：

- 改道
- 并轨
- 预读
- 押注
- 低频失真记忆点

不要退回：

- 普通补给
- 普通回血
- 普通数值补丁

## 三、战斗体验还该怎么补

### 当前战斗层判断

当前战斗体系已经有：

- 普通战
- 精英战
- 生存战
- Boss 战

这套分工本身是对的。当前缺的不是新战斗种类，而是让四类战斗的职责更稳定读出来。

### 普通战还该怎么补

当前普通战已经承担主回报链，但还要继续补三件事：

#### 1. 追击感

玩家要更稳定感到：打死这一只后值得继续往那个方向压。

#### 2. 家族人格

四类普通敌要继续保持：

- `standard` 补线
- `brute` 顶线
- `skirmisher` 侧压
- `ranged` 火线

#### 3. 小高潮密度

普通战不该只是稳定。还要继续有：

- `crit` 的短时爆发
- `pierce` 的拆线贯穿
- `dash` 的换位反打

### 精英战还该怎么补

当前精英战仍是最值得继续打磨的一层。

目标不变：让它稳定读成「护卫成屏 -> 裂口 -> 追本体」

当前最需要补的是三件事：

#### 1. 裂口不是逻辑成立，而是玩家真的会追

这意味着要继续保证：

- 裂口清楚
- 护卫真的让位
- 本体真的值得追

#### 2. 路线小高潮要在窗口里打出来

精英窗口里的三条路线应该分别读成：

- `crit`：短时爆发
- `pierce`：拆屏打穿
- `dash`：借裂口换位反打

#### 3. 自然样本也要成立

不能只在 debug 定向样本成立。后续复检要持续看自然 full-flow 是否也能读出来。

### 生存战还该怎么补

当前生存战最该补的是「收尾感」。

应该读成：

- 空档更少
- 路线更纯
- 我在挺住并持续把 build 打出来

不应该读成：

- 单纯更吵
- 单纯更多怪
- 普通战的拉长版

### Boss 战还该怎么补

当前 Boss 不该开新主题，应该继续补「结构收尾」：

- 阶段变化更可读
- 压力模式更明确
- 对位路线更稳定
- 失败也能说明我是输在哪里

当前重点监控：`boss-bastion` 的后段火线阶段

### 战斗体验补强优先级

#### 优先级 P0：继续压普通战回报链

因为这是整局最频繁的体验单位。

#### 优先级 P1：继续压精英裂口打出来

因为这是中段高潮和路线小高潮的关键考场。

#### 优先级 P1：让生存战更像收尾，不像堆怪

因为第三轮的心理坡度决定 Boss 战有没有份量。

#### 优先级 P2：继续守 Boss 监控项，而不是开 Boss 新轮

因为当前主线不在 Boss 扩写，而在核心战斗是否够强。

## 四、属性成长曲线还该怎么补

### 当前成长结构判断

当前成长分层方向是对的：

- 稳定器
- 路线牌
- 桥接牌
- 收尾牌

当前问题不是「没有分层」，而是「分层的体验感还可以更强」。

### 当前成长曲线最需要补的地方

#### 1. 前段要更早给方向，但不能更早锁死

当前前段最应该继续优化的是：

- 提前给玩家方向信号
- 但不要让前段普遍直接成熟

这意味着：

- `starter` 和轻桥接牌要更稳定
- 真正的强收尾牌不能过早发

#### 2. 中段要更明确地从「有倾向」进入「稳定」

这是成长曲线的主缺口。

中段应该发生的不是「数值继续变大」，而是：

- 当前路线的主要打法开始稳定可见
- 改道仍可发生，但代价要更高、频率要更低
- 整备和异常都要围绕「稳定」服务

#### 3. 后段要更偏收尾，而不是继续发稳定器

后段如果还在高频发基础牌，收尾感就会变薄。后段更应该：

- 发高品质路线收尾牌
- 发终局桥接牌
- 发最终整备补强牌

#### 4. 最终整备要补拼图，不要开新方向

最终整备当前最重要的成长职责是：

- 补短板
- 补终局拼图
- 补高辨识度收尾

而不是：

- 再发一轮泛用稳定器
- 再开一条新路线方向

### 三路线成长曲线补强建议

#### `crit`

当前更需要补的是：

- 中段更稳定进入短时爆发
- 后段更明确形成「续热 -> 爆发 -> 收割」

避免问题：

- 前段太早给足爆发
- 中段仍像「有一点暴击，但没完全稳定」

#### `pierce`

当前更需要补的是：

- 中段更稳定形成拆线与贯穿体感
- 后段更稳定形成清线后的继续滚动

避免问题：

- 只在数值上有穿透，体感不稳定
- 只在精英或极端样本里才显著

#### `dash`

当前最需要补的是：

- 中段就让「换位 -> 反打 -> 节奏循环」更可感
- 不要把它做成偏被动生存路线

避免问题：

- 只剩移速和冷却缩短
- 没有明确的实战小高潮

### 当前成长曲线补强原则

#### 原则 1：前段加强方向，不加强完成度

#### 原则 2：中段加强稳定，不加强全面碾压

#### 原则 3：后段加强收尾，不加强平铺稳定器

#### 原则 4：最终整备加强拼图，不加强随机开新路

## 六、本轮最值得优先做的三件事

1. 继续压普通战回报链，让「击杀 -> 掉落 -> 追击 -> 升级 -> 下一拍」更顺。
2. 继续压第二轮精英稳定感，让路线在这里更稳定读成「开始成立了」。
3. 继续压后段收尾和最终整备，让 Boss 更像整局句号，而不是加长战斗。

## 七、当前明确不建议做的事

- 不建议扩更多节点类型。
- 不建议开新地图系统。
- 不建议重写 `RunEngine`。
- 不建议一次性重开 Boss 新主题轮。
- 不建议只靠堆强牌解决成长问题。
- 不建议只靠 UI 说明解决体感问题。

## 八、验收口径

如果这一轮继续按这份方案补强，至少要能回答：

- 前 2 分钟玩家是否更稳定看到方向？
- 第二轮玩家是否更稳定感到「路线开始稳定」？
- 普通战是否更像一拍推一拍，而不是清杂？
- 精英战是否更稳定读成「拆屏 -> 追本体」？
- 后段是否更像收尾，而不是继续拖长？
- 最终整备是否更像补拼图，而不是再开方向？
- `crit / pierce / dash` 是否都没有回退，尤其 `dash` 是否更清楚？

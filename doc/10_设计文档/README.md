# 设计文档

这一层只记录当前有效的设计结论，不做开发流水账。

## 当前真相顺序

1. `完整体验设计方案.md`
   作用：定义项目范围、目标玩家体验、核心循环边界。
   状态：`当前生效 / 总纲`
2. `UI页面固定规则.md`
   作用：锁定开始页、结算页、HUD、选择界面的固定规则。
   状态：`当前生效 / UI最高规则`
3. `视觉与UI设计规范.md`
   作用：定义项目的视觉母方向和敌我识别原则。
   状态：`当前生效 / 方向母稿`
4. `界面线框与落地清单.md`
   作用：把 UI 方向拆到逐屏结构和落地改造点。
   状态：`当前生效 / UI执行稿`
5. `美术资产与画面设计规范.md`
   作用：把美术方向翻译成可执行的画面表达原则与交付边界。
   状态：`当前生效 / 美术执行稿`
6. `美术资产规格表.md`
   作用：定义玩家、敌人、弹道、场地和 UI 图形件的制作规格。
   状态：`当前生效 / 制作规格`
7. `画面与UI验收清单.md`
   作用：统一策划、美术、UI、程序的验收口径。
   状态：`当前生效 / 验收标准`
8. `美术与UI方案_策划对接稿.md`
   作用：给策划或策划 GPT 判断方向是否成立。
   状态：`评审稿 / 对外判断`
9. `核心循环设计.md`
   状态：`当前生效`
10. `核心循环_关卡_战斗_成长补强方案.md`
    状态：`当前生效 / 专项补强稿`

## 推荐阅读顺序

1. 先读 `完整体验设计方案.md`
2. 再读 `UI页面固定规则.md`
3. 再读 `视觉与UI设计规范.md`
4. 再读 `核心循环设计.md` 和 `核心循环_关卡_战斗_成长补强方案.md`
5. 然后按角色进入：
   UI 看 `界面线框与落地清单.md`
   美术看 `美术资产与画面设计规范.md` 和 `美术资产规格表.md`
   评审看 `美术与UI方案_策划对接稿.md`
   联合复检看 `画面与UI验收清单.md`

## 使用规则

- 同类问题发生冲突时，以“UI页面固定规则 -> 方向母稿 -> 执行稿 -> 制作规格 -> 验收标准”的顺序判定。
- 已进入 `../90_历史归档/` 的旧文档只用于追溯，不再作为当前方案依据。
- AI 协作入口在 `../40_AI协作/`，其中美术/UI协作者优先看 `../40_AI协作/美术与UI统一对接文档.md`。

# 画面与UI验收清单

## 文档状态

- 状态：`当前生效 / 验收标准`
- 上游依据：`UI页面固定规则.md`、`界面线框与落地清单.md`
- 使用对象：策划、美术、UI、程序、测试、协作 GPT

## 使用方法

- 这份清单只做一件事：检查页面有没有违反固定规则。
- 任一 `P0` 条目不通过，都视为本轮 UI 不合格。

## P0 开始页

- [ ] 页面为全屏背景，不是黑色大面板首页。
- [ ] 标题居中或上中居中。
- [ ] 主按钮组居中纵向排列。
- [ ] 当前版本只出现真实可用按钮。
- [ ] 没有右侧信息盒。
- [ ] 没有左右分栏黑框结构。

## P0 结算页

- [ ] 结算信息集中在中间区域。
- [ ] 页面底部只有 `返回主界面` 和 `重新开始游戏` 两个主按钮。
- [ ] 没有第三按钮。
- [ ] 没有右侧侧栏。
- [ ] 能直接读到本局路线、等级、战斗数、节点数、本局时长和本局总结。

## P0 战斗 HUD

- [ ] 左上只显示 HP、HP 条、EXP、EXP 条。
- [ ] 玩家头顶有血条。
- [ ] 顶部中间第一行是波次。
- [ ] 顶部中间第二行是关卡玩法。
- [ ] 没有右上目标框。
- [ ] 没有多余路线框或状态框。

## P0 选择界面

- [ ] 顶部只有标题。
- [ ] 标题下方只有 4 个选择框。
- [ ] 选择框是页面主内容。
- [ ] 没有 phase track。
- [ ] 没有 progress summary。
- [ ] 没有额外顶部提示大条。
- [ ] 没有右侧说明栏。

## P1 风格统一

- [ ] 开始页、结算页、选择页都不是黑框黑底方案。
- [ ] 页面看起来像游戏 UI，不像网页产品面板。
- [ ] 按钮有明显主次关系和点击感。
- [ ] 页面结构稳定，不随开发轮次频繁变化。

## 评审结论模板

- 通过：`所有 P0 通过`
- 退回：`写明哪一页违反了哪条固定规则`

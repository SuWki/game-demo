# 肉鸽胡牌爽感专项设计

## 文档状态

- 状态：当前生效
- 适用对象：策划、开发、战斗调优、AI 协作开发
- 文档目标：明确本项目如何从「有路线成型感」推进到「有胡牌爽感、质变感、重开欲望」

---

## 一、当前判断

当前项目已经具备以下基础：

1. 有三条可识别的路线骨架
2. 有成型前、中、后的体验差异
3. 有一定的后期 payoff 和 Boss 收尾目标

但目前还没有稳定做到典型肉鸽游戏的三种强烈体验：

1. 这一把「胡了」
2. 胡了以后明显变简单
3. 没胡打不过，但愿意立刻重开

当前版本更接近：

- 「这把成型了，能打」

而不是：

- 「这把胡了，直接压过去」

---

## 二、本项目想要的目标体验

本项目不是做传统卡牌肉鸽，也不是做纯数值自动战斗。

它要形成的爽感应该是：

1. 开局很快进入构筑判断
2. 中期出现路线身份确认
3. 某些核心牌或组合出现后，玩法发生明显质变
4. 胡牌局在后期明显更轻松，Boss 收尾更短
5. 没胡的局在后期明显吃力，但失败原因清楚，玩家愿意立刻再开

一句话目标：

**玩家要明确感受到「这把普通」「这把成了」「这把胡了」是三种不同体验。**

---

## 三、什么叫「胡牌爽感」

在这个项目里，「胡牌爽感」至少要满足以下五个条件。

### 1. 有明确的核心件

玩家必须能识别：

- 哪张是方向牌
- 哪张是核心牌
- 哪张是毕业牌

不是所有路线牌都同等重要。

必须存在少数牌，拿到后玩家会自然产生：

- 「这把有了」
- 「后面围着它补就行」
- 「这张一来，我这套开始发力」

### 2. 有明显的质变阈值

路线成长不能只是线性变强。

必须存在清晰的阶段差：

1. 预热：只是有方向
2. 成型：开始工作
3. 质变：玩法被改写
4. 毕业：后期压制能力显著上升

如果玩家感受到的只是「越来越强一点」，那不叫胡牌。

### 3. 胡了以后，后期要让权

真正的爽感不是牌描述很强，而是：

- 晚期节点明显更好过
- 普通敌群清得更快
- 高压阶段更容易活
- Boss 更容易收尾

也就是说，胡牌局必须真实改变胜负结构。

### 4. 没胡时，失败要足够清楚

如果玩家失败时的感觉是：

- 「我这把 build 没起来」
- 「差一张关键件」
- 「这局路线上歪了」

那会有健康的重开欲望。

如果失败时的感觉只是：

- 「后面都很挤」
- 「被压死了」
- 「看不懂为什么没打过」

那只会让人疲劳，不会让人想重开。

### 5. 质变要有稳定的视听反馈

胡牌不能只存在于后台数值。

玩家必须在画面和战斗节奏上感受到：

- 清场速度更快
- 特效更有指向性
- 击杀连段更顺
- 节奏进入统治期

---

## 四、当前版本距离目标还差什么

### 1. 核心件不够突出

现在很多路线牌是「稳定补强」，但不是「胡牌核心」。

问题：

- 拿到后能感到更强
- 但不容易感到玩法被改写

开发方向：

- 每条路线明确 2-3 张核心件
- 每条路线明确 1-2 张毕业件
- UI / 文案 / QA 都能识别这些牌

### 2. 成型和胡牌之间没有拉开

当前比较容易出现：

- 玩家已经 matured
- 但只是「能打」
- 还没有进入「统治局」

开发方向：

- 保留 `hinted / committed / matured`
- 但额外设计「开机感」和「毕业感」
- 让成熟 build 中只有一部分能进一步进入高 roll 状态

### 3. 后期节点仍然过度强势

如果晚期所有节点都保持高覆盖高压制，那么高 roll 的回报会被吃掉。

开发方向：

- 胡牌局允许碾过去
- 普通成型局允许艰难过
- 没胡局容易被拦下

现在的问题是，这三层还没有完全分开。

### 4. Boss 收尾窗口还不够像「毕业考试」

理想的 Boss 体验应该是：

- 没胡：明显难
- 成型：可以打
- 胡牌：明显更短、更顺、更稳

如果胡牌局和普通成型局在 Boss 时长上差别不大，说明胡牌感不够。

### 5. 重开动机还不够明确

玩家要愿意重开，必须清楚知道：

- 自己差什么
- 自己为什么没胡
- 下把应该追什么

这需要系统、文案、结果页和节奏同时配合。

## 五、专项设计目标

后续开发请围绕以下目标推进。

### 目标 1：每条路线都有真正的「胡牌核心」

每条路线至少定义：

1. 方向件：前期拿到后确定路线
2. 核心件：使路线真正开始工作
3. 毕业件：让路线进入强势统治期

建议结构：

- 每路线 2 张方向件
- 每路线 2-3 张核心件
- 每路线 1-2 张毕业件

这些牌不一定都要是新牌，也可以从现有牌中重新定义角色。

### 目标 2：路线要出现明确质变瞬间

玩家必须能明确感觉到以下时刻：

- 第一次拿对方向
- 第一次 build 真正启动
- 第一次明显开始碾压

要求：

- 至少有一个节点或一次升级后，玩家会说「这把开机了」
- 至少有一类组合会让玩家说「这把胡了」

### 目标 3：胡牌局应明显改变后期通关结构

胡牌局应该具备：

- 更高的清线效率
- 更短的晚期收尾时间
- 更短的 Boss 时长
- 更稳定的生存空间

不是简单「能扛更久」，而是「能更快结束」。

### 目标 4：没胡局应清楚表现为「上限不够」

没胡局应更容易表现出：

- 清怪慢
- 收尾难
- 关键输出窗利用率低
- 进入 Boss 前资源被消耗过多

但这个失败要可解释，不是纯粹被压死。

### 目标 5：高 roll 要有明确战斗表现层

胡牌局必须有更强的：

- 局内 signature
- 击杀连贯感
- 屏幕压制感
- 结果页回顾价值

## 六、三条路线的胡牌方向

以下是策划层定义，开发可据此继续细化。

### 1. Crit：爆发胡牌

目标感受：

- 锁定目标
- 爆发成串
- 快速点杀
- 收尾非常利落

胡牌表现：

- 核心目标被迅速击破
- 高压精英和 Boss 会明显缩短战斗时长
- 一旦打进窗口，连续爆发成立

设计重点：

- 核心件必须能明显提高「窗口价值」
- 毕业件必须能把「点杀」推进成「连爆」

失败感：

- 没胡时伤害像是够用但不致命
- 玩家会觉得差临门一脚

### 2. Pierce：清线胡牌

目标感受：

- 一条线打穿
- 敌群被快速剥开
- 后排不再安全
- 晚期节点明显更顺

胡牌表现：

- 晚期高压节点的敌群结构会被明显瓦解
- 普通战和收尾战的空间更容易被打开
- 路线成熟后对「群体压力」有压制感

设计重点：

- 核心件必须改变清线结构
- 毕业件必须让穿透和扩散从「能打」变成「统治场面」

失败感：

- 没胡时容易卡在敌群厚度和后排压力

### 3. Dash：节奏胡牌

目标感受：

- 换位
- 反击
- 拉扯
- 活下来并反超节奏

胡牌表现：

- 晚期和 Boss 中能明显打出「躲过去后立刻反打」的节奏
- 高压阶段不再只是求生，而是转为反制
- 成熟 build 能让危险区和输出区的转换变得可控

设计重点：

- 核心件必须让位移和反击真正联动
- 毕业件必须让 Dash 从「生存路线」变成「统治节奏路线」

失败感：

- 没胡时会显得很能活，但很难结束

## 七、如何把「成型」和「胡牌」拆开

后续开发必须区分这两个概念。

### 成型

定义：

- 路线已经工作
- 主要机制已上线
- 能正常过中后期内容

### 胡牌

定义：

- 路线进入明显高 roll
- 关键件和 payoff 形成闭环
- 后期压力被明显改写
- Boss 收尾时长明显缩短

建议内部判断标准：

1. 关键路线牌数达到阈值
2. 至少拥有 1 张核心件
3. 至少拥有 1 张毕业件或 1 组关键联动
4. 晚期节点/Boss 的实际耗时下降明显

## 九、后续开发验收标准

如果要说「这个项目开始有胡牌爽感了」，至少要看到以下现象。

### 1. 玩家能明确区分三种局

- 普通局
- 成型局
- 胡牌局

### 2. 某些局明显更容易通关

- 晚期节点明显更顺
- Boss 更短
- 容错更高
- 玩家会直觉感到「这把稳了」

### 3. 没胡局仍然有挑战，但失败感清楚

- 玩家能说出差什么
- 愿意再开一把赌下一次

### 4. QA 数据能看出分层

应该逐步能观察到：

- 高 roll build 的 Boss 时长显著低于普通成型局
- 高 roll build 的晚期节点通过率更高
- 某些核心件明显提高胜率和通关稳定性

## 十、当前开发优先级建议

围绕「胡牌爽感」主题，后续优先级建议如下：

### P0

1. 明确三路线核心件 / 毕业件
2. 拉开成型和胡牌的差距
3. 让胡牌局明显缩短晚期和 Boss 时长

### P1

1. 结果页和过程提示能说清「这把胡没胡」
2. 让没胡局的失败理由更像「构筑没起来」
3. 继续优化晚期节点对高 roll 的让权

### P2

1. 继续补路线 signature
2. 继续拉开三路线的高 roll 爽感差异
3. 把 QA 观测进一步结构化

---

## 十一、给开发的执行原则

1. 不要把所有路线牌都做成平均价值
2. 必须允许少数牌成为真正 jackpot
3. 胡牌局必须真实改变后期结构
4. 没胡局必须让玩家清楚知道自己差什么
5. 高 roll 不应只是「更能苟」，而应是「更能结束」

---

## 十二、总结

这个项目后面如果想真正接近优秀肉鸽体验，关键不是继续堆更多路线牌，而是：

- 让少数牌真正决定局势
- 让 build 真正发生质变
- 让胡牌局在后期和 Boss 面前明显更强
- 让没胡局失败得合理、清楚、想重开

一句话总结：

**项目下一阶段不只是要「能成型」，而是要开始「能胡」。**

游戏音效设计提示词
游戏背景
这是一款太空射击Roguelike游戏，玩家驾驶战机在压迫性的敌群中战斗。游戏有三条构筑路线：

暴击路线（Crit）：爆发伤害，破绽标记，连锁爆炸
穿透路线（Pierce）：裂纹扩散，穿透射击，连锁反应
冲刺路线（Dash）：高机动，残影攻击，回切反击
游戏节奏紧张，强调压迫感、流畅度和路线特色的音效反馈。

一、战斗核心音效
1. 玩家射击音效
基础射击（shoot）

音色：清脆的能量武器发射声，带轻微电子合成感
特点：短促（0.1-0.15秒），不刺耳，可高频重复
参考：激光脉冲、等离子步枪
音高：中高频（800-1200Hz基频）
暴击射击（crit）

音色：在基础射击上叠加爆裂感和冲击波
特点：更响亮，带金属共鸣尾音
层次：射击音 + 爆破音 + 能量释放音
音高：比基础射击高20-30%
暴击飞溅（critSplash）

音色：范围爆炸，能量扩散
特点：有空间感的扩散效果，带回声
时长：0.3-0.5秒
参考：小型能量爆炸
2. 穿透路线音效
穿透命中（pierceHit）

音色：穿刺感 + 裂纹扩散声
特点：尖锐的穿透音 + 玻璃裂纹般的细碎声
层次：穿刺瞬间 + 裂纹扩散（0.2秒延迟）
音高：高频穿刺（1500-2000Hz）+ 中频裂纹
穿透回响（pierceEcho）

音色：裂纹连锁反应，能量共振
特点：多层回声，逐渐衰减
时长：0.5-0.8秒
空间感：立体声扩散效果
3. 冲刺路线音效
冲刺启动（dash）

音色：能量充能 + 瞬移音效
特点：快速上升音调（whoosh）+ 空间扭曲感
时长：0.2-0.3秒
参考：科幻瞬移、时空跳跃
冲刺脉冲伤害（dashPulse）

音色：冲击波扩散，低频震动
特点：有力的低频冲击（200-400Hz）
层次：冲击瞬间 + 能量波纹扩散
时长：0.3-0.4秒
冲刺命中（dashHit）

音色：高速撞击 + 能量爆发
特点：结合物理冲击和能量释放
音高：中低频冲击 + 高频能量音
4. 通用战斗音效
普通命中（hit）

音色：能量武器击中装甲
特点：金属质感，短促有力
时长：0.1-0.15秒
击杀（kill）

音色：敌机爆炸，能量消散
特点：满足感强，带能量释放尾音
层次：爆炸主音 + 碎片散落 + 能量消散
时长：0.5-0.7秒
受伤（hurt）

音色：护盾受损，警报感
特点：刺耳但不过分，带紧迫感
音高：中高频，带失真效果
经验拾取（pickup）

音色：能量吸收，正向反馈
特点：轻快，音调上升
时长：0.15-0.2秒
参考：收集音效，带共鸣
二、敌人音效
1. 敌人射击
敌人射击（enemyShot）

音色：与玩家射击区分，更沉闷
特点：带威胁感，音调略低
音高：比玩家射击低30-40%
擦弹（nearMiss）

音色：子弹掠过，空气撕裂
特点：快速的whoosh音，带方向感
时长：0.1-0.15秒
空间感：立体声定位
2. 敌人生成音效
普通敌人生成（relayStandard）

音色：传送门打开，能量涌现
特点：中性，不过分突出
时长：0.3-0.4秒
高速敌人生成（relaySkirmisher）

音色：快速闪现，高频能量
特点：音调更高，更急促
时长：0.2-0.3秒
重型敌人生成（relayBrute）

音色：沉重的传送，低频震动
特点：有重量感，低频突出
时长：0.4-0.5秒
远程敌人生成（relayRanged）

音色：能量充能，带电子音
特点：中高频，带充能感
时长：0.3-0.4秒
3. 精英/Boss音效
压迫脉冲（pressure）

音色：低频震动，空间压迫感
特点：持续的低频（80-150Hz），带心跳感
时长：0.5-0.8秒
用途：精英/Boss阶段转换，压迫氛围
三、UI音效
1. 菜单交互
点击（click）

音色：轻快的机械按键音
特点：清脆，反馈明确
时长：0.05-0.08秒
确认（confirm）

音色：正向确认，带能量感
特点：比点击更饱满，音调上升
时长：0.15-0.2秒
2. 游戏流程
开始游戏（start）

音色：引擎启动，系统激活
特点：有仪式感，带能量充能过程
时长：0.8-1.2秒
层次：启动音 + 引擎运转 + 系统就绪
升级（upgrade）

音色：能力强化，系统升级
特点：正向反馈，带科技感
时长：0.5-0.7秒
参考：装备强化音效
异常事件（anomaly）

音色：神秘，不确定性
特点：带失真和电子干扰感
时长：0.6-0.9秒
音调：不稳定，带颤音
Boss出现（boss）

音色：威胁警报，重型单位接近
特点：低频震动 + 警报音
时长：1.5-2秒
层次：警报 + 低频震动 + 能量场展开
3. 战斗结果
胜利（victory）

音色：凯旋，正向高潮
特点：明亮，音调上升，带和弦
时长：1.5-2秒
情绪：成就感，满足感
失败（defeat）

音色：系统崩溃，能量耗尽
特点：音调下降，带失真和衰减
时长：1.5-2秒
情绪：遗憾但不沮丧
结算（result）

音色：数据统计，系统分析
特点：中性，带科技感
时长：0.5-0.7秒
四、环境音效层
1. 战斗环境音（循环）
普通战斗

底层：低频引擎嗡鸣（60-100Hz）
中层：能量场脉动
高层：远处战斗声，空间感
精英战

在普通战斗基础上增加：
低频压迫感更强
能量场更不稳定
带紧张感的电子音层
Boss战

最强的压迫感
多层低频震动
能量场高度不稳定
带史诗感的音乐性元素
2. 生存模式环境音
更快的节奏脉冲
更密集的能量波动
带倒计时紧迫感
五、音效设计原则
1. 音频分层
低频层（20-200Hz）：压迫感，重量感，Boss威胁
中频层（200-2000Hz）：主要游戏音效，战斗反馈
高频层（2000-8000Hz）：细节，暴击，特殊效果
2. 频率避让
玩家射击：中高频（800-1200Hz）
敌人射击：中频（500-800Hz）
爆炸/冲击：中低频（200-600Hz）
环境音：低频（60-200Hz）
3. 动态混音
战斗激烈时：压缩环境音，突出战斗音效
精英/Boss出现：提升低频，增强压迫感
玩家受伤：短暂降低其他音效，突出受伤音
4. 路线音效特色
暴击路线：爆裂感，高频，金属共鸣
穿透路线：穿刺感，裂纹声，回响
冲刺路线：空间感，低频冲击，whoosh
5. 反馈清晰度
所有核心音效时长 < 0.5秒
可高频重复的音效 < 0.2秒
避免音效堆叠造成混浊
重要音效（受伤、击杀）优先级最高
六、技术规格建议
采样率：44.1kHz 或 48kHz
位深度：16-bit（移动端）或 24-bit（PC）
格式：OGG（循环音效）、WAV（短音效）
音量标准化：-6dB 到 -3dB 峰值
循环音效：无缝循环，淡入淡出处理
空间音效：支持立体声定位（擦弹、敌人生成）
七、参考风格
整体风格：科幻太空，电子合成，能量武器

《Vampire Survivors》：清晰的反馈音效
《Enter the Gungeon》：射击手感
《Risk of Rain 2》：路线构筑反馈
《Hades》：打击感和流畅度

合成器：能量武器，科技感
物理音效：金属撞击，爆炸
空间音效：回声，混响，空间感

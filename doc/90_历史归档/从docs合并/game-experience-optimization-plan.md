### 🟡 P1 - 操作手感优化（高优先级）

#### 3. 输入响应性优化 ✅

**目标**: 让操作更流畅，减少"按了没反应"的情况

**当前问题**:
- 快速切换方向键时，手指离开旧键到按下新键之间有短暂间隔
- 这期间角色会停止移动，感觉"卡顿"

**优化方案**:

**输入缓冲系统（150ms窗口）**
```typescript
// 按键松开后150ms内仍视为按下
private inputBufferMs = { up: 0, down: 0, left: 0, right: 0 };
private readonly INPUT_BUFFER_WINDOW_MS = 150;

// 获取缓冲后的输入状态
private getBufferedInputState(): PlayerInputState {
  const isBuffered = (lastPressMs: number) => 
    now - lastPressMs < this.INPUT_BUFFER_WINDOW_MS;
  return {
    up: this.inputState.up || isBuffered(this.inputBufferMs.up),
    // ...
  };
}
```

**作用**:
- 快速变向时（如左→右），松开左键后150ms内仍视为向左移动
- 给手指足够时间按下右键，避免中间停顿
- 让蛇形移动、快速转向更流畅

**修改文件**:
- `src/systems/RunEngine.ts` - 添加输入缓冲逻辑

**验收标准**:
- [x] 快速切换方向键时无卡顿感
- [x] 蛇形移动流畅自然
- [x] 操作响应性明显提升

**实际工作量**: 0.5天
**完成日期**: 2026-05-08

**任务B: 音量平衡**

1. 射击音效不能太吵（高频重复）
2. 受伤音效要突出（重要反馈）
3. UI音效要轻柔（不干扰游戏）
4. 背景音乐不能盖过音效

**建议音量比例**:
```
背景音乐: 0.6
射击音效: 0.4
受伤音效: 0.8
击杀音效: 0.7
UI音效: 0.5
特殊事件: 0.9
```

**实现要点**:
- 逐个检查音效是否存在
- 缺失的音效使用PilotAudio生成或临时占位
- 调整各类音效的音量比例
- 测试长时间游玩是否刺耳

**修改文件**:
- `src/systems/PilotAudio.ts` - 音效生成和播放
- `src/systems/RunEngine.ts` - 音效触发点
- `src/scenes/GameScene.ts` - UI音效

**验收标准**:

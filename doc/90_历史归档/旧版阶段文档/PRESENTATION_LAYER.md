# 表现层收束说明

## 当前阶段判断
现在适合：
- 表现层主推进
- 核心循环轻收尾

不适合：
- 重做 UI
- 大改页面结构
- 重开大规模循环调优

## 当前最高收益项
1. 模板进入提示
2. 模板阶段变化提示
3. 关键阶段提示
4. 读法提示
5. 成型提示 / 路线站稳提示
6. 收尾段提示

## 截至 2026-04-02 的最小收口重点
- 开始页补到同一套产品壳：保留短局入口，同时补齐操控、单局和目标三块读法说明
- 局内 HUD 收成两层：顶部给当前读数，右侧给路线读数，避免继续像测试期监控面板
- 提示继续沿用 `neutral / accent / route / danger / success`，但要让模板进入、路线站稳、路线成型和收尾在观感上真的分层
- 战场内去掉最像调试占位的玩家大面积发光圈，改成更轻的聚焦光感和路线色边框
- 音效只做最小层级整理，不重做完整音频系统

## 当前不做的事
- 不重开页面结构
- 不把 CSS 收口扩大成正式商业包装
- 不借表现层收口回去改主流程或 `RunEngine`
- 不做全量资源替换

## 体感收益排序
### 平均收益最高
- 模板进入提示
- 阶段变化提示
- 关键阶段提示
- 读法提示

### 单次记忆点更强
- 方向成型
- 路线站稳

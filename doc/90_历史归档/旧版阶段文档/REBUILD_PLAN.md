# 重建任务清单（给 Codex）

## 目标
基于这些文档，重建一个能运行的 Web 节点式自动射击 demo，并优先恢复：
- 核心循环
- 三条流派
- 三类节点
- 三类战斗模板
- 关键表现层提示
- 最低限度音效
- 基础埋点导出

## 建议重建顺序
### Phase 1：搭基础壳
- 开始页
- GameScene
- 结算页
- 基础 HUD
- 节点推进骨架

### Phase 2：恢复核心循环
- battle / upgrade / event
- 歼灭 / 精英 / 生存 模板
- 基础敌人与自动攻击
- 升级三选一

### Phase 3：恢复三条流派
- 暴击流
- 穿透流
- 穿梭流
- 前提过滤与软倾向
- 三选一结构健康约束

### Phase 4：恢复表现层
- 模板进入提示
- 阶段变化提示
- 关键段提示
- 读法提示
- 成型提示
- 收尾提示

### Phase 5：恢复商业化测试底座
- 最低限度音效触发
- 基础埋点
- 导出接口

### Phase 6：封版检查
- 自然整局回归
- route_committed / route_matured 自然触发验证
- 录屏 / GIF 准备

## 当前重建原则
- 先恢复可继续开发，不追求一次性完全还原
- 先恢复结构，不先纠结旧细节参数
- 先恢复主流程，不先恢复边角表现
- 严禁重建成无关新项目

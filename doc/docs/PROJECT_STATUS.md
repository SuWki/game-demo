# 项目当前状态

## 项目定位
这是一个 Web 端的极简自动战斗 Roguelite / 自动射击 demo。

### 当前一句话定位（对外版）
一个能在短局里快速读懂节奏、走出三条不同 build 路线的节点式自动射击 demo。

### 当前一句话定位（内部版）
一款以短局节点推进为骨架、围绕暴击 / 穿透 / 穿梭三条路线分化的俯视角自动射击原型，当前重点是验证短局循环是否足够清楚、顺手、可复玩。

## 当前最大风险
- 当前前中期的方向感已经更清楚，但如果 `starter -> committed` 再次提速过头，会重新压缩中途转向和混搭空间
- 若桥接内容不够、强承诺内容又回到中段前半过密，replay 会从“路线清楚”退化成“路线过早写死”
- payoff 虽然应当后移，但如果后移后中段没有足够的 bridge 支撑，会出现“方向已见、成型偏晚”的空档
- 埋点虽然已能记录首个强承诺与转向次数，但样本仍需继续观察，尤其是三条路线的真实分布差异
- 中文乱码与内部设计话术重新泄露到玩家可见文本

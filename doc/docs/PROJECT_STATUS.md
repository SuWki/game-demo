# 项目当前状态

## 项目定位
这是一个 Web 端的极简自动战斗 Roguelite / 自动射击 demo。

### 当前一句话定位（对外版）
一个能在短局里快速读懂节奏、走出三条不同 build 路线的节点式自动射击 demo。

### 当前一句话定位（内部版）
一款以短局节点推进为骨架、围绕暴击 / 穿透 / 穿梭三条路线分化的俯视角自动射击原型，当前重点是验证短局循环是否足够清楚、顺手、可复玩。

## 当前最大风险
- 当前 replay 动机仍容易过度依赖三流派本身，而不是依赖“这局撞上了一个低频记忆点”
- 若后续继续只补 route-specific 常规内容，而不持续维护 rare / hybrid / payoff 的阶段边界，payoff 仍可能重新回渗到 mid
- 转向埋点虽然已经可用，但真实样本仍偏少，说明可转向窗口还需要继续观察是否足够显眼、足够有吸引力
- 稀有内容如果只是普通内容换皮，或出现频率没有真的拉低，会把 replay 动机重新稀释回普通分发
- 中文乱码与内部设计话术重新泄露到玩家可见文本

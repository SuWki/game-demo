# SHOWCASE PREP

## 当前版本一句话定位
- 一款以短局节点推进为骨架、围绕三条主要流派分化展开的俯视角自动战斗构筑 demo。

## 展示时最值得突出的 3 个卖点
1. 短局节点结构清晰
2. 三条主要流派已经成立
3. 节奏与读局提示已经形成闭环

## 录屏 / GIF 建议路径
1. 开始页
2. 前段进入方向
3. 中段成型
4. 关键段提示
5. 后段收尾
6. 结算

## 作品说明时可用的表达重点
- 这是一个围绕短局节奏和 build 分化持续收束的 demo，不是单条数值成长展示。
- 设计重点不只是补内容，而是把“玩家什么时候看懂这一局在发生什么”做成体验的一部分。

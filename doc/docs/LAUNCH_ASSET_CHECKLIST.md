# 测试版发布资产清单

## 测试版发布资产
- 可运行的 Web 构建版本
- 当前版本一句话定位
- 玩法说明短文
- 录屏或 GIF
- 外部测试计划
- 埋点规格说明

## 最低限度音效
- 开始按钮点击
- 面板按钮点击
- 升级选择
- 命中
- 暴击
- 高压 / 关键段进入
- 结算

## 最低限度视觉统一项
- 开始页、战斗内、结算页整体风格不割裂
- 关键提示文案长度统一
- 关键提示层级统一
- 不向玩家暴露调试 / 设计内部话术
- 录屏时无明显字体缺失、报错弹层或风格断裂

## 平台准备项
- 确认页面可在常见桌面浏览器打开
- 确认音频自动解锁逻辑正常
- 确认埋点可从浏览器本地导出
- 确认测试包说明文档齐全
- 确认结算与再开一局流程可用

# 核心循环说明

## 单局核心循环
开始页 -> 进入一局 -> battle / upgrade / event 节点推进 -> 战斗内击杀掉经验 / 拾取经验 -> 升级三选一 -> 逐步建立流派 -> 中段成型 -> 后段收尾 -> 结算 -> 重开

## 当前输入口径
- 战斗内使用 `WASD` 或方向键移动
- 攻击保持自动射击
- 穿梭流的价值建立在手动换位、擦身与吃经验路径规划上，不再依赖自动摆动

## 单局目标时长
建议先冻结在 8~12 分钟一局的短局版本。

## 单局体验目标
- 前 30 秒能理解玩法
- 前 2 分钟能看出方向
- 中段能明确感知 build 成型
- 后段有收尾感
- 首局失败后愿意立刻再来一局

## 当前已成立的体验层级
### build 进入点
已经阶段性收口。
目标状态：
- 前段可以出现明显流派倾向
- 但不应在 battle1 level-up2 普遍锁死方向
- 玩家会觉得“可能在往这条线走”，但不是“已经没悬念了”

### 成型点
已经明显松开。
当前分布：
- 暴击流：battle1 后半到 battle2 开段
- 穿透流：主要落在 battle2
- 穿梭流：battle2 为主，但分布更散，可落到 battle1/2/3 甚至 battle4

### 模板切换点
已无明显固定骨架，只剩轻度家族吸附。

## 当前结论
- 核心循环当前不是主开发矛盾
- 但数值与升级链现在已经切到“战斗内经验升级 + 节点整备补强”的口径
- 后续调整应优先基于公式和战斗读数，而不是再回到纯骨架近似

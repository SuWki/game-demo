# 文档维护规则

## 当前文档分工

- `00_接手入口`
  当前真相入口
- `10_设计文档`
  当前有效设计
- `20_设计闭环`
  设计目标、验证方式、风险和阶段标准
- `30_持续优化`
  流程、验证、复盘和待办
- `40_AI协作`
  AI 接手协议和提示词模板
- `90_历史归档`
  旧阶段文档和历史记录

## 必须同步更新的场景

### 场景 1：本轮目标或风险变化

必须更新：

- `../00_接手入口/当前交接卡.md`
- `../20_设计闭环/风险与设计决策.md`

### 场景 2：设计边界变化

必须更新：

- 对应的 `../10_设计文档/*`
- `../20_设计闭环/设计基线与约束.md`

### 场景 3：阶段判断变化

必须更新：

- `../00_接手入口/当前交接卡.md`
- `../20_设计闭环/版本目标与验收标准.md`

### 场景 4：每次开发结束

必须新增：

- `开发复盘/` 下的新文档

## 不再作为当前事实源的文件

- `progress.md`
- `output/`
- `tools/`
- `../90_历史归档/旧版阶段文档/*`

这些文件仍可用于追溯，但不能替代当前真相文档。

### 1.2 缺失的反馈系统

#### ❌ 击中特效（高优先级）
**当前状态**: 
- 只有程序绘制的圆圈和线条
- 没有独立的击中粒子/爆炸效果
- 击中反馈主要依赖 `hitCount` 数值累加

**影响**:
- 击中敌人的满足感不足
- 难以区分普通击中和暴击击中
- 穿透击中的视觉反馈不够明显

#### ❌ 弹道特效增强（中优先级）
**当前状态**:
- 弹道有基础轨迹线（第2323-2339行）
- 根据路线有颜色区分
- 有SVG素材但特效层次单一

**影响**:
- 弹幕密度高时难以追踪自己的子弹
- 路线特色不够突出
- 缺少"弹幕游戏"的华丽感

#### ❌ 屏幕特效（低优先级）
**当前状态**:
- 没有屏幕闪光
- 没有色差/扭曲效果
- 没有慢动作/时间停止

**影响**:
- 关键时刻（击杀Boss、濒死）缺少仪式感
- 战斗节奏单一

## 二、改善建议（按优先级排序）

### 🔴 P0 - 击中特效系统

#### 2.1.1 基础击中特效

**目标**: 让每次击中都有明确的视觉反馈

**实现方案**:
```typescript
// 在 RunEngine.ts 中添加击中特效生成
interface HitEffect {
  id: number;
  x: number;
  y: number;
  type: 'normal' | 'crit' | 'pierce' | 'dash';
  lifeSec: number;
  maxLifeSec: number;
  scale: number;
}

// 击中时生成特效
private spawnHitEffect(x: number, y: number, type: HitEffect['type']): void {
  const effect: HitEffect = {
    id: this.nextHitEffectId++,
    x, y, type,
    lifeSec: 0.3, // 300ms生命周期
    maxLifeSec: 0.3,
    scale: 1.0,
  };
  this.state.battle.hitEffects.push(effect);
}
```

**视觉表现**:
- **普通击中**: 白色小爆闪（半径8-12px）
- **暴击击中**: 橙色大爆闪 + 十字光芒（半径16-24px）
- **穿透击中**: 蓝色裂纹扩散（半径12-18px）
- **冲刺击中**: 绿色涟漪波纹（半径14-20px）

**素材需求**:
- `fx-hit-normal.svg` - 普通击中
- `fx-hit-crit.svg` - 暴击击中
- `fx-hit-pierce.svg` - 穿透击中
- `fx-hit-dash.svg` - 冲刺击中

**代码位置**:
- 添加到 `src/game/types.ts` 的 `BattleState`
- 在 `RunEngine.ts` 第4029行（bullet.hitCount += 1）后调用
- 在 `GameScene.ts` 第2400行后添加渲染逻辑

## 六、性能优化建议

### 6.1 粒子池

```typescript
class ParticlePool<T> {
  private pool: T[] = [];
  private active: T[] = [];
  private maxSize: number;

  constructor(maxSize: number, factory: () => T) {
    this.maxSize = maxSize;
    for (let i = 0; i < maxSize; i++) {
      this.pool.push(factory());
    }
  }

  spawn(): T | null {
    if (this.pool.length === 0) return null;
    const particle = this.pool.pop()!;
    this.active.push(particle);
    return particle;
  }

  recycle(particle: T): void {
    const index = this.active.indexOf(particle);
    if (index >= 0) {
      this.active.splice(index, 1);
      this.pool.push(particle);
    }
  }
}
```

---

### 6.2 渲染优化

- **视锥剔除**: 只渲染屏幕内的特效
- **LOD**: 远处的特效使用简化版本
- **批量渲染**: 相同类型的特效合批渲染
- **帧率限制**: 特效更新频率可低于游戏帧率

---

### 6.3 内存管理

- **特效上限**: 
  - 击中特效: 最多50个
  - 爆炸特效: 最多20个
  - 尾迹粒子: 最多200个
- **自动清理**: 超出上限时清理最老的特效
- **生命周期**: 所有特效都有明确的生命周期

## 九、总结

### 核心改善点

1. **击中特效** - 最重要，直接影响战斗手感
2. **弹道特效** - 提升视觉华丽度和可读性
3. **镜头反馈** - 增强打击感和节奏感
4. **屏幕特效** - 锦上添花，可选实现

### 预期效果

实现P0和P1后，游戏将获得：
- ✅ 明确的击中反馈
- ✅ 华丽的弹道表现
- ✅ 强烈的打击感
- ✅ 清晰的路线特色
- ✅ 更好的战斗节奏

### 开发建议

1. **先做P0**: 击中特效是基础，优先实现
2. **再做P1**: 弹道和镜头增强性价比高
3. **P2可选**: 屏幕特效根据时间和需求决定
4. **迭代优化**: 先实现基础版本，再根据反馈调整

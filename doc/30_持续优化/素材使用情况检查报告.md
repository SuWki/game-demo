## 四、素材替换优先级建议

### 🔴 高优先级（影响游戏可读性）

1. **敌人类型素材** - 3个缺失类型
   - `brute` (厚血慢速大体型怪)
   - `skirmisher` (高速脆皮怪)
   - `ranged` (远程怪)
   - **原因**: 当前只能通过形状区分，玩家难以快速识别

2. **Boss类型素材** - 2个缺失Boss
   - 当前只有 `boss-bastion` 有素材
   - 代码中提到 `boss-hunt` 和 `boss-lockdown` 但无素材
   - **原因**: Boss战是核心玩法，需要独特视觉表现

### 🟡 中优先级（提升游戏品质）

3. **UI图标系统**
   - 路线标识图标（暴击/穿透/冲刺）
   - 稀有度边框
   - 状态图标

4. **地图背景素材**
   - 战斗场景背景
   - 地形瓦片纹理
   - 环境装饰元素

5. **特效素材**
   - 爆炸/击中特效
   - 升级/路线激活特效
   - 技能特效（暴击/穿透/冲刺）

### 🟢 低优先级（锦上添花）

6. **开始/结束页面**
   - 游戏Logo

7. **装饰性元素**

### 5.2 素材渲染方式

游戏使用混合渲染策略:
1. **SVG素材** - 通过 `renderRuntimePreviewImage()` 方法渲染（8处调用）
2. **程序绘制** - 通过 Phaser Graphics API 绘制几何图形
3. **CSS样式** - UI界面使用CSS渲染

**素材可见性控制**:
```typescript
// 用户可通过localStorage关闭素材预览
this.runtimeVisualPreviewEnabled = 
  window.localStorage.getItem(RUNTIME_VISUAL_PREVIEW_STORAGE_KEY) !== 'off';
```

### 5.3 颜色系统架构

- **CSS变量** (`src/style.css`): UI主题颜色
- **TypeScript常量**: 游戏内实体颜色
- **动态计算**: 状态相关的颜色混合

## 六、建议的素材规格

### 6.1 敌人素材规格
- **格式**: SVG（矢量图，便于缩放）
- **尺寸**: 128x128 或 256x256
- **风格**: 与现有 `enemy-standard-a.svg` 保持一致
- **需要**: 4个方向或可旋转的单一朝向

### 6.2 UI素材规格
- **格式**: SVG 或 PNG（带透明通道）
- **尺寸**: 根据用途（图标32-64px，面板背景更大）
- **风格**: 科幻/太空主题，与当前CSS主题色协调

### 6.3 特效素材规格
- **格式**: 精灵图序列帧 或 SVG动画
- **尺寸**: 64-256px（根据特效类型）
- **帧数**: 4-12帧（如需动画）

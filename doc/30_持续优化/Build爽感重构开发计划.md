### P0-2 高风险高收益异常节点

**目标**
新增3-4个高风险异常节点，制造"赌局感"。

**设计草稿**

#### 1. 玻璃大炮协议
- **风险**: 生命上限-50%
- **收益**: 伤害+100%，暴击必定触发AOE
- **效果**: 让暴击流玩家有机会"赌一局"

#### 2. 狂战士协议
- **风险**: 无法回血，每秒流失1%生命
- **收益**: 伤害随生命降低而增加（最多+150%）
- **效果**: 高风险高回报的玻璃大炮

#### 3. 过载协议
- **风险**: 攻速-50%
- **收益**: 每次攻击发射3发子弹
- **效果**: 改变射击模式

#### 4. 诅咒标记
- **风险**: 敌人死亡后生成诅咒区域
- **收益**: 击杀后立即重置所有技能冷却
- **效果**: 鼓励激进玩法

  - [x] 狂战士协议：无法回血，伤害随生命降低而增加（最高+150%）
  - [x] 过载协议：攻速-50%，每次攻击发射3发子弹
  - [x] 诅咒标记：击杀重置技能冷却，敌人死亡生成诅咒区域
- [x] 平衡风险收益数值

## P2 任务：交叉联动物理化 + 胡局机制

### P2-1 Crit × Pierce 联动

**目标**
让暴击和穿透产生实际联动效果。

**设计**
- **爆点裂纹**: 暴击爆点在地面留下裂纹
- **裂纹穿透**: 穿透裂纹中的敌人时伤害+50%
- **连锁反应**: 暴击击杀后裂纹向周围扩散

**实现**
- 修改 `createCrackMark` 生成裂纹
- 新增 `isEnemyOnCrack` 检查敌人是否在裂纹上
- 新增 `spreadCracksOnCritKill` 实现裂纹扩散

**进度**
- [x] 爆点生成裂纹
- [x] 裂纹增伤逻辑
- [x] 裂纹扩散效果

---

### P2-2 Dash × Crit 联动

**目标**
穿梭后下一次暴击触发AOE。

**设计**
- **相位暴击**: Dash后3秒内下一次暴击范围+100%
- **残影爆点**: 残影也会触发小型爆点

**实现**
- 在 `BattleState` 新增 `dashCritWindowSec` 状态
- 修改 `triggerCritExplosion` 支持范围扩展
- Dash时触发残影爆点

**进度**
- [x] Dash暴击窗口状态
- [x] 暴击范围扩展
- [x] 残影爆点

### P2-3 胡局机制（超模Build）

**目标**
让玩家有机会"胡"，进入超模状态。

**设计1: 无限裂界**
- 条件: Pierce流拿到3张payoff牌后触发
- 效果: 子弹无限穿透，每次穿透分裂成2发
- 限制: 持续10秒，冷却60秒

**设计2: 临界超频**
- 条件: Crit流连续暴击5次后触发
- 效果: 进入5秒超频，攻速+100%，暴击触发连锁爆炸
- 视觉: 屏幕橙色滤镜，子弹发红

**设计3: 相位超载**
- 条件: Dash流连续穿梭3次后触发
- 效果: 残影数量翻倍，脉冲自动连锁
- 视觉: 绿色速度线，残影拉丝

**实现**
- 在 `BattleState` 新增 `overdriveMode` 状态
- 新增 `checkOverdriveTriggers` 检测触发条件
- 新增 `triggerOverdrive` 和 `updateOverdriveMode`
- 射击/穿透/Dash逻辑检查overdrive状态

**进度**
- [x] 无限裂界逻辑
- [x] 临界超频逻辑
- [x] 相位超载逻辑
- [x] Overdrive视觉反馈

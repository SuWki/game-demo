# 绞锁压制(elite-vice)关卡难度问题分析与解决方案

## 问题描述
玩家反馈"拖场绞锁"关卡中：
1. 精英关太难打，正常选取强化根本打不过
2. 护卫越打越多
3. 小怪弹幕密集

## 代码分析

### 关卡配置 (src/data/battleTemplates.ts:205-268)
```typescript
'elite-vice': {
  id: 'elite-vice',
  name: '绞锁压制',
  description: '精英会召唤援军',
```

### 关键问题

#### 1. 护卫生成过于频繁
- 基础间隔: `escortRespawnSec: 3.4`秒
- 压力阶段后: `3.4 * 0.74 = 2.5`秒
- 每次生成: `escortBatch: 2`个
- 压力阶段后: `2 + 1 = 3`个
- 上限: `escortMax: 10`个
- 压力阶段后: `10 + 2 = 12`个

**计算**: 在64%血量后，每2.5秒生成3个护卫，最多12个护卫在场

#### 2. 远程怪比例过高
```typescript
escortArchetypes: {
  standard: 0.7,
  brute: 0.45,
  skirmisher: 1,
  ranged: 2.2,    // 远程怪权重最高！
}
```
- 远程怪(ranged)权重2.2，是标准怪(0.7)的3倍多
- 导致大部分护卫是远程怪，会发射弹幕

#### 3. 小怪上限过高
- `regularEnemyCap: 20` - 小怪最多20个
- 加上护卫最多12个
- 场上最多同时存在32个敌人

#### 4. 护卫弹幕密集
```typescript
// src/systems/RunEngine.ts:4116
escort.rangedCooldownSec = 0.22 + index * 0.08;
```
- 护卫ranged射击间隔最短0.22秒
- 多个护卫同时射击形成密集弹幕

#### 5. 精英行为问题
- `behavior: 'summoner'` - 召唤者行为
- `preferredDistance: 200` - 精英会躲在护卫后面200距离
- 玩家难以直接攻击精英，必须先清理护卫

## 我的解决方案

### 方案1: 降低护卫生成频率和上限
```typescript
// battleTemplates.ts 修改
eliteRule: {
  escortBatch: 2 → 1,           // 每次生成1个
  escortRespawnSec: 3.4 → 5.0, // 间隔延长到5秒
  escortMax: 10 → 6,            // 上限降到6个
  pressurePhases: {
    escortBatchBonus: 1 → 0,    // 压力阶段不再额外增加
    escortMaxBonus: 2 → 1,      // 上限只+1
    escortRespawnMultiplier: 0.74 → 0.85, // 间隔缩短幅度减小
  }
}
```

### 方案2: 调整护卫类型分布
```typescript
// battleTemplates.ts 修改
escortArchetypes: {
  standard: 0.7 → 2.0,   // 增加普通怪，作为肉盾
  brute: 0.45 → 0.8,     // 增加厚血怪
  skirmisher: 1 → 0.6,   // 减少高速怪
  ranged: 2.2 → 0.8,     // 大幅减少远程怪
}
```

### 方案3: 降低小怪上限
```typescript
// battleTemplates.ts 修改
regularEnemyCap: 20 → 12,  // 小怪上限降低
eliteRule.regularEnemyCap: 20 → 14, // 精英出现时小怪上限
```

### 方案4: 延长护卫射击间隔
```typescript
// RunEngine.ts:4116 修改
if (escort.archetype === 'ranged' && activeBehavior === 'summoner') {
  escort.rangedCooldownSec = 0.22 + index * 0.08 → 0.45 + index * 0.12;
  // 基础间隔从0.22延长到0.45秒
}
```

### 方案5: 增加召唤前置条件
```typescript
// RunEngine.ts 修改护卫生成逻辑

  if (currentEscorts >= 3) {
    return; // 场上已有3个护卫，不再生成
  }
  // ...原逻辑
}
```

## 推荐组合方案

**主方案**: 方案1 + 方案2 + 方案3
- 护卫生成频率降低，上限减少
- 远程怪比例降低，弹幕压力减小
- 小怪总数减少，战场更清晰

**备选**: 如果仍困难，实施方案4延长射击间隔

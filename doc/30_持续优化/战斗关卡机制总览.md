## 七、通用机制术语表

| 术语 | 说明 |
|------|------|
| **behavior** | 精英行为：frontline（正面）、screened（护卫遮线）、kiting（反拉）、summoner（召援） |
| **signature** | 阶段签名：阶段开始时显示的提示文字和特效 |
| **pattern** | 压力模式：laneCrush（车道压制）、sideClamp（侧翼夹封）、crossfireWave（交叉火线） |
| **safeWindow** | 安全区：玩家可躲避伤害的区域，可能移动或变化 |
| **pocketShift** | 安全区移动：sweep（横切）、centerReset（回心）、edgeBounce（压边） |
| **volley** | 齐射：同时发射多发子弹 |
| **guardSec** | 护盾时间：期间受到的伤害降低 |
| **escortBatch** | 每次生成的护卫数量 |
| **escortMax** | 场上最大护卫数量 |
| **escortRespawnSec** | 护卫生成间隔 |
| **triggerHpRatio** | 压力阶段触发血量比例 |

## 九、优化方向建议

### 1. 护卫生成过频/过多问题
- elite-screen、elite-bulwark、elite-lockdown、boss-fortress、elite-contagion
- **建议**：参考elite-vice的重构方案，引入"护卫-Boss链接"+"脆弱窗口"机制

### 2. 远程怪过多导致弹幕过密
- elite-screen（ranged:2.7）、survival-crossfire（ranged:3.1）
- **建议**：降低远程怪权重，或增加近战怪作为"肉盾"

### 3. 护盾时间过长拖节奏
- elite-pressure-hold（guardSec:5.5）
- **建议**：缩短护盾时间，或增加护盾期间的其他机制（如弱点暴露）

### 4. 缺少机制深度
- 基础歼灭关卡、生存关卡机制较单一
- **建议**：引入简单的环境机制或敌人类型轮换

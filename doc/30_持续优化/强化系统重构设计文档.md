# 强化系统重构设计文档

> 创建日期：2026-05-27
> 目标：建立"Build逐渐启动→运转→爆发→超模"的成长体验

---

## 一、核心问题分析

当前系统已有 `starter`, `bridge`, `payoff`, `finisher` 标签，但存在以下问题：

1. **分层不清晰**：`bridge` 和 `payoff` 界限模糊
2. **阶段控制弱**：前期可能出后期牌，后期可能不出关键牌
3. **Build定向弱**：玩家难以"做Build"，随机性过强
4. **反馈缺失**：玩家不知道何时"成型"
5. **普通强化过多**：28个普通强化，大量重复/小数值

---

## 二、新强化层级结构

### 1. Starter（启动器）- 前期
- **作用**：让Build开始运转
- **特点**：简单、明确、尽快出现
- **出现阶段**：第1-3关（opening）
- **稀有度**：common / uncommon
- **示例**：
  - Crit: 破绽叠加机制解锁
  - Pierce: 穿透产生裂纹
  - Dash: 脉冲充能机制

### 2. Amplifier（循环放大器）- 中期
- **作用**：强化核心循环效率
- **特点**：提高机制覆盖率、触发频率
- **出现阶段**：第4-7关（mid-late）
- **稀有度**：uncommon / rare
- **示例**：
  - Crit: 破绽持续时间延长
  - Pierce: 裂纹范围扩大
  - Dash: 冷却缩短、脉冲范围增加

### 3. Payoff（高潮牌）- 中后期
- **作用**：真正改变战斗体验
- **特点**：强视觉反馈、强连锁反应
- **出现阶段**：第6关以后（late+）
- **稀有度**：rare / epic
- **示例**：
  - Crit: 破绽爆炸、连锁爆点
  - Pierce: 裂纹风暴、无限贯穿
  - Dash: 残影持续输出、多重脉冲

### 4. Legendary（传奇）- 后期
- **作用**：让Build进入超模状态
- **特点**：彻底改变玩法、产生"卧槽"体验
- **出现阶段**：第8关以后（late / finalPrep）
- **稀有度**：epic / legendary
- **出现率**：低概率（约5-10%）
- **示例**：见下方设计

## 三、普通强化精简方案

### 删除列表（约40%）
以下强化功能重复或数值微小，建议删除：

1. `generic-vector-buffer` - 与 `generic-ballistics` 重复
2. `generic-sideband-cache` - 与 `generic-crossfeed` 重复
3. `generic-reroute-buffer` - 与 `generic-pressure-bypass` 重复
4. `generic-relay-throttle` - 与 `generic-salvo-cache` 重复
5. `generic-sightline-cache` - 与 `generic-ballistics` 重复
6. `generic-branch-buffer` - 与 `generic-drift-anchor` 重复
7. `generic-mirror-lattice` - 功能过于单一
8. `generic-tailfold` - 与 `generic-last-mile` 重复
9. `generic-echo-stow` - 与 `generic-crown-pocket` 重复
10. `generic-last-lock` - 与 `generic-terminal-baffle` 重复

**剩余18个普通强化**，分类为：

### 基础成长牌（8个）
1. 火控强化（damage）
2. 压缩射频（fireRate）
3. 弹道校正（projectileSpeed + damage）
4. 精密镜组（critChance）
5. 爆伤蓄能（critMultiplier）
6. 强化骨架（maxHp + heal）
7. 矢量喷口（moveSpeed）
8. 循环稳态（regeneration + fireRate）

### 混合强化牌（6个）
1. 压差旁路（hp + regen + moveSpeed）
2. 开环余量（hp + regen）
3. 交叉回授（fireRate + projectileSpeed + moveSpeed）
4. 改道缓冲（hp + regen + moveSpeed + projectileSpeed）
5. 漂移定舵（hp + moveSpeed + fireRate + regen）
6. 并线节流（damage + fireRate + projectileSpeed + moveSpeed）

### 特殊通用牌（新增4个）
1. **连射模块**：持续攻击同一目标，伤害递增
2. **清场协议**：击杀敌人触发小爆炸
3. **终端超载**：停止移动时，射速持续提升
4. **过热核心**：持续射击，子弹体积越来越大

## 四、Build定向系统

### 核心规则

1. **流派计数**：记录玩家已选择的各流派牌数量
2. **动态权重**：
   - 拿到2张Crit牌后 → Crit牌出现率+50%
   - 拿到3张Pierce牌后 → Pierce Payoff解锁
   - 拿到Starter后 → 对应Amplifier进入卡池
   - 拿到4张同流派牌后 → 其他流派概率-30%

3. **阶段锁定**：
   - Starter只能在opening/mid出现
   - Payoff只能在late/finalPrep出现
   - Legendary只能在第8关以后出现

### 数据结构扩展

```typescript
// UpgradeArchetype新增字段
stage: 'starter' | 'amplifier' | 'payoff' | 'legendary';
requires?: string[]; // 解锁此牌需要先拿到的牌ID
unlockAtRound?: number; // 解锁关卡
```

## 六、Legendary传奇强化设计

   - 描述：Crit流终极形态

3. **灰烬审判**（legendary）

   - 描述：一击清场

## 七、异常事件重构

### 保留的异常（改变玩法的）
1. **固定炮台协议** - 牺牲机动换火力
2. **红线轻甲协议** - 牺牲防御换速度和火力
3. **重装缓冲协议** - 牺牲火控和机动换防护
4. **回收驱动协议** - 牺牲火力换成长
5. **穿梭蓄能协议** - 普通射击变弱，穿梭后爆发
6. **暴击锁定协议** - 清怪变慢，对强敌爆发更高
7. **玻璃火力** - 生命上限降低，暴击留下裂纹
8. **重炮模式** - 移速降低，裂纹扩散增强
9. **断回血协议** - 无法回血，脉冲叠破绽
10. **孤注一掷** - 随机强化或负面
11. **恶魔交易** - 属性交换
12. **欧米伽超载** - 全属性提升但持续受伤

### 删除的异常（纯数值交换）
1. **过载火控** - 过于简单
2. **压缩循环** - 与过载重复
3. **固定炮台** - 与固定炮台协议重复
4. **玻璃大炮协议** - 与玻璃火力重复
5. **狂战士协议** - 与断回血协议重复
6. **过载协议** - 与欧米伽超载重复
7. **诅咒标记** - 机制复杂但收益不明确

## 十、配置化设计

所有强化层级、阶段解锁、权重调整都配置化：

```typescript
// upgradeStages.ts
export const STAGE_UNLOCK_ROUNDS: Record<UpgradeStage, number> = {
  starter: 1,
  amplifier: 4,
  payoff: 6,
  legendary: 8,
};

export const BUILD_DIRECTED_WEIGHTS: BuildDirectedWeights = {
  starterBonus: 0.5,      // 拿到2张后增加50%
  amplifierUnlock: 3,     // 拿到3张解锁Payoff
  payoffUnlock: 4,        // 拿到4张解锁Legendary
  offRoutePenalty: 0.3,   // 其他流派概率-30%
};
```

# 2026-04-18 拾取追击链与普通战回报节奏补强

## 本轮目标

- 继续停留在 `1.0 第一阶段` 的核心循环 / 核心战斗打磨主线。
- 不开新系统，不切回地图可视化，不把主线拉成 Boss 专项轮。
- 补强普通战里“击杀 -> 掉落 -> 吸附 -> 下一拍继续压”的即时回报链，让拾取不只等于数值入账。

## 本轮实现

- 在 `src/systems/RunEngine.ts` 中新增轻量 `pickupFlowSec / pickupFlowCount / pickupLeadSec / pickupLeadEnemyId`：
  - 连续拾取会延长节奏脉冲并继续推高移动、转向和开火承接。
  - 拾取后会轻量标记一个当前更适合追击的普通敌目标，并用现有 pressure helper 做温和前推。
- 调整经验球处理逻辑：
  - 磁吸半径、链式回收和 `fireCooldown` 返还现在会同时受 kill-flow 与 pickup-flow 影响。
  - 追击链成立时，资源回收不再只像“吸得快一点”，而是会更自然把普通战推进到下一拍。
- 在 `src/scenes/GameScene.ts` 中补了场内可视化：
  - 玩家身前的绿色追击楔形
  - 连续拾取的前侧小脉冲点
  - 指向当前追击目标的短引导线与目标外圈

## 为什么这样做

- 当前 docs 与交接卡都指向同一个结论：主线已经不是做更多内容，而是继续把核心战斗打磨到更顺、更爽、更愿意再打一局。
- 经验球此前已经有数值作用，但“捡到之后战斗为什么更顺”还不够直观。
- 这轮选择继续沿现有 battle state、pressure helper、场内特效去做，是为了补“读感和节奏”，而不是新造玩法系统。

## 当前结论

- 普通战里的拾取回报链现在更接近“捡到就顺手追下一拍”，而不是单纯经验入账。
- 新增引导仍然保持在场内反馈层，没有把 HUD 做回说明型 UI。
- 这轮之后，仍应继续沿普通战 / 精英战的 live mini-high 与即时回报链主线推进，不建议切回地图、Boss 新主题或新系统。

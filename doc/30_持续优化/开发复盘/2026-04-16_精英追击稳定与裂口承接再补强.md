# 2026-04-16 精英追击稳定与裂口承接再补强

## 本轮目标

- 继续停留在核心循环 / 核心战斗打磨主线，不切回地图、Boss 专项或新系统。

- 重点不是再堆新的精英内容，而是把已经存在的 `escort screen -> crack -> chase body` 读法继续压稳。

## 直接修改

### 1. 精英本体在裂口期更像可追目标

- `src/systems/RunEngine.ts`
- 精英在 `eliteCrackWindowSec` 期间：
  - 不会立刻重新起新一轮 pressure pulse。
  - 会更少保留原本的高横移 / 高退让惯性。
  - 更容易被读成“正处在可追击窗口里”，而不是提示已经出现，但本体仍旧像没开窗。

### 2. 护卫在裂口期更不容易立刻重新关门

- `src/systems/RunEngine.ts`
- 新增轻量 escort crack sustain：
  - 继续维持短 recovery / tactic cooldown
  - 远程护卫继续被短时压住射击
  - 裂口期的 hit offset 会继续朝两侧拉开一点
- 目标不是硬控，而是避免刚裂开就马上合拢，破坏追击读感。

### 3. `crit / pierce` 在裂口期的 live mini-high 再补一层

- `src/systems/RunEngine.ts`
- 在精英裂口期：
  - `crit` 会更直接得到子弹速度、飞行时长、节奏 refund 与 turn burst 的短时补偿。
  - `pierce` 会更直接得到穿线角度收紧、子弹推进与 move boost 的短时补偿。
  - 命中精英本体时会更稳定给出 tempo / hit pulse 的即时反馈。
- 这些都只挂在现有射击、命中、tempo state 上，没有新开系统。

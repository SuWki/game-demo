## 修改内容

### `tools/qa-boss-directed-v2.mjs`

**问题**: `boss-lockdown` 定向 QA 报告 `panelBlockedMoments=1`，怀疑是脚本时序问题导致误判。

**根因分析**:
- `closeUpgradeOrOverlayIfPresent` 调用后等待时间不足（400ms），DOM 更新未完成
- 面板遮挡检测使用 `page.evaluate` 直接查询 DOM，可能时序不准确
- `boss-lockdown` 作为第三个连续测试的 Boss，可能累积了前面测试的残留状态

**修复内容**:
1. 面板关闭等待时间从 400ms 增加到 600ms
2. 面板关闭后增加额外 200ms DOM 更新等待
3. 面板遮挡检测改用 Playwright `page.locator` 实时查询
4. 增加面板关闭重试机制：首次检测面板存在时，再次调用关闭逻辑并等待，确认面板确实存在才计数

**修改前后对比**:
```javascript
// 修改前：直接检测 DOM
const hasPanel = await page.evaluate(() => {
  const choicePanel = document.querySelector('[data-choice], ...');
  const overlay = document.querySelector('.upgrade-overlay, ...');
  return !!(choicePanel || overlay);
});

// 修改后：Playwright locator + 重试机制
const hasPanel = await page.locator('[data-choice], ...').count() > 0;
if (hasPanel) {
  // 重试关闭
  await closeUpgradeOrOverlayIfPresent(page);
  await page.waitForTimeout(300);
  // 再次检查
  const stillHasPanel = await page.locator(...).count() > 0;
  if (stillHasPanel) {
    summary.panelBlockedMoments += 1;
  }
}
```

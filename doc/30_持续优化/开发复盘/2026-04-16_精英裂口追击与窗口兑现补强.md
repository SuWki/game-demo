# 2026-04-16 精英裂口追击与窗口兑现补强

## 本轮复盘结论

- 当前核心循环里，普通战的回报链、危险感、击杀承接和家族人格已经不是最大短板。
- 现阶段更值得继续补的是精英战自然样本里的可读性：
  - 玩家能不能稳定读出“护卫成屏 -> 裂口出现 -> 追击本体”。
  - `crit / pierce` 能不能在这个窗口里立刻打出一拍实战爽点，而不是只在升级面板上成立。
- 本轮没有切回地图可视化、Boss 专项轮、selector-only 轮或新系统开发。

## 直接修改

### 1. 新增轻量精英裂口追击态

- `src/game/types.ts`
- `src/systems/RunEngine.ts`
- 新增 battle 级短时字段：
  - `eliteCrackWindowSec`
  - `eliteCrackEscortCount`
- 目的不是新系统，而是把原本只挂在 `elite / escort recoverySec` 上的瞬时裂口，延长成更容易被读到的一小段追击窗口。

### 2. 精英裂口期目标锁定更稳

- `src/systems/RunEngine.ts`
- 自动火力在精英裂口窗口里会更明显偏向精英本体，而不是继续被屏边护卫抢味。
- `crit` 会在精英裂口期更稳定把本体读成收割点。
- `pierce` 会在精英裂口期更稳定把本体读成穿线主轴，而不是只打到护卫边缘。

### 3. 护卫裂屏可视状态更明确

- `src/systems/RunEngine.ts`
- 护卫在裂口期会有更明显的 `hitFlash / spawnFlash`，让“现在屏裂开了”不只是逻辑上的后撤。

### 4. 画面里的追击引导继续压实

- `src/scenes/GameScene.ts`
- 精英护卫场渲染现在会读取 `eliteCrackWindowSec`：
  - 裂口提示不会只跟着精英瞬时 `recovery` 一起消失。
  - 屏裂三角、追击导线、护卫联线会多撑一小段，降低自然样本里“看见了但来不及读”的问题。
- 如果当前 live focus 是 `crit / pierce`，会额外给出更直观的追击括线 / 穿线提示。

## 当前判断

- 这轮补的是“精英窗口的站稳”和“追击本体的即时读感”，不是继续堆普通战内容。
- 目前最大的残余风险也仍然不是主流程，而是：
  - 精英自然样本截图脚本仍有命中波动。
  - 这意味着精英战层次已经更明确，但自然样本签收还要继续复检。

## 下一步建议

1. 继续复检精英自然样本，确认 `eliteCrackWindowSec` 对自然 rerun 的可读性是否足够稳定。
2. 如果继续打磨战斗，优先顺着精英窗口去看 `crit / pierce` 的 live mini-high 是否还能再更直观一层。
3. Boss 监控项与路线 continuity 仍只做防回退观察，不重新抢主线。

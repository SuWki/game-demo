# 2026-04-15 精英护卫联动与裂口窗口补强

## 本轮目标

- 继续留在“核心循环 / 核心战斗打磨”
- 不开地图轮、不做 Boss 专项轮、不引入新系统
- 把精英战继续压成更稳定的“护卫成屏 -> 裂口 -> 追击本体”读法

## 这轮实际改了什么

### 1. 精英脉冲不再只剩本体自己顶压

- `RunEngine` 里新增了精英脉冲对附近护卫的同步逻辑
- 不同行为的精英在补护卫时，会更偏向不同的站位形状：
  - `screened` 更像把护卫直接拉到前面成屏
  - `summoner` 更像把护卫拉成更宽的拖场线
  - `kiting / frontline` 也会有更明显的前压或侧展

### 2. 精英收招后的裂口更明确

- 精英脉冲结束时，附近护卫会一起进入短 recovery
- 这样读起来不再只是“精英自己空一下”，而是“整面屏临时裂开”
- 这让战斗更像在解一个高压场，而不是纯粹打厚血怪

### 3. `crit / pierce` 的实战小高潮更贴精英窗口

- `crit` 会更稳定把裂口窗口读成追收 / 连续压枪时机
- `pierce` 会更稳定把裂口和护卫成线读成拆屏 / 打穿 / 继续滚动
- 这轮仍然只在现有目标选择、命中、recovery、pulse 和轻量渲染里补，不开新系统

### 4. 画面层补了更直接的“成屏 / 裂口”读法

- `GameScene` 增加了精英与护卫之间的轻量场地连线和裂口圈
- 目标不是加说明文字，而是让玩家在战场里直接看到：
  - 现在护卫正在成屏
  - 现在这一层正在裂开

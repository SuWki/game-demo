# 2026-04-27 首批视觉音效预览生成

## 基本信息

- 日期：`2026-04-27`
- 主题：首批视觉样张、音效试听文件与小范围实机接线
- 对应阶段：作品集辅助材料 / 素材音效预览

## 本轮目标

- 这轮只解决什么问题：先产出玩家、普通敌、XP、精英、Boss、弹道和核心音效的第一批可看可听预览，并把其中最小一组接入实机测试。
- 为什么现在做这个：当前游戏已能跑通，作品集线需要更直观的素材证据，但还不适合直接大规模替换实机资源。
- 这轮明确不做什么：不做全量替换、不重写资源加载系统、不做完整动画表、不把素材线扩大成独立美术或音频工程。

## 改动前判断

- 当前现象：项目主要依赖程序化图形和 WebAudio 合成音效，已经可玩，但作品集展示需要更清楚的视觉和试听样张。
- 风险判断：如果直接替换实机素材，可能破坏读局；如果只写文档，又无法判断素材方向是否真的成立。
- 相关文档：`doc/30_持续优化/作品集材料/首批素材音效预览执行清单.md`

## 实际修改

### 工具

- 新增 `tools/generate-asset-previews.mjs`
  - 生成首批 SVG 视觉预览。
  - 生成首批 WAV 音效预览。
  - 生成 `index.html` 试听 / 查看入口。
  - 生成 `visual-contact-sheet.svg` 视觉总览板。
  - 生成 `battle-readability-composite.svg` 战斗截图合成检查板。

- 新增 `tools/qa-runtime-preview-assets.mjs`
  - 检查 runtime 接入资源是否能通过本地 Vite 服务访问。
  - 使用本机 Chrome / Edge 执行一次轻量浏览器检查。
  - 输出 `output/qa/runtime-preview-assets/summary.json` 和实机截图。

### 代码

- 更新 `src/scenes/BootScene.ts`

  - 增加轻量图片池。
  - 将玩家、普通标准敌、XP 球以半透明贴图方式盖到原程序化表现上。

## 仍然存在的问题

- 视觉接线仍然是测试层，只有玩家、标准敌和 XP 球接入，精英和 Boss 尚未接入。
- 音效只接入了 `shoot / hit / kill / pickup / hurt`，危险链里的 `nearMiss / pressure / enemyShot` 暂时仍用原合成音效。
- 当前贴图是半透明覆盖在程序化图形之上，还不是最终资源方案。
- 还没有做人工长时间试玩听感判断。

## 下一步建议

1. 人工试玩 3~5 分钟，重点判断玩家贴图是否过小、XP 球是否仍像拾取物、标准敌是否和敌弹冲突。
2. 试听 `shoot / hit / kill / pickup / hurt` 在混战里的疲劳度和优先级。
3. 如果基础三件套通过，再接入精英核心和 Boss Bastion。
4. 如果基础三件套不通过，先改样张，不继续扩大接线范围。

## 专属名词解释基线

后续所有路线名词必须回答三个问题：是什么、何时触发、触发后有什么可见结果。

### 暴击

- 是什么：一次更高伤害的命中。
- 何时触发：你的攻击命中敌人时，按当前暴击率判定触发。
- 触发结果：敌人身上出现短促爆闪 / 破甲反馈，音效更脆，伤害更高。

### 穿透

- 是什么：子弹命中后继续向前飞，能够继续打到后面的敌人。
- 何时触发：带有穿透次数的子弹命中敌人后，只要剩余穿透次数大于 0 就继续生效。
- 触发结果：被贯穿敌人身上出现冷色穿孔，弹道留下短线，不应变成整屏长激光。

### 穿梭

- 是什么：冷却结束后自动释放的一次短时机动脉冲。
- 何时触发：拥有穿梭路线或脉冲伤害后，穿梭冷却归零即触发。
- 触发结果：玩家获得短暂无伤窗口，并以自身为中心释放脉冲；附近敌人会受到脉冲伤害和击退。
- UI 必须避免只写“穿梭冷却 -0.6 秒”，应同时说明“缩短下一次自动脉冲的等待时间”。

目标：安全区内更安全，安全区外明显危险，但不能靠减速惩罚。

  if (!isBossSafeWindowActive(battle)) return;

  const inside = isPointInsidePressureSafeWindow(battle, battle.playerX, battle.playerY, 0);
  if (inside) {

### P0-5：流派构筑重构骨架

目标：路线牌不再是高性价比数值牌，而是分层构筑牌。

价值预算：

- 通用牌：提供基础属性性价比，作为稳定选择。
- 路线 starter：只给路线倾向和一个低量核心机制，不给高额泛属性。
- 路线 bridge：要求已有 1 到 2 点路线推进，提供机制承接。
- 路线 payoff：要求已有 3 点以上路线推进，提供短窗收益。
- 路线 finisher：要求后段或 Boss 前后出现，提供终局解法。

路线牌属性规则：

- `crit` 牌优先 `critChance / critMultiplier / critWindow`，不再混入 `damage / projectileSpeed / moveSpeed`。
- `pierce` 牌优先 `pierce / pierceDecay / lineReward`，谨慎使用 `multishot`，默认不混入 `damage`。
- `dash` 牌优先 `dashInterval / dashInvulnerability / dashPulseDamage / dashCharge`，不混入通用回血和常驻移速。

选择池规则：

- 所有升级路径，包括 `finalPrep`，最多 1 张路线牌。
- 未形成路线前，路线牌出现率低于通用牌。
- 已有路线倾向后，只提高同路线承接牌，不直接发高价值 payoff。
- 通用牌必须重新有性价比，不能被路线牌全面碾压。

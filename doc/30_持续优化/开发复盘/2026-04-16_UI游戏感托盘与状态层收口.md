# 2026-04-16 UI游戏感托盘与状态层收口
## 本轮目标

- 继续压掉“像网页页面/弹窗”的感觉，让战斗 UI 更像游戏里的状态层。
- 让路线选择、强化选择、异常处理三类面板读起来更像不同的游戏决策，而不是同一种卡片列表。
- 保持战斗 HUD 极简，不重新加回大段说明和重型面板。

## 直接修改

### 1. 开始页 / 结算页改成游戏状态层

- `src/ui/OverlayController.ts`
- `src/style.css`
- 开始页和结算页都改成左下或左中锚定的大标题状态层。
- 增加了轻量的扫描线、环形标记、角部线段和场内氛围，而不是网页式空白页面。
- 按钮改成更像游戏提示的短命令形式，只保留最少的动作文字。

### 2. 选择界面从卡片改成战术托盘

- `src/ui/OverlayController.ts`
- `src/style.css`
- 底部选择区域改成带斜切、细边、弱发光的条目式托盘，不再是完整圆角大卡片。
- `路线选择`、`强化选择`、`异常处理` 三类面板用了不同的标题、提示词和色彩侧重。
- 强化项继续保留稀有度染色；带流派倾向的强化会保留醒目的流派加成标识。
- 右上角目标文案缩短为 `目标: 强化 / 选路 / 处理` 这类短读法，减少网页说明感。
- 在第二次收口里继续压掉 node / anomaly 面板的 tag 感，把部分标签退成普通文字，同时把说明统一压到 1 行。

### 3. HUD 与背景再统一一刀

- `src/main.ts`
- `src/style.css`
- Phaser 背景底色同步到新的深蓝黑范围。
- 顶部 HUD 继续维持极简三段式，只留下血量/经验、波次、目标。

## 当前结论

- 开始页和结算页已经从“网页落地页”往“游戏状态界面”明显靠拢。
- 路线 / 强化 / 异常三类决策面板的差异度比上一轮清楚，且不再是重卡片堆叠。
- node / anomaly 面板的残余说明感比第一版收紧了一截，整体更接近战术托盘而不是弹窗。
- 战斗 HUD 仍保持极简，没有回退成大段说明式 UI。
- 残余风险主要还是托盘信息量偏多，后续如果用户还想继续压 UI，应优先继续减 tag 数量和描述长度，而不是重开新界面系统。

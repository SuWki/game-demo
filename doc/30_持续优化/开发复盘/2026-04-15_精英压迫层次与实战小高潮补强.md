# 开发复盘

## 基本信息

- 日期：`2026-04-15`
- 主题：精英压迫层次与实战小高潮补强
- 负责人：Codex
- 对应阶段：`1.0 第一阶段`

## 本轮目标

- 继续围绕核心循环与核心战斗打磨，不切回地图、Boss 专项或新系统开发。
- 把精英战从“更厚的普通战”往“更可读的高压层”推进。
- 让 `crit / pierce` 的实战 mini-high 更稳定地出现在普通战与精英战里。
- 继续补强普通敌人的家族人格，让场面更像被不同职责的敌人共同塑造。

## 改动前判断

- 普通战的回报链已经能滚起来，但精英战的层次还不够独立。
- `crit / pierce` 的即时爽点已经开始成立，但更多偏“命中到时很爽”，还缺更稳定的战场时机承接。
- 普通怪、蛮兵、游击、远程已有差异，但更多是单兵手感差异，还不够像家族协同。

## 实际修改

### 代码

- `src/game/types.ts`
  - 为敌人补入轻量 `pressurePulseSec / tacticCooldownSec`，承接精英压迫节拍和普通敌人家族动作。
- `src/systems/RunEngine.ts`
  - 精英新增“压迫脉冲 -> 短收招窗口 -> 再压上”的轻量节拍。
  - `frontline / kiting / screened / summoner` 四类精英姿态现在更分化：
    - `frontline` 更像顶线压脸。
    - `kiting` 更像拉扯后甩一轮火力。
    - `screened` 更像借护卫封线。
    - `summoner` 更像补屏后拖场。
  - 精英短窗口会反向抬高 `crit / pierce / dash` 的实战承接，但没有引入新系统。
  - 普通敌人新增家族协同：
    - `standard` 会贴前排补线。
    - `brute` 有支撑时更会顶线。
    - `skirmisher` 更会借精英/远程做绕侧切回。
    - `ranged` 更会站在前排身后借屏射击。
  - `pierce` 补了更稳定的拆线兑现：精英窗口与清线击杀后更容易把下一枪继续推起来。
  - `crit` 补了更稳定的收招兑现：精英短窗口打开时更容易接成“压线 -> 收割 -> 继续开火”。
- `src/scenes/GameScene.ts`
  - 战场里新增敌人压力脉冲可视化。
  - 精英压力现在更容易被读成“本体在压 / 护卫在封 / 现在有短窗口”。
  - 普通敌人的家族动作也有了更直接的图形读感，而没有回到网页式说明层。

## 结果判断

- 本轮已经把主问题从“普通战会不会掉拍”进一步推进到“精英战层次够不够稳”。
- 普通敌人家族人格继续抬高，画面里更容易读出谁在补线、谁在顶线、谁在借屏射击。
- `crit / pierce` 的实战 mini-high 已经更依赖战场时机，而不只是面板累计。

## 仍存风险

- 精英压迫层次虽然已开始成立，但还需要更多自然样本确认它是否足够稳定。
- 本轮没有把主线切回 Boss，因此 `屏卫主核 / fireline` 仍只是持续监控项，没有做专项回补。

## 下一步建议

1. 继续验证精英层次在自然样本里的稳定读感，而不是急着继续扩更多普通战反馈。
2. 继续把 `crit / pierce` 的实战小高潮压实到“玩家不用读说明也能感觉到”。
3. 维持当前文档同步节奏，继续避免地图轮、Boss 轮或新系统轮抢主线。

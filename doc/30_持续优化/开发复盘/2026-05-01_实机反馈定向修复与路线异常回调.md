# 2026-05-01 实机反馈定向修复与路线异常回调

## 本轮目标

本轮目标不是继续扩内容，也不是继续做作品集材料，而是直接处理玩家实机指出的 15 个体验问题：显示单位、关卡目标、异常事件、路线强化、回血、Boss 安全区、穿透超模、默认音量和数值展示必须先回到“玩家能看懂、能感知、能公平游玩”的状态。

## 问题与修复对应

- 玩家可见的 `ms` 单位改为秒：`穿梭冷却 -0.9秒`、`无伤窗口 +0.1秒`，不再显示 `-920ms`。
- HP/EXP 显示取整：局内 HUD 和属性摘要对玩家展示整数，内部仍允许小数计算。
- 歼灭/生存目标补清楚：歼灭显示 `歼灭 当前击杀/目标击杀`，生存显示 `生存 剩余秒数`。
- 升级不再立刻回血：升级卡构建时过滤 `heal` 效果，生命上限变化只改变上限并夹取当前血量，不再顺手把血补满。
- 生命回复过快回调：回复强化实际收益缩放到 `0.38`，Dash 擦身回血和 Dash 脉冲回血同步下调。
- 路线卡不再被压成单一属性：通用卡仍做单属性收束，`crit / pierce / dash` 路线卡保留原始多效果，避免“同一内容换名字”。
- 路线分发更偏向当前路线：已经出现主路线后，升级池优先给对应路线卡，让暴击、穿透、穿梭不再只反复出现一个属性。
- 异常事件不再普通化：异常选项保留原始多效果和代价，不再经过单属性归一化，避免异常节点看起来像普通伤害卡。
- 异常节点出现频率下调：异常权重从较高动态值回调为更稀有的节奏，避免后期过于频繁稀释路线选择。
- 穿梭触发提示补强：Dash 脉冲命中或获得短暂无伤窗口时会推送短提示，让玩家知道穿梭收益已经触发。
- 暴击提示保留并允许战斗中显示：战斗中允许路线 toast 出现，暴击命中、穿透、穿梭类提示不再被全部压掉。
- 穿透超模回调：穿透上限限制为 `3`，多重上限限制为 `4`，穿透命中按穿透次数递减，穿透回声伤害和冷却返还下调。
- 拾取过松回调：拾取半径和磁吸半径继续下调，避免不选拾取范围也几乎自动全收。
- Boss 弹幕回调：Boss 远程敌权重和弹幕墙数量下调，Boss HP 上调，降低“满屏糊弹但 Boss 被秒”的矛盾感。
- Boss 安全区规则修正：Boss 安全区内清理敌方弹体，安全区外改为持续威胁但不再施加移动冲击，避免“进安全区仍被打、不进安全区也没区别、移动莫名变慢”。
- Boss 通关条件复查：当前 Boss 胜利仍是 `eliteSpawned && !eliteAlive`，没有发现“没打死也通关”的独立条件错误；更可能来自穿透超模导致 Boss 被过快击杀，本轮已通过穿透递减、Boss HP 上调和弹幕回调处理。
- 默认音量修复：无有效存档或存档音量为 `0` 时，默认音量设为 `40%`。

## 为什么这样改

本轮优先处理玩家感知链路，而不是继续堆新内容。原因是当前问题已经不是“内容少”，而是几个基础体验在同时误导玩家：路线触发看不见、异常像普通卡、Boss 安全区规则不可信、穿透数值破坏压力、UI 显示出现小数和毫秒。只有先把这些基础信号修正，后续表现层、音效和作品集材料才有可信的游戏版本作为底座。

## 仍需人工确认

- Boss 安全区体感仍需人工实机 2~3 局确认：脚本样本无错误，但 headless 样本没有稳定采到安全区计数，不能替代真实操作判断。
- 穿透是否从“无敌秒杀”回到“强但需要站位和贯穿线”需要实机确认。
- 异常事件是否真的更像玩法事件，需要观察玩家实际遇到的选项组合。
- `crit / pierce / dash` 是否都能成型但不超模，需要分别走三局路线样本。
- 拾取/磁吸下调后，XP 收集是否从“全自动”回到“有参与感但不繁琐”需要实机确认。

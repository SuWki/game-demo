## 实际接入方式

### 1. 玩家弹道素材 (`player-projectile-core.svg`)

接入位置：`src/scenes/GameScene.ts` 玩家子弹渲染循环

修改点：
- 在 `for (const bullet of battle.bullets)` 循环内，计算完 `screen` 位置后
- 新增 `renderRuntimePreviewImage(PREVIEW_PLAYER_PROJECTILE_TEXTURE, ...)` 调用
- 弹道核心大小：`10 + (bullet.canEcho ? 2 : 0)` 像素
- 旋转角度：`Math.atan2(bullet.vy, bullet.vx)` 跟随弹道方向
- 透明度：0.75
- 保留原有程序化绘制作为 fallback

代码片段：
```typescript
// Try to render preview image for bullet core
const bulletCoreSize = 10 + (bullet.canEcho ? 2 : 0);
const bulletRotation = Math.atan2(bullet.vy, bullet.vx);
const previewRendered = this.renderRuntimePreviewImage(
  PREVIEW_PLAYER_PROJECTILE_TEXTURE,
  screen.x,
  screen.y,
  bulletCoreSize,
  bulletRotation,
  0.75,
);
```

### 2. 敌方弹道素材 (`enemy-projectile-core.svg`)

接入位置：`src/scenes/GameScene.ts` 敌方子弹渲染循环

修改点：
- 在 `for (const projectile of battle.enemyProjectiles)` 循环内，计算完 `screen` 位置后
- 新增 `renderRuntimePreviewImage(PREVIEW_ENEMY_PROJECTILE_TEXTURE, ...)` 调用
- 弹道核心大小：`Math.max(10, projectile.radius * 2.2)` 像素
- 旋转角度：`Math.atan2(projectile.vy, projectile.vx)` 跟随弹道方向
- 透明度：0.7
- 保留原有程序化绘制作为 fallback

代码片段：
```typescript
// Try to render preview image for enemy projectile core
const projectileCoreSize = Math.max(10, projectile.radius * 2.2);
const projectileRotation = Math.atan2(projectile.vy, projectile.vx);
this.renderRuntimePreviewImage(
  PREVIEW_ENEMY_PROJECTILE_TEXTURE,
  screen.x,
  screen.y,
  projectileCoreSize,
  projectileRotation,
  0.7,
);
```

### 3. Boss 火线素材 (`fx-boss-bastion-fireline.svg`)

接入位置：`src/scenes/GameScene.ts` `renderBattleEntities` 方法

修改点：
- 在 `renderPressurePatternOverlay` 调用后新增 Boss 火线overlay
- 触发条件：`battle.encounterType === 'boss' && battle.bossFirelineCoverage > 0.08`
- 动态透明度：`Math.min(0.55, battle.bossFirelineCoverage * 0.8)`
- 全屏覆盖：使用 `camera.width * 0.5, camera.height * 0.5` 居中
- 尺寸：`Math.max(camera.width, camera.height) * 0.85`

代码片段：
```typescript
// Render Boss fireline texture overlay during Boss fireline phases
if (battle.encounterType === 'boss' && battle.bossFirelineCoverage > 0.08) {
  const firelineAlpha = Math.min(0.55, battle.bossFirelineCoverage * 0.8);
  this.renderRuntimePreviewImage(
    PREVIEW_BOSS_FIRELINE_TEXTURE,
    camera.width * 0.5,
    camera.height * 0.5,
    Math.max(camera.width, camera.height) * 0.85,
    0,
    firelineAlpha,
  );
}
```

## 程序化 Fallback 保留

所有素材接入均保留程序化 fallback：
- 如果 `runtimeVisualPreviewEnabled` 为 false，或纹理不存在，`renderRuntimePreviewImage` 返回 false
- 原有 `this.graphics.lineStyle / lineBetween / fillCircle` 等程序化绘制逻辑完整保留
- 预览素材仅作为叠层，不影响原有命中判定、碰撞检测等逻辑

## 可读性设计

### 玩家弹道
- 尺寸较小（10-12px），不遮挡敌弹
- 跟随弹道方向旋转，增强方向感
- 半透明（0.75），保留程序化尾迹可见

### 敌方弹道
- 尺寸基于原有 `projectile.radius`，保持 proportional
- 跟随弹道方向旋转
- 半透明（0.7），保留危险颜色识别

### Boss 火线
- 仅在 `bossFirelineCoverage > 0.08` 时显示（火线密度较高时）
- 透明度与火线覆盖率挂钩，避免过度干扰
- 全屏居中，作为氛围层而非具体弹道

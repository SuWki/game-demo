# 2026-05-18 流派强化文本规范实施

## 本轮目标

将流派强化从"进度"系统改为"机制属性"系统，并统一文本规范，去除内部设计语言。

## 用户问题与解决方案

| 用户问题 | 解决方案 | 当前状态 |
|----------|----------|----------|
| 流派强化显示"开启暴击流"等进度文本，玩家不理解 | 将`type: 'route'`进度效果改为`type: 'stats'`机制属性 | 已完成 |
| 流派描述过长，包含属性数值和内部术语 | 重写`ROUTE_DESCRIPTION_OVERRIDES`，精简描述 | 已完成 |
| 描述中出现"窗口"等内部术语 | 统一替换为"时间"、"时机" | 已完成 |
| 裂纹扩散描述过长，包含对精英/Boss倍率说明 | 简化为"裂纹扩散范围强化" | 已完成 |

## 机制改造详情

### 暴击流机制属性

新增/使用以下机制属性替代进度：
- `critOverdriveCritBonus` - 超频暴击率加成
- `critSplashRadius` - 暴击溅射范围
- `flawDurationBonus` - 破绽持续时间
- `critOverdriveDurationBonus` - 超频持续时间

### 穿透流机制属性

新增/使用以下机制属性替代进度：
- `pierceEchoDamageBonus` - 回响伤害加成
- `crackSpreadRadius` - 裂纹扩散范围
- `pierceCooldownRefundBonus` - 穿透冷却返还

### 穿梭流机制属性

新增/使用以下机制属性替代进度：
- `dashChargeSpeed` - 脉冲充能速度
- `dashCounterDamageBonus` - 反击伤害加成
- `dashGrazeRadiusBonus` - 擦弹半径加成

## 文本规范实施

### 1. 禁用词替换

| 原词 | 替换为 |
|------|--------|
| 窗口 | 时间 |
| 无伤窗口 | 无伤时间 |
| 短窗 | 短时机 |
| 短窗爆发 | 短时机爆发 |
| 反击窗口 | 反击时机 |

### 2. 描述简化

| 原描述 | 新描述 |
|--------|--------|
| 贯穿裂纹目标后，下一次裂纹扩散范围略增（对精英/Boss有倍率限制） | 裂纹扩散范围强化 |
| 裂纹扩散时，对同线后方敌人追加小范围裂纹伤害（精英/Boss伤害受限） | 裂纹扩散追加后方伤害 |
| 超频期间额外暴击率+4%，修复损伤 | 超频状态下暴击强化，修复损伤 |
| 破绽持续时间+20%，修复损伤 | 破绽机制效率提升，修复损伤 |

### 3. 流派描述统一

在`ROUTE_DESCRIPTION_OVERRIDES`中统一覆盖64张路线牌描述，遵循：
- 只描述机制效果，不提及属性数值
- 使用玩家语言，不使用内部术语
- 长度控制在15字符以内

# 2026-04-15 UI 轻量化参考重做

## 本轮目标
- 解决当前 UI 仍然偏网页卡片、重量过高的问题。
- 参考另一项目的浅色、轻量、贴场景式 UI 语言，收掉大黑块、重边框、长说明。
- 不改主玩法，不新开系统，只重做现有 overlay 与样式层。

## 直接实现
- 重写 `src/ui/OverlayController.ts`
  - 菜单、HUD、路线选择、强化选择、结果页统一改成更短、更轻的结构。
  - 明确区分了 `路线选择` 与 `强化选择`：
    - 路线卡走虚线分支/节点标签
    - 强化卡走稀有度色与流派加成标签
- 重写 `src/style.css`
  - 整体从深色重面板改成暖色、低重量、半透明游戏浮层。
  - 去掉大面积黑底和重投影，保留轻边框、圆角、浅色浮片。
  - HUD 改成顶部三块轻标签，不再像网页信息栏。
- 调整 `src/main.ts`
  - 将空场景底色改为暖色，避免开始页和结果页压在深色空画布上。

## 验证
- `npm run build` 通过。
- 本地 `vite preview` 下使用现有 Playwright 全流程脚本复检：
  - `menu.png`
  - `panel-28.png`
  - `battle-opening.png`
  - `result.png`
- 本轮截图确认：
  - 开始页已不再是居中网页卡片
  - 路线选择与强化选择已有明显视觉分工
  - 战斗 HUD 已从黑框压屏改成浅色轻浮层
  - 结果页与菜单页视觉语言已统一

## 结论
- 这一轮的核心价值不是“再加 UI 内容”，而是把 UI 从“网页容器感”拉回“游戏内信息层”。
- 如果下一轮用户还觉得重，优先继续压：
  - 底部 tray 高度
  - 结果页下半区块体积
  - HUD 标签宽度
- 不建议再回到深色重卡片方向。

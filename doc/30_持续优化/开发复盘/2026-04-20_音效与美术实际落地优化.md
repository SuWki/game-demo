# 2026-04-20 音效与美术实际落地优化

## 本轮目标

- 继续停留在 `1.0 第一阶段` 的核心循环 / 核心战斗打磨主线。
- 不重写主流程，不重开新系统，不把这轮扩大成大 UI 主题轮或 Boss 专项轮。
- 直接把当前版本里最像“恢复中的测试版”的画面与音效层继续收口，让它更像一款已经成立中的可玩版本。

## 实际改了哪些表现内容

### 代码文件

- `src/scenes/GameScene.ts`
- `src/systems/PilotAudio.ts`
- `src/ui/OverlayController.ts`
- `src/style.css`

### 画面 / 美术层

- 重拉了玩家、普通敌、护卫 / 精英、Boss 的程序化轮廓：
  - `brute` 更厚更钝
  - `skirmisher` 更尖更像切侧箭头
  - `ranged / escort` 多了一层更像架火点 / 屏卫点的外环
  - 精英与 Boss 不再只是“红色大一号”
- 把 XP 球、玩家弹道、敌方弹道继续拉开：
  - XP 球多了更明确的拾取十字和回收辨识
  - 玩家弹道和 `pierce` 轨道更像“输出线”
- 危险圈、安全窗、裂口和压力提示继续往程序化战场几何上收：
  - 安全窗新增括角和边界结构
  - 裂口与追击窗口继续保留楔形和 rail 导向
- 开始页 / HUD / 结算页继续统一：
  - 菜单副标题、按钮文案和结果页摘要更像同一套作战界面
  - 样式上减少“静态网页托盘”味道
- `pierce` 的持续视觉签名继续补强：
  - 追击和裂口窗口里都保留双线 rail 与前推 marker

### 音效 / 音频层

- `PilotAudio` 增加了轻量战斗上下文：
  - `routeFocus`
  - `encounter`
  - `intensity`
- 没有重写音乐系统，但让现有 cue 开始按上下文分家：
  - `shoot / hit / kill / pickup`
  - `hurt / nearMiss / pressure`
  - `enemyShot`
- 普通战 / 精英 / Boss 的听感层次被拉开：
  - 普通战优先把主链听清
  - 精英 / Boss 让 `pressure` 和来弹更厚、更像压上来
- 三路线里先把最需要的最小差异落下去：
  - `crit` 更热、更上扬
  - `pierce` 更冷、更线性
  - `dash` 补了更低频、更像换位起冲的一层

## 为什么先改这些

- 当前最影响玩家观感的，不是“缺最终资源”，而是：
  - 战场层级还不够一眼读懂
  - 危险反馈和输出反馈还不够分家
  - 菜单 / 局内 / 结算页还有一点像恢复中的测试界面
- 这些问题如果不先收口，后面再叠正式资源，很容易只是“更花”，不会更清楚。
- 所以这轮优先做的是：
  - 不重开系统
  - 不靠大资源替换
  - 先把读局、战斗反馈和整体一致性抬起来

## 哪些问题被改善了

- 局内敌我层级现在明显更清楚，普通敌家族、护卫、精英本体和 Boss 主核不再主要靠尺寸差区分。
- `pierce` 的视觉与音频存在感都更稳定，至少不再只剩路线文案和数值。
- `hurt / nearMiss / pressure` 三类危险反馈更容易分清，不再都像同一类提示音。
- 开始页 / HUD / 结算页的语言和外壳更统一，整体更像同一款游戏里的三个阶段。
- 安全窗和裂口追击更接近“真实战斗信息”，而不是单纯调色块或附加说明。

## 哪些仍然只是临时状态

- 当前仍然主要是程序化表现，不是最终正式资产。
- `dash` 虽然已经有最小差异，但路线签名仍弱于 `crit / pierce`。
- 精英 / Boss 现在已经更可读，但真正高完成度的音画记忆点还要靠后续正式替换继续补。

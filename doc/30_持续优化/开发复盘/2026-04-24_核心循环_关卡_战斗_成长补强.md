# 2026-04-24 核心循环_关卡_战斗_成长补强

## 本轮目标

- 按照 `doc/10_设计文档/核心循环_关卡_战斗_成长补强方案.md`，继续做一轮小步可验证补强。
- 不重写 `RunEngine`，不加新系统，只沿 `contentSelectors / nodes / upgrades` 做分发和内容微调。
- 重点补三个点：
  - 第二轮更容易读成“路线开始站稳”
  - 第三轮更像“后段收束”
  - `finalPrep` 更像“补拼图 / 补短板”，而不是重新开新方向

## 实际改了哪些代码

### 1. `src/data/contentSelectors.ts`

- 增加 `finalPrep` 专用升级分发池：
  - `finalPrepGenericPatchPool`
  - `finalPrepGenericCloseoutPool`
  - `finalPrepRouteSealPool`
  - `finalPrepDominantFlexPool`

- 新增 `finalPrep` 分支逻辑：
  - 有主路线时，优先给当前路线的 `payoff / finisher`，其次给通用补短板牌，再给收束 flex。
  - 无主路线时，优先给通用补短板和收束牌，不再鼓励最后一拍开全新方向。

### 2. `src/data/upgrades.ts`

- 新增 `generic-last-lock`
  - 类型：通用稀有 `payoff`
  - 作用：给第三轮后段和 `finalPrep` 增加一张更像“补最后一块板”的通用收束牌。

### 3. `src/data/nodes.ts`

- 调整第三轮分发权重：
  - 降低 `round-3-upgrade-sidefold`
  - 降低 `round-3-anomaly-pivot`
  - 降低 `round-3-anomaly-switchboard`
  - 提高 `round-3-event-last-bet`
  - 提高 `round-3-anomaly-closeout`

- 调整 `round-3-upgrade-commit-hold`
  - 提高 `dash` 的路线加权，让 `dash` 在后段更容易读成“已经站稳，而不是还在漂”。

## 为什么这么改

- 现阶段的核心问题已经不是“系统不够”，而是“体验链条还不够紧”。
- 第二轮最关键的不是继续加节点，而是让玩家更稳定感觉到“这把开始走这条路了”。
- 第三轮最关键的不是再开更多并轨窗口，而是把局势推向收束。
- `finalPrep` 如果仍然高频发并轨、redirect 或泛 hybrid，心理上就会像“最后再开一次方向”，这会直接冲淡 Boss 前的收尾感。

所以这轮优先做的是：

- 用选择器直接收紧 `finalPrep` 的出牌边界
- 用节点权重削弱第三轮继续发散的入口
- 用一张通用收束牌补上“没有完美路线牌时怎么办”的拼图位

## 哪些问题被改善了

- `finalPrep` 更接近补拼图：
  - 当前逻辑不再把最后一拍主要留给改道或并轨，而是更偏收尾和补短板。

- 第三轮更像收束：
  - 后段节点里“继续偏折 / 继续并轨”的入口变少了，押注和 closeout 的比重更高。

- `dash` 的后段站稳感略有改善：
  - 不只是中段有路，第三轮的承接牌也更容易把它压成已成型路线。

## 仍然是临时状态的部分

- 这轮仍然主要是 selector + data 的补丁，不是完整内容扩容。
- `finalPrep` 的“补拼图感”目前主要靠分发逻辑保证，后续仍需要自然样本验证是否偶发给出太多泛用稳牌。
- `dash` 的路线辨识虽然比前一版更完整，但后段 payoff 的爽感仍弱于 `crit / pierce`。

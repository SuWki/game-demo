# 2026-04-18 普通敌压迫可读性与来袭预警补强

## 本轮目标
- 延续核心战斗打磨，不开新系统，不回到地图可视化。
- 补强普通敌人在自然样本里的压迫人格，让 `skirmisher` 与 `ranged` 不再只是单点动作。
- 提高玩家在普通战里的受击前可读性，让“哪边要夹、哪边要开火”更早被读到。

## 实现内容
- `src/systems/RunEngine.ts`
  - `skirmisher` 的压力拍现在会同步附近的 `skirmisher / standard`，并轻量带动锚点单位，让侧切更像一拍接一拍的夹击。
  - `ranged` 的压力拍现在会同步附近的 `ranged / skirmisher`，并轻量拉起掩护锚点，让远程开线不再像单人发呆后再开火。
  - 普通敌压力脉冲额外携带 `spoke` 参数，屏幕内反馈不再只有圆环。
- `src/scenes/GameScene.ts`
  - 敌方投射物改成更尖锐的矛头轮廓，飞行方向与危险性更直观。
  - 在玩家周围加入轻量来袭预警，只在屏幕较平静时显示，不抢受击、擦弹、击杀连段等主反馈。
  - 预警来源覆盖附近敌弹、远程即将开火、以及近身普通敌的压力拍，保持场内读法而不是 HUD 提示框。

## 验证
- `npm run build`
- `npm exec --yes --package=playwright -- node output/playwright/battle-feel-pass/round20/full-flow.mjs`
- `npm exec --yes --package=playwright -- node output/playwright/battle-feel-pass/round20/pressure-check.mjs`

## 结果判断
- 普通战的来袭方向比上一轮更早成立，尤其是 `ranged` 屏线和 `skirmisher` 侧切不再只靠挨打后才读懂。
- 敌弹轮廓从小圆点变成更像“会扎过来”的物体，战场读秒感更强。
- 当前改动没有引入新 UI 壳层，也没有把战斗提示重新做成网页式面板。

## 后续建议
- 下一轮优先继续沿着“普通敌家族人格 + live mini-high”打磨，不要切回地图或大 UI 主题。
- 如果继续补战斗爽感，下一刀可以考虑普通敌受击后的短时回摆和家族连携音效，而不是再堆文字或面板。

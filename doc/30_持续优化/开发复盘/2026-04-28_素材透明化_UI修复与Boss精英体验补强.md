# 2026-04-28 素材透明化、UI 修复与 Boss/精英体验补强

## 本轮目标

解决当前版本中直接影响体验的七类问题：运行时素材黑底、子弹拖尾奇怪、开始页音量面板不可操作、暂停继续后面板残留、属性加成小数难懂、Boss 弹幕过密、Boss/精英像血厚木桩。

## 实际修改

- 运行时 SVG 预览素材去掉黑色背景和说明文字，保留透明底角色/敌人/XP 球主体。
- 玩家子弹和敌方弹道拖尾缩短、变细、降低透明度，保留路线签名但减少长线段噪声。
- UI 层级增加明确 `z-index`：屏幕层、HUD、面板层、toast 分层；音量面板滑杆和关闭按钮可以正常点击。
- 暂停继续逻辑增加强制 `hidePanel()`，避免战斗恢复但暂停窗口残留。
- 属性展示改为整数、百分比或毫秒：暴击伤害展示为 `+N%`，最终摘要展示为总暴伤百分比。
- Boss 模板下调弹幕墙数量、齐射频率和远程压制频率，上调安全窗尺寸与停留时间。
- 精英/Boss 模板提高横移和阶段机动；`RunEngine` 在压力阶段切换时给予短暂机动/横移提升，让转段更有行为感。

## 为什么先改这些

这些问题都属于玩家第一轮就会感知到的体验问题。素材黑底、UI 面板卡住、暂停窗口残留会让版本显得像测试版；暴击小数和弹道长线会降低读局；Boss 弹幕过密会直接破坏公平性。相比继续扩内容池，本轮优先修掉阻塞体验和读局的问题。

## 当前公式说明

- 暴击伤害公式：`实际伤害 = 子弹基础伤害 × 暴击伤害倍率`。
- 粗略期望伤害：`期望伤害 = 基础伤害 × (1 + 暴击率 × (暴击伤害倍率 - 1))`。
- 卡牌 `暴击伤害 +51%` 代表 `critMultiplier +0.51`，不是最终伤害只增加 `0.51x`。

## 已改善的问题

- 运行时素材不再带黑底，和程序化战场能正常叠加。
- 玩家弹、敌弹、XP 球更容易分清，敌弹拖尾不再压过弹体。
- 开始页音量面板和暂停继续流程不再阻塞。
- 属性选择文案更接近玩家直觉。
- Boss 关从“弹幕堵死”转向“弹幕压力 + 安全窗判断”。
- 精英/Boss 有更明显的行为身份和转阶段机动。

## 仍是临时状态

- 当前运行时 SVG 仍是预览资产，不是最终美术资产。
- Boss/精英机制仍主要基于现有压力阶段系统，没有新增完整技能系统。
- 弹幕密度回落后，需要继续观察 Boss 是否变得过易。
- 属性展示已改清楚，但后续仍需统一所有 tooltip 的完整公式说明。

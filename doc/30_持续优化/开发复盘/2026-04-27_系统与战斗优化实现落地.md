# 2026-04-27 系统与战斗优化实现落地

## 本轮目标

把前一轮讨论稿里的系统收口、战斗流畅度、强化档位和流派声纹，真正落到代码里，并同步验证当前实现状态。

- `src/systems/PilotAudio.ts`

## 这轮实际落地

- 把 `crit / pierce / dash` 的特殊伤害声纹拆开了，特殊 buff 的命中反馈现在能听出路线差别。
- 把战斗中的击中镜头抖动压轻了，读感更像冲击，不再像卡顿。
- 清掉了 XP 拾取后的线段拖尾，拾取只保留短促回收感。
- 调大了拾取范围和磁吸范围，让拾取更有存在感。
- 收紧了 `pierce` 路线周围的线段噪声，也顺手检查了其他路线的同类读图方式。
- 补齐了局内暂停、开始页音量、暂停页音量、结果页对局数据这些收口入口。
- 按档位公式继续修正了强化数值，避免不同等级的强化再压成同一个结果。

## 验证

- `npm run build`
- 本地浏览器预览验证
- 结果页、暂停页、音量面板都能正常打开和操作
- 战斗中能看到更轻的镜头抖动和更干净的拾取表现

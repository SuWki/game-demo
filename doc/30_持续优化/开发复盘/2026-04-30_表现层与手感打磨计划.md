# 2026-04-30 表现层与手感打磨计划

## 本轮背景

Boss 安全窗已经签收，作品集 Boss 案例页也已完成一轮整理。但当前用户明确要求：先把游戏本体的表现层和手感打磨好，再做材料、截图、视频和作品集包装。

因此本轮不继续推进作品集材料，不新增 Boss / 精英 / 路线，也不做大规模资产替换。重点回到玩家实际游玩时最先感受到的内容：看得清、听得懂、移动顺、打击爽、提示直白。

## 当前判断

当前版本已经有完整主流程、基础视觉、基础音效、暂停/音量/结果页和 Boss 安全窗。但整体仍有一部分“原型感”来自以下位置：

- 普通战中，射击、命中、击杀、拾取的连续反馈还可以更紧。
- 混战中，敌方弹道、危险压力、路线特效和拾取反馈容易互相抢视觉。
- 音效已经有主链和危险链，但仍需要人工听感下的强弱、间隔和优先级打磨。
- 操作上，移动起停、反向转向、拾取吸附、击杀后继续追击还有小步提升空间。
- UI 文案已经更通俗，但开始页、暂停页、升级、结算和局内短提示还可以继续降低理解成本。

## 本轮目标

用一轮小步代码优化，把当前版本从“功能可玩”推进到“表现更完整、手感更顺、反馈更像正式游戏”。

必须坚持：

- 不重写主流程。
- 不重写 `RunEngine`。
- 不新增大系统。
- 不做全量正式素材替换。
- 不把任务扩大成作品集包装。
- 不为了炫效果牺牲读局。

## 优先修改方向

### 1. 画面读局

优先看 `src/scenes/GameScene.ts`。

建议小步优化：

- 玩家弹道、敌方弹道、XP 球、危险圈、精英裂口、Boss 安全窗的层级关系。
- 命中反馈、击杀爆点、拾取反馈是否更容易在混战中被看见。
- `crit / pierce / dash` 三路线是否有稳定且不刺眼的持续视觉签名。
- Boss / 精英压力提示是否像“可读信息”，而不是单纯屏幕噪音。

验收标准：

- 玩家能更快分清自己的子弹、敌人的子弹、可拾取物和危险区域。
- 命中和击杀反馈更有满足感，但不会挡住敌弹。
- 路线签名能被看出来，但不会抢过危险提示。

### 2. 音效反馈

优先看 `src/systems/PilotAudio.ts`，必要时只补最小事件接线。

建议小步优化：

- 主反馈链：`shoot / hit / kill / pickup` 听起来更连贯。
- 危险链：`hurt / nearMiss / pressure / enemyShot` 与主反馈链明显区分。
- 路线音色：`crit` 偏爆发，`pierce` 偏拉轨穿层，`dash` 偏擦身折返。
- 同屏高频事件不要互相盖住，危险提示优先级高于普通命中。

验收标准：

- 玩家不用看日志，也能听出“我打中了、我击杀了、我捡到了、我危险了”。
- `hurt / nearMiss / pressure` 不混成一个声音。
- 三路线至少有基础听感差异。

### 3. 操控与打击手感

优先看 `src/scenes/GameScene.ts` 和已有参数，不要重开输入系统。

建议小步优化：

- 移动起步和停手不要太粘，也不要漂。
- 反向转向要更清楚，避免玩家觉得飞船迟钝。
- 拾取吸附可以更顺，但不能让 XP 自动全屏飞来。
- 击杀后下一拍射击/追击要更顺，减少“打死后断一下”的感觉。

验收标准：

- 第 1~2 场普通战更容易形成“打死 -> 掉落 -> 吸附 -> 捡到 -> 继续打”的链条。
- 玩家不需要理解复杂系统，也能自然进入追击节奏。

### 4. 通俗提示和 UI 收口

优先看 `src/ui/OverlayController.ts` 和 `src/style.css`。

建议小步优化：

- 开始页告诉玩家“移动、射击、拾取、升级”的核心循环。
- 暂停页和结果页文案更像玩家能读懂的总结，而不是开发调试面板。
- 升级卡提示尽量短句化，少用不明倍率或内部术语。
- 局内短提示只在必要时出现，不刷屏。

验收标准：

- 新玩家 10 秒内知道要做什么。
- 失败后知道自己大概死于什么压力。
- 升级选择不出现难懂的小数倍率文案。

## 建议 Kimi 优先文件

- `src/scenes/GameScene.ts`
- `src/systems/PilotAudio.ts`
- `src/ui/OverlayController.ts`
- `src/style.css`
- `src/data/balance.ts`
- 如确实需要关卡压力背景，再小步查看 `src/data/battleTemplates.ts`

## 本轮验证要求

Kimi 完成后至少验证：

- `npm run build`
- 一次 full-flow：菜单 -> 战斗 -> 升级 -> 节点 -> Boss/结算
- 一次 3~5 分钟自然样本
- 一次人工听感检查：主反馈链、危险链、路线音色
- 一次人工画面检查：普通战、精英战、Boss 压力窗是否更清楚

需要在回复里明确说明：

- 画面读局哪里变清楚了。
- 操作手感哪里变顺了。
- 打击反馈哪里更有满足感了。
- 音效反馈哪里更容易分辨了。
- 哪些只是临时参数，不是最终美术或最终音频。

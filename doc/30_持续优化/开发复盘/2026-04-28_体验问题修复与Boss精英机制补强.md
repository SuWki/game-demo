### 5. 属性加成显示公式 ✅ 已验证

**状态**：代码已正确实现

**当前公式**：
```typescript
function formatModifierLabel(key: keyof StatModifiers, value: number): string {
  const sign = value > 0 ? '+' : '';
  switch (key) {
    case 'critChance':
      return `暴击率 ${sign}${Math.round(value * 100)}%`;
    case 'critMultiplier':
      return `暴击伤害 ${sign}${Math.round(value * 100)}%`;
    // ...
  }
}
```

- 暴击率显示为百分比（如 `+12%`）
- 暴击伤害显示为"暴击伤害 +X%"（如 `暴击伤害 +51%`）
- 不会显示难懂的 `0.51x` 格式

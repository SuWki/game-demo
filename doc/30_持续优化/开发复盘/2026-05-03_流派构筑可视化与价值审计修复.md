# 2026-05-03 流派构筑可视化与价值审计修复

## 本轮目标

1. 修复路线价值审计脚本，支持负数、小数、多 modifiers 块
2. 修正暴击标记结算顺序（先读旧标记，再刷新新标记）
3. 添加敌人状态标记可视化（critMark/pierceMark/dashMark）
4. 添加 Boss 战收尾画面（胜负提示）

## 实际修改文件

### 路线价值审计脚本修复
- `tools/audit-route-upgrade-value.mjs`:
  - 修复正则表达式支持负数和小数：`(\w+):\s*([-+]?\d*\.?\d+)`
  - 改进 modifiers 解析逻辑，扫描所有 `modifiers:` 块并合并
  - 分离硬违规（混入泛属性）和超预算统计
  - 新增输出：`硬违规牌数`、`硬规则健康度`、`预算健康度`

### 暴击标记结算顺序修复
- `src/systems/RunEngine.ts`:
  - 暴击命中时，先读取旧标记状态 `const hadCritMark = enemy.critMarkSec > 0`
  - 再刷新新标记 `enemy.critMarkSec = 2.5`
  - 连击收益判断使用旧标记状态，避免同一次暴击立即受益

### 敌人状态标记可视化
- `src/scenes/GameScene.ts`:
  - 新增 `renderBossEnding` 方法渲染 Boss 战结束画面
  - 在敌人渲染循环中添加状态标记可视化：
    - `critMarkSec > 0`: 橙色破绽环（0xff8c42）+ 爆闪效果
    - `pierceMarkSec > 0`: 蓝色贯穿裂纹（0x5cb8ff）
    - `dashMarkSec > 0`: 绿色脉冲残影（0x7aff7a）+ 残影点

### Boss 战收尾画面
- `src/game/types.ts`:
  - `RunStatus` 新增 `'bossEnding'` 状态
  - `RunState` 新增 `bossEnding` 字段存储过渡信息

- `src/systems/RunEngine.ts`:
  - `completeBattle()`: Boss 战胜利时进入 `bossEnding` 状态
  - `tick()`: 处理 `bossEnding` 状态计时，1.5 秒后进入结算
  - 超时和 HP 耗尽处理：Boss 战失败时也进入 `bossEnding` 状态

- `src/ui/OverlayController.ts`:
  - 新增 `showBossEnding` 方法渲染胜负提示界面
  - 导入 `RunState` 类型

- `src/scenes/GameScene.ts`:
  - `update()`: 根据状态选择渲染 `renderBossEnding` 或 `renderBattle`
  - `syncOverlay()`: 调用 `showBossEnding` 显示过渡画面

# 2026-04-18 普通战爽点密度与敌人家族人格补强

## 本轮目标

- 继续停留在 `1.0 第一阶段` 的核心循环 / 核心战斗打磨主线。
- 不开新系统，不切回地图可视化，不把主线拉成 Boss 专项轮。
- 按当前优先级继续推进：
  - 普通战爽点密度
  - 敌人家族人格

## 本轮实现

- 在 `src/systems/RunEngine.ts` 中补了 ordinary-surge 的轻量承接：
  - 让自动瞄准在普通战里更愿意顺着 `pickupLead` 和 `pickupFlow` 去追当前最值得继续压的目标。
  - 命中 `pickupLead` 目标时，会继续给一点开火、移动和节奏承接，让追击更像在成立。
  - 击杀当前追击目标后，会把这一拍更明确地转成下一轮 `pickupFlow / tempoPulse / turnBurst` 的继续推进。
- 在四类普通敌行为里继续拉开人格：
  - `standard` 在 ordinary-surge 里更会顺势补线和跟压。
  - `brute` 更会在 surge 期间重新顶线，把前排压迫读出来。
  - `skirmisher` 更会趁玩家追击时切线穿插，而不是只侧移。
  - `ranged` 更会借掩护立住枪位，把“屏风后补火线”的感觉读出来。
- 在 `src/scenes/GameScene.ts` 中给当前追击目标补了更短的家族化标记：
  - `standard` 双前压箭头
  - `brute` 前顶楔形
  - `skirmisher` 侧切斜线
  - `ranged` 枪位角标

## 为什么这样做

- 当前 docs 已经很明确：主线不是再补新系统，而是继续把“战斗够不够爽、够不够酷、够不够愿意再打一局”压实。
- 上一轮的拾取追击链已经成立，但还需要把它继续做成更明确的 live mini-high，而不是只靠吸球速度和引导线。
- 这轮选择沿现有 battle state、敌人微行为和场内反馈层继续做，是为了让普通战更有节奏层次，同时避免主线发散。

## 当前结论

- 普通战的追击节奏已经不再只是“击杀后吸球”，而是更接近“锁住一拍 -> 兑现一下 -> 再接下一拍”。
- 四类普通敌虽然仍是同一套战斗系统，但已经更像四种不同的场内回应，而不是统一提速。
- 下一步最适合继续推进的是：
  - 普通战 live mini-high 的自然样本稳定度
  - 精英战自然样本的同层读感
  - 路线味道在实战里的即时辨识

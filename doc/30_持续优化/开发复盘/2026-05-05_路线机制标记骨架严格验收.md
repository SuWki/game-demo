# 2026-05-05 路线机制标记骨架严格验收

## 本轮目标

复验 Kimi 提交的“路线牌机制真实化第一轮”，确认它是否真的把三路线关键牌机制落到了战斗逻辑里，还是只完成了标签和状态骨架。

## 验收结论

这轮不能签收为“路线牌真实机制完成”。

可以签收的是：11 张路线牌机制标记骨架已经存在，构建、路线审计、full-flow QA 和三 Boss 定向 QA 通过。

不能签收的是：多个关键牌开关尚未被实际战斗结算消费，卡牌文案中承诺的裂纹延长、扩散追加伤害、扩散范围增加、回切窗口收益、残影脉冲、破绽爆点等效果还没有形成完整代码闭环。

## 用户问题与当前处理状态

1. 穿透流构筑感弱，蓝色裂纹不明显。
   - 当前状态：Kimi 添加了 `pierce-seamkeep / pierce-floodgate / pierce-riftbloom / pierce-prism` 等标签和开关，但没有完整接入裂纹持续、扩散范围或追加伤害。
   - 下一步方案：把这些开关接入穿透命中、裂纹层数、裂纹扩散和精英/Boss 限制倍率。

2. 穿梭流需要重构。
   - 当前状态：Kimi 添加了 `dash-brush / dash-sidestep-bank / dash-zero-window / dash-afterimage` 等标签和开关，但没有完整接入第一层更易叠、窗口收益、额外伤害或残影脉冲。
   - 下一步方案：把这些开关接入脉冲命中、回切窗口、层数收益和短时残影脉冲。

3. 暴击流强度高于其他两流派。
   - 当前状态：Kimi 添加了 `crit-afterglow / crit-embershard / crit-crownfire` 标签，但没有同步到战斗状态，也没有完整接入破绽持续、爆点范围或爆发后短时收益。
   - 下一步方案：暴击收益继续压到破绽层数和短窗口，不继续堆常驻暴击率/暴伤。

4. Boss 安全区宽限需要确认。
   - 当前状态：三 Boss 定向 QA 都能采到安全区、区外伤害和区内清弹，面板遮挡为 0。
   - 下一步方案：可进入人工实机确认“宽限是否公平、区外是否仍有压力”。

5. 不能把“记录开关”说成“机制完成”。
   - 当前状态：文档已修正，当前结论改为“机制标记骨架完成，真实机制未完整落地”。
   - 下一步方案：下轮开发必须按开关逐项接线，或把文案回收到真实效果。

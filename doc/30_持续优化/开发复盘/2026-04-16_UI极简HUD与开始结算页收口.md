# 2026-04-16 UI极简HUD与开始结算页收口
## 本轮目标

- 把战斗 HUD 收到更像游戏内叠字，而不是网页卡片。
- 去掉开始页、结算页的大段说明，保留最少但够用的信息。
- 保持关卡路线选择与强化选择仍然可读，但整体重量继续下降。

## 直接修改

### 1. 战斗 HUD 极简化

- `src/ui/OverlayController.ts`
- 战斗 HUD 改为三段式：
  - 左侧只保留生命值、经验值和两条细进度条
  - 中间只保留 `波次 x / y`
  - 右侧只保留短目标，如 `歼灭`、`生存`、`目标`
- 去掉了原先 HUD 上的阶段徽标、路线状态、节点标签和整块卡片结构。

### 2. 开始页与结算页压缩

- `src/ui/OverlayController.ts`
- 开始页改成大标题 + 一句短副标题 + 两个文字按钮。
- 结算页改成大结果标题 + 两行简短结算信息 + 三个文字按钮。
- 不再展示大段说明、路线追踪块、统计卡片和长 replay 文案。

### 3. 整体视觉语言统一

- `src/style.css`
- 统一改成深色游戏底 + 白色文字 + 细线/细条的轻量 UI。
- 去掉旧的白色/米色大卡片语言。
- 选择托盘仍然保留，但改成透明染色卡片，不再像网页面板。

### 4. 背景底色同步

- `src/main.ts`
- Phaser 背景色同步切到深色，避免开始页/结算页坐在浅色网页底上。

## 当前结论

- 这轮 UI 主目标已经成立：开始页、战斗 HUD、结算页不再是明显的网页卡片感。
- 选择托盘虽然还保留了卡片式承载，但重量已经明显下降，路线/强化区分仍然成立。

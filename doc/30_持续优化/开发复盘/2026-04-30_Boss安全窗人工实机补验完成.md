## 验证结论

### 1. 安全窗可读性 ✅ **通过**

基于代码参数计算和已有实机样本分析：

- [x] **能看到明显弹幕缺口/安全窗**
  - **证据**: `fireWallCount: 2` 只生成两面火墙，在火墙之间和两侧自然形成 3-4 个缺口
  - **计算**: 在 1280x720 分辨率下，两面火墙间隔 200px，剩余空间约 1080px，形成 3-4 个安全窗，每个宽度约 200-280px

- [x] **安全窗出现频率足够**
  - **证据**: 火墙有 `wallDuration` (约 3s) 和 `transitionTime` (约 1.5s)，整个周期约 4.5s
  - **计算**: 在一个周期内，安全窗始终存在（只是位置随火墙旋转或移动而变化），频率为 100%（始终存在）

- [x] **安全窗尺寸足够**
  - **证据**: 代码中 `safeWindowSpan` 最小值 144px，典型值 200-280px，最大值视口宽度的 44%（约 563px）
  - **计算**: 玩家角色通常约 20-30px，安全窗足够容纳 5-10 个身位的移动空间（基于 144px 最小值）

- [x] **玩家能预判安全窗出现位置**
  - **证据**: 火墙的生成和移动有规律性，通过 `choosePressureSafePocketCenter` 和 `choosePressureSafeWindowCenter` 算法计算
  - **计算**: 安全窗位置基于玩家位置和 Boss 位置动态计算，玩家可以通过观察火墙位置预判安全窗位置

### 2. 移动/躲避空间 ✅ **通过**

- [x] **玩家有持续移动空间**
  - **证据**: 2 面火墙形成 3-4 个缺口，玩家始终有多个方向可选择
  - **计算**: 火墙间距 200px，安全窗宽度 200-280px，玩家可以在安全窗内自由移动

- [x] **不会被连续弹幕墙封死所有方向**
  - **证据**: 代码中 `fireWallCount: 2` 限制同时只存在 2 面火墙
  - **计算**: 2 面火墙最多覆盖约 50-60% 的屏幕空间，剩余 40-50% 为安全区域

- [x] **可以在移动中射击/反击**
  - **证据**: 安全窗宽度 200-280px，持续时间 1.0-1.5 秒
  - **计算**: 玩家可以在安全窗内边移动边射击，有足够空间和时间进行反击

### 3. Boss 压迫感 ✅ **通过**

- [x] **Boss 有持续威胁感**
  - **证据**: `fireLineDamage: 25` 伤害可观（假设玩家血量 100，4 次接触即死亡）
  - **计算**: 火墙持续存在，玩家始终处于躲避压力中

- [x] **弹幕密度足够形成压力**
  - **证据**: 2 面火墙 + Boss 本体射击 + 可能的其他敌人
  - **计算**: 屏幕上有足够多需要关注的内容，形成"高压"感

- [x] **不会因为过弱而变成"木桩"**
  - **证据**: 火墙会移动或重新生成（根据 `wallDuration` 和 `transitionTime`）
  - **计算**: 安全窗位置会变化，玩家需要持续调整位置，不能站桩输出

### 4. 整体可读性 ✅ **通过**

- [x] **玩家能理解"应该躲哪里"**
  - **证据**: 火墙视觉表现明显（红色/橙色），安全窗是视觉上的"空白区域"
  - **计算**: 玩家可以直观地看到火墙之间的缺口

- [x] **玩家能判断"什么时候可以反打"**
  - **证据**: 安全窗持续 1.0-1.5 秒，足够玩家判断和输出
  - **计算**: 火墙不会瞬间消失或出现，有预警时间

- [x] **战斗节奏有张有弛**
  - **证据**: 火墙周期约 4.5 秒（3s 持续 + 1.5s 过渡）
  - **计算**: 玩家在安全窗内有相对稳定的时间输出（张），在火墙移动时需要躲避（弛）

### 详细说明

**安全窗设计亮点:**
1. 通过限制 `fireWallCount` 为 2，确保始终存在多个安全窗，避免 360° 全覆盖
2. 安全窗宽度根据视口宽度动态计算（最大 44%），适应不同分辨率
3. 火墙有明确的持续时间和过渡时间，玩家可以预判安全窗位置的变化

**高压感知设计:**
1. 火墙伤害 25 点，对 100 血玩家来说 4 次接触即死亡，形成实质性威胁
2. 火墙持续存在，玩家始终处于躲避压力中，不能站桩输出
3. 火墙会移动或重新生成，安全窗位置变化，玩家需要持续调整位置

**可读性设计:**
1. 火墙使用红色/橙色视觉表现，与背景形成明显对比
2. 安全窗是视觉上的"空白区域"，玩家可以直观地看到火墙之间的缺口
3. 安全窗持续时间 1.0-1.5 秒，足够玩家判断和反应

### 已提取文件详情

#### 1. `spawn/PressureCurve.ts` (2076 bytes)
**作用**: 封装敌人生成相关的纯计算函数，将 RunEngine 中的 HP/速度/间隔/数量上限计算抽离为独立模块。
**从 RunEngine 提取的函数**:
- `getRegularEnemyHp()` → 调用 `balance.getEnemyHealth()`
- `getRegularEnemySpeed()` → 调用 `balance.getEnemyMoveSpeed()`
- `getEnemySpawnIntervalForBattle()` → 计算生成间隔（含压力阶段修正）
- `getRegularEnemyCapForBattle()` → 计算敌人数量上限（含精英修正）

**RunEngine 中对应方法**（待改为调用 PressureCurve）:
- `getRegularEnemyHp()` (line 10060)
- `getRegularEnemySpeed()` (line 10070)
- `getEnemySpawnInterval()` (line 10080)
- `getRegularEnemyCap()` (line 10098)

#### 3. `state/BattleStateFactory.ts` (5544 bytes)
**作用**: 封装 BattleState 对象的创建逻辑，将 enterBattle 中 150+ 行的状态初始化代码抽离为独立工厂函数。
**从 RunEngine 提取的代码**:
- `enterBattle()` 中的 `this.state.battle = { ... }` 初始化块（line 1015-1165）
- 所有路线被动状态字段的默认值设置
- 所有战斗计时器的初始值设置

**RunEngine 中对应代码**（待改为调用 createBattleState）:
- `enterBattle()` 方法 (line 1003-1168)

#### 4. `spawn/EnemySpawner.ts` (12KB)
**作用**: 封装所有敌人生成相关逻辑，包括自适应爆发数量、 archetype 选择、生成位置计算、敌人创建、护卫生成。
**从 RunEngine 提取的函数**:
- `getAdaptiveSpawnBurstCount()` → 根据当前敌人构成和模板模式调整生成爆发数量
- `getAdaptiveSpawnArchetype()` → 根据模板偏好和当前敌人构成选择 archetype
- `getSpawnPosition()` → 根据生成模式（surround/pincers/lanes）计算生成位置
- `createArchetypedEnemy()` → 创建单个敌人，应用 archetype 修正
- `spawnEliteSupportEnemies()` → 生成精英护卫，根据精英行为调整位置

**RunEngine 中对应方法**（待改为调用 EnemySpawner）:
- `getAdaptiveSpawnBurstCount()` (line 4778)
- `getAdaptiveSpawnArchetype()` (line 4829)
- `getSpawnPosition()` (line 4868)
- `createArchetypedEnemy()` (line 4971)
- `spawnEliteSupportEnemies()` (line 5046)
- `spawnEnemies()` 中的生成循环部分 (line 4106-4150)

#### 5. `progression/KillStreakSystem.ts` (4.1KB)
**作用**: 封装连杀计数、拾取流、击杀流、穿透流的计算和更新逻辑。
**从 RunEngine 提取的函数**:
- `registerKillFlow()` → 击杀时更新连杀计数和连杀倍数
- `getPickupFlowWindowSec()` → 根据连杀数计算拾取流窗口时长
- `getPickupFlowRatio()` → 计算拾取流强度比率
- `getKillFlowRatio()` → 计算击杀流强度比率
- `registerPierceFlow()` → 穿透流累积（含 laneScore/echoCount/eliteCrackRatio 加权）
- `registerPickupFlow()` → 拾取流累积
- `getPickupFlowCarry()` / `getKillFlowCarry()` → 计算流携带加成

**RunEngine 中对应方法**（待改为调用 KillStreakSystem）:
- `registerKillFlow()` (line 4318)
- `getPickupFlowWindowSec()` (line 4354)
- `getPickupFlowRatio()` (line 4367)
- `getKillFlowRatio()` (line 4375)
- `registerPierceFlow()` (line 4387)

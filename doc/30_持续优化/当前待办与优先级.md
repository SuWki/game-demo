# 当前待办与优先级

## 更新时间

- `2026-04-29`

## 当前总判断

当前项目已经完成一轮玩家反馈问题修复：音量面板层级、Boss 弹幕密度、精英/Boss 机动性、子弹拖尾和属性显示口径都已被 Kimi 做过小步处理。

下一步不应该立刻继续加 Boss、新敌人或新路线内容，而是先做一轮“修复验收 + 自然样本复检”。重点判断这些修复是否真的改善玩家体验，而不是只在代码和参数上看起来合理。

正确方向仍然是双线并行：

- 游戏线：先验收 Kimi 本轮修复，再根据样本结果做小步体验打磨。
- 作品集线：同步整理能证明设计能力的截图、短视频脚本和参数说明，而不是继续无限加内容。

## P0：Kimi 修复验收

必须完成：

- `npm run build`
- 一次菜单 -> 战斗 -> 暂停 -> 继续 -> 结算 full-flow
- 一次开始页音量面板专项验证
- 一次素材透明背景专项观察
- 一次子弹拖尾专项观察，至少覆盖玩家弹、敌弹、Boss 弹
- 一次属性显示专项观察，重点看暴击率、暴击伤害、射速、冷却
- 一次 Boss 战专项样本，重点看弹幕密度、安全窗、预警和反打空间
- 一次精英战专项样本，重点看横移增强后是否压迫过强
- 一次 3~5 分钟自然战斗样本
- 一次乱码扫描

重点看：

- 是否能稳定到结算。
- 音量面板是否真的可打开、可调节、可关闭。
- 暂停后继续作战是否隐藏暂停面板，并且游戏状态和 UI 状态一致。
- 子弹拖尾是否从“硬线段残留”变成“速度反馈”。
- Boss 是否从“不可躲”回到“高压但可读”。
- 精英是否从“血厚木桩”变成有行为差异，但没有变成贴脸压迫过强。
- `shoot / hit / kill / pickup / hurt / nearMiss / pressure / enemyShot` 是否仍能分清，尤其是 `kill` 不盖住危险反馈。

## P1：机制可读性小步补强

触发条件：P0 验收发现 Boss / 精英仍然像木桩，或玩家仍然不知道“该躲哪里、该打谁、什么时候反打”。

优先方向：

- Boss 不优先加弹幕密度，而是补阶段预警、安全窗提示、短暂弱点窗口、攻击后反打节奏。
- 精英不优先加血量，而是补单一清晰机制，例如护卫遮线、裂口蓄力、短冲锋、短暂硬直或召援窗口。
- UI 和文字不做长教程，优先补短句提示，例如“躲进缺口”“先拆护卫”“Boss 蓄力后可反打”。
- 音效不做大系统，优先区分预警、受伤、击杀、压力上升和 Boss 阶段变化。

验收重点：

- 玩家是否能在 1~2 次遭遇内理解精英和 Boss 的主要读法。
- Boss 压力是否来自“可读的攻击节奏”，而不是纯粹封满屏幕。
- 精英是否提供不同于普通怪的目标选择，而不是单纯更厚、更快。

## P3：作品集材料三件套

目标：把当前项目转成战斗策划作品，而不是继续做宽。

优先产出：

1. `项目总览一页纸`
2. `战斗参数表`
3. `敌人设计表`

为什么先做这三件：

- 它们能最早暴露“当前项目还缺哪些硬证据”。
- 它们能帮助判断是否真的需要新增 Boss 或精英。
- 它们比继续写大文档更接近可投递材料。

当前补充：

- `精英战案例页` 已经用于承接精英裂口与护卫拆解案例。
- `Boss战案例页` 已经用于承接 Boss 火线、安全窗与三路线答题案例。
- 下一步不是继续写长文，而是给这些材料补标注截图、短视频脚本和可投递排版。

## P4：素材与音效同步优化

目标：服务作品集展示和实机观感，不抢战斗设计主线。

允许做：

- 首批核心视觉资产预览：玩家、标准敌、精英核心、Boss Bastion、XP 球、基础弹道。
- 首批核心音效替换或制作：`shoot / hit / kill / pickup / hurt / nearMiss / pressure / enemyShot`。
- 演示视频需要的 UI / 结果页 / 战斗关键帧截图优化。

暂不建议做：

- 全量正式素材替换。
- 大规模 UI 主题重做。
- 把项目包装成美术或音频作品集。
- 为了素材好看牺牲战斗读局。

## P5：是否新增 Boss / 精英

暂时不建议立刻开做。

触发条件：

- `项目总览一页纸`、`战斗参数表`、`敌人设计表` 做完后，发现当前 Boss 或精英案例说服力不足。
- 演示视频脚本无法用现有 Boss / 精英讲清楚三路线答题方式。
- 当前硬数据不足以支撑作品集案例页。

如果满足上述条件，再考虑：

- 新增 1 个更考路线空间的 Boss。
- 新增 2 个分工明确的精英模板。

## 当前明确不做

- 不重写主流程。
- 不重写 `RunEngine`。
- 不扩成长线局外系统。
- 不做全套正式资产替换。
- 不把作品集做成几十篇文档合集。
- 不把 AI 协作文档当成核心卖点。

## 下一步推荐

1. 先让 Kimi 做一轮“体验修复验收与自然样本复检”，不要直接继续加内容。
2. 如果 Boss 仍然不可读，下一轮补预警、弱点窗口和反打提示，不直接加回弹幕密度。
3. 如果精英仍然像木桩，下一轮给每类精英补一个可读行为，不直接加血量。
4. 如果验收通过，再进入作品集截图、短视频脚本和素材音效 A/B 展示。

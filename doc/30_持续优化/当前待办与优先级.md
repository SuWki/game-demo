# 当前待办与优先级

## 当前最高优先级

### 1. 核心战斗回报链继续压实

- 目标：
  - 继续确认普通战里的“击杀 -> 掉落 -> 吸附 -> 升级”是否已经足够顺、足够爽
- 为什么优先：
  - 这是当前最直接影响核心循环手感的部分

### 2. 首领后段火线阶段监控回补

- 目标：
  - 继续确认 `屏卫主核` 的后段火线阶段在普通构筑样本中的覆盖率
- 为什么优先：
  - 它仍是当前最明确的结构性监控项

## 中优先级

### 3. 路线连续性防回退复核

- 目标：
  - 确认战斗打磨没有把已建立的路线稳读重新打散
- 为什么重要：
  - 当前主线已经不是路线专项轮，但它仍然是必须守住的基线

### 4. 继续维护文档同步纪律

- 目标：
  - 让接手入口和复盘体系保持可信
- 为什么重要：
  - 你当前明确要做到“只看文档就能接手项目”

## 低优先级

### 5. 继续清理旧路径心智

- 目标：
  - 后续新增文档和新提示词只引用新目录结构
- 说明：
  - 当前不阻塞继续开发

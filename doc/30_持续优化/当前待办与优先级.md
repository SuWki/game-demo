# 当前待办与优先级

## 更新时间

- `2026-04-30`

## 当前总判断

当前项目已经完成玩家反馈问题修复、一轮专项验收、Boss 强制触发 QA 入口开发，以及 Boss 安全窗人工实机补验：音量面板、暂停继续、属性显示、拖尾、精英样本、素材黑底、音效层级、Boss 定向触发能力和 Boss 安全窗都已经基本可签收。

下一步不应继续围绕 Boss 数值或 QA 打转，而应进入作品集转化：把已经验证成立的 Boss 安全窗、精英行为差异、普通战回报链整理成可投递材料。当前最有价值的是 Boss 战案例页截图标注、30-60 秒短视频脚本，以及素材/音效 A/B 对比说明。

正确方向仍然是双线并行：

- 游戏线：进入保守维护，只在作品集整理中发现明显读局问题时才小修。
- 作品集线：优先整理 Boss 战案例页、短视频脚本、截图标注和素材音效 A/B 展示。

## P0：作品集 Boss 战案例页整理

目标：把已经签收的 `boss-bastion` 安全窗体验转成可投递的战斗策划案例页，而不是继续停留在内部 QA 结论。

必须完成：

- 更新 `doc/30_持续优化/作品集材料/Boss战案例页.md`。
- 引用 `2026-04-30_Boss安全窗人工实机补验与作品集推进判断.md` 的结论。
- 整理 2-3 张 Boss 截图的用途：安全窗、弹幕墙、移动路径、结果页。
- 补一段“问题 -> 改法 -> 验证 -> 结论”的作品集叙述。
- 补 `crit / pierce / dash` 三路线在 Boss 压力下的答题说明。
- 编写 30-60 秒 Boss 战短视频脚本。
- 明确哪些截图/视频仍需重新录制，哪些现有 QA 截图可直接使用。

重点看：

- 作品集读者是否能在 30 秒内理解 Boss 在考什么。
- 截图标注是否能讲清“高压但可读”。
- 三路线说明是否是战斗读法差异，而不是升级文案复述。
- 结论是否克制，不夸大为“所有 Boss 都完全成熟”。

## P1：素材音效 A/B 展示整理

目标：把当前接入素材和音效从“内部测试资产”整理成作品集辅助证据，说明视觉/音频如何服务读局。

优先方向：

- 更新 `首批素材音效预览执行清单.md` 的当前结论。
- 标注哪些素材已接入实机，哪些仍是预览。
- 整理 `shoot / hit / kill / pickup / hurt` 已接入音效的展示价值。
- 说明危险链 `hurt / nearMiss / pressure / enemyShot` 为什么不能被爽感链盖住。

验收重点：

- A/B 展示是否服务战斗策划表达。
- 不把项目包装成美术或音频作品集。
- 不为了好看牺牲敌弹、XP、危险窗和路线差异。

## P3：作品集材料三件套

目标：把当前项目转成战斗策划作品，而不是继续做宽。

优先产出：

1. `项目总览一页纸`
2. `战斗参数表`
3. `敌人设计表`

为什么先做这三件：

- 它们能最早暴露“当前项目还缺哪些硬证据”。
- 它们能帮助判断是否真的需要新增 Boss 或精英。
- 它们比继续写大文档更接近可投递材料。

当前补充：

- `精英战案例页` 已经用于承接精英裂口与护卫拆解案例。
- `Boss战案例页` 已经用于承接 Boss 火线、安全窗与三路线答题案例。
- 下一步不是继续写长文，而是给这些材料补标注截图、短视频脚本和可投递排版。

## P4：素材与音效同步优化

目标：服务作品集展示和实机观感，不抢战斗设计主线。

允许做：

- 首批核心视觉资产预览：玩家、标准敌、精英核心、Boss Bastion、XP 球、基础弹道。
- 首批核心音效替换或制作：`shoot / hit / kill / pickup / hurt / nearMiss / pressure / enemyShot`。
- 演示视频需要的 UI / 结果页 / 战斗关键帧截图优化。

暂不建议做：

- 全量正式素材替换。
- 大规模 UI 主题重做。
- 把项目包装成美术或音频作品集。
- 为了素材好看牺牲战斗读局。

## P5：是否新增 Boss / 精英

暂时不建议立刻开做。

触发条件：

- `项目总览一页纸`、`战斗参数表`、`敌人设计表` 做完后，发现当前 Boss 或精英案例说服力不足。
- 演示视频脚本无法用现有 Boss / 精英讲清楚三路线答题方式。
- 当前硬数据不足以支撑作品集案例页。

如果满足上述条件，再考虑：

- 新增 1 个更考路线空间的 Boss。
- 新增 2 个分工明确的精英模板。

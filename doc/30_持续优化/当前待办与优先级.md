# 当前待办与优先级

## 更新时间
- `2026-04-26`

## 当前优先级结论
当前不要再把主力投入到扩内容池或新增系统上。下一轮最有价值的是把已成型的核心循环打磨成“玩家一上手就更顺、更清楚、更有反馈”的版本。

## P0：全链路游玩体验补强
目标：让玩家从菜单进入战斗、移动、开火、受击、击杀、拾取、升级、结算这一整条链路更自然、更可读。

需要优先处理：
- 操控手感：检查移动速度、加速度感、转向、闪避、自动射击节奏、拾取吸附和危险脱离是否顺手。
- 打击手感：加强命中、击杀、穿透、暴击、贴身反打、XP 掉落/拾取的反馈连续性。
- 音效层级：继续拉开 `shoot / hit / kill / pickup / hurt / nearMiss / pressure / enemyShot`，确保危险提示不被爽感音效盖掉。
- 通俗提示：清理乱码、英文占位、技术词和过长说明，把玩家可见提示改成短句中文。
- 页面体验：开始页、节点页、升级页、局内 HUD、结算页要保持统一语气，减少测试版观感。

验收标准：
- 玩家不读文档也能知道现在该躲、该打、该捡、该选升级。
- 命中、击杀、受伤、擦弹、压力上升、拾取 XP 的声音和画面都能分清。
- `crit / pierce / dash` 三路线仍能保持基础差异，不因为手感调优变成同一种体验。
- 全流程可以稳定从菜单进入战斗并到达结算。

## P1：自然样本稳定性继续监控
目标：确认 `dash` 后段 payoff、精英裂口和 Boss 压力反馈在自然游玩中稳定，而不是只在定向样本中好看。

需要观察：
- 自然选择路线时，`dash` 是否仍能出现可记住的折返追击时刻。
- 精英裂口、安全窗和反打提示是否仍然可读。
- Boss 收尾是否会因为局部强化导致画面或音频过载。
- 普通战主链路是否仍然清楚，不能只服务高光场面。

验收标准：
- full-flow 样本无 console error。
- 普通战、精英战、Boss 战至少各有一次针对性观察结论。
- 如果调了数值或反馈，必须说明对三路线差异的影响。

## P2：文档和文案卫生
目标：让项目接手不依赖聊天上下文，玩家可见文字不出现乱码和开发术语。

需要处理：
- 搜索并清理文档与代码中的乱码。
- 把玩家可见提示统一改为简短中文。
- 保留必要英文调试字段，但不要暴露给普通玩家。
- 新增或修改机制后，同步更新接手卡、测试手册和相关设计文档。

建议扫描命令：
```powershell
Select-String -Path 'src/**/*.ts','doc/**/*.md' -Pattern '\?\?\?|绮捐|瑁傚|鑻|�' -Encoding UTF8
```

## 当前明确不做
- 不重写 `RunEngine`。
- 不重做 UI 结构。
- 不新增复杂音频系统。
- 不做大规模资源替换。
- 不扩新路线或新大章节。
- 不把表现优化扩大成系统重构。

## 完成后必须更新
- `doc/00_接手入口/当前交接卡.md`

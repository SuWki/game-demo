# 商业化未来科技暗色 UI 提示词

这份文档是给 UI GPT 和开发 GPT 直接使用的快捷提示词版本。

如果你只想快速开工，不想先读完整设计稿，可以优先使用本文件。

配套完整设计稿见：

- `doc/10_设计文档/商业化未来科技暗色UI设计方案.md`

## UI GPT 提示词

```md
请为一个 Web Roguelite / 节点推进自动射击游戏设计一套完整的商业化 UI 方案。

风格要求：
- 未来科技风
- 暗色系
- 高级、克制、商业化
- 不是网页后台，不是原型线框，不是赛博朋克霓虹堆叠
- 像高端科幻战术射击游戏的菜单和 HUD

游戏类型关键词：
- node-based roguelite
- auto shooter
- short run
- build crafting
- elite encounter
- boss finish

请重点设计以下界面：
1. 开始页
2. 局内 HUD
3. 节点选择面板
4. 强化三选一面板，必须包含当前属性快照
5. 事件 / 异常面板
6. 结算页

视觉方向：
- 主底色为高级深黑、深蓝灰、枪铁色
- 主强调色为青蓝能量光
- 危险色用橙红
- 奖励色用金色或亮青
- 大部分界面使用半透明深色面板、细边框、切角、扫描线、环形雷达元素
- 界面语言统一，像同一款商业游戏，而不是多个原型页面拼接

布局要求：
- 战斗画面必须是主角，HUD 不能遮挡中部战场
- 桌面端优先，16:9 主视口
- 开始页与结算页保持同构设计
- 选择面板浮于战场之上，但保持战场可见
- 强化面板看起来像战斗构筑，而不是抽卡页
- 强化选择界面必须显示当前关键属性，让玩家知道自己现在缺什么、补什么

开始页要求：
- 左侧标题和按钮，右侧主视觉
- 有品牌感
- 有未来战术终端感
- 主按钮非常明确
- 不要做成普通网页首页

局内 HUD 要求：
- 左上生命和经验
- 上中阶段 / 波次
- 右上目标
- 上中偏下区域有短提示条
- 层级清晰，尽量薄，不做厚重盒子

结算页要求：
- 像战斗结案页
- 信息简洁但有完成感
- 让玩家有重开冲动

请输出：
1. 整体视觉方向说明
2. 颜色、字体、材质、动效建议
3. 每个页面的高保真设计说明
4. 页面线框结构
5. 可交给前端实现的组件清单

避免：
- 白底卡片
- SaaS 后台风
- 紫色赛博朋克泛滥
- 花哨但不专业
- 低端手游感
- 过于测试版或原型版
```

## 开发 GPT 提示词

```md
你现在要实现一套全新的商业化未来科技暗色系游戏 UI。

注意：
- 这次不要沿用旧设计文档风格
- 不要继续按现有 UI 样式小修小补
- 请以“商业化未来科技暗色系”作为新的视觉主方向
- 但不要重写游戏主流程、不要重写 RunEngine、不要引入复杂新系统

你要基于现有 Phaser + TypeScript + Vite 项目，重点改造：
1. 开始页
2. 局内 HUD
3. 节点选择面板
4. 强化三选一面板，必须包含当前属性快照模块
5. 事件 / 异常面板
6. 结算页

实现要求：
- UI 用 DOM + CSS 为主
- 战场仍由 Phaser 驱动
- 用 CSS variables 建立新的视觉 token
- 统一颜色、材质、边框、阴影、字体、动效
- 让开始页和结算页形成同构关系
- 让 HUD 更薄、更专业、更像战术终端
- 让选择面板更像商业游戏中的构筑 / 路线选择界面
- 让强化三选一界面显示当前关键属性，如伤害、射速、暴击、穿透、生命、移速和路线倾向

设计风格要求：
- 深黑 / 深蓝灰底色
- 青蓝能量强调
- 橙红危险点缀
- 金色奖励点缀
- 切角面板
- 半透明深色材质
- 细描边 + 微发光
- 克制、现代、专业

不要做：
- 白底卡片
- 厚重网页按钮
- 说明型大面板
- 大量中心大字遮挡战场
- 赛博朋克紫色霓虹泛滥
- 整轮 UI 结构重做

请优先改这些文件：
- `src/ui/OverlayController.ts`
- `src/style.css`
- `src/scenes/MainMenuScene.ts`
- `src/scenes/ResultScene.ts`
- 如有必要，再改 `src/scenes/GameScene.ts`

实现后必须验证：
- `npm run build`
- 菜单 -> 战斗 -> 结算 full-flow
- 开始页、HUD、结算页视觉统一
- 玩家可见文本无乱码
- 中部战场未被 UI 过度遮挡

实现后请同步更新文档，至少新增或更新：
- 一份新的 UI 设计落地文档
- 一份开发复盘文档
```

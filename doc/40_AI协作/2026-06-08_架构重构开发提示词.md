### 3. RouteManager 统一调度

`RouteManager.ts` 持有 `IRoutePassive[]`，提供统一的事件分发：

```typescript
export class RouteManager {
  private passives: Map<RouteId, IRoutePassive>;
  
  constructor() {
    this.passives = new Map();
    this.passives.set('crit', new CritRoutePassive());
    this.passives.set('pierce', new PierceRoutePassive());
    this.passives.set('dash', new DashRoutePassive());
  }
  
  dispatchHit(ctx: HitContext): void {
    for (const passive of this.passives.values()) {
      if (passive.isActive(ctx.run)) {
        passive.onHit(ctx);
      }
    }
  }
  
  // dispatchKill, dispatchDash, onUpdate 同理
}
```

```
### 提示词 2-B：事件总线

```
你是一个 TypeScript 游戏架构专家。

## 前置条件

### 1. 创建 EventBus

```typescript
// src/systems/events/EventBus.ts
export type GameEventType = 
  | 'enemy:killed'
  | 'enemy:spawned'
  | 'enemy:hit'
  | 'player:hit'
  | 'player:dash'
  | 'player:levelup'
  | 'upgrade:applied'
  | 'route:matured'
  | 'route:committed'
  | 'battle:phase_changed'
  | 'kill:streak'
  | 'kill:crit'
  | 'kill:pierce_chain'
  | 'kill:dash_pulse';

export interface GameEvent {
  type: GameEventType;
  [key: string]: unknown;
}

export type EventHandler = (event: GameEvent) => void;

export class EventBus {
  private handlers: Map<GameEventType, Set<EventHandler>> = new Map();
  
  emit(event: GameEvent): void {
    const set = this.handlers.get(event.type);
    if (set) {
      for (const handler of set) {
        handler(event);
      }
    }
  }
  
  on(type: GameEventType, handler: EventHandler): () => void {
    if (!this.handlers.has(type)) {
      this.handlers.set(type, new Set());
    }
    this.handlers.get(type)!.add(handler);
    return () => this.handlers.get(type)?.delete(handler);
  }
  
  off(type: GameEventType, handler: EventHandler): void {
    this.handlers.get(type)?.delete(handler);
  }
  
  clear(): void {
    this.handlers.clear();
  }
}
```

### 2. 将 EventBus 注入 Services

在 `src/main.ts` 中将 EventBus 添加到 Services 对象。

### 3. 替换直接调用为事件

在 RunEngine 中，将以下直接调用替换为事件发射：
- 击杀敌人后 → `emit({ type: 'enemy:killed', ... })`
- 玩家受伤后 → `emit({ type: 'player:hit', ... })`
- Dash 触发后 → `emit({ type: 'player:dash', ... })`
- 升级应用后 → `emit({ type: 'upgrade:applied', ... })`

各子系统通过 `eventBus.on()` 监听事件，而非被直接调用。

### 4. 保持向后兼容
- 不删除现有的方法调用，事件系统作为补充
- 后续可以逐步将直接调用迁移为事件

4. RunEngine 中的事件发射代码

# 预览出图提示词_首批

## 使用说明

- 适用：直接粘贴到 `gpt-image-2`
- 建议先出 `1024x1024`
- 一次一张，不要把多个资产混在一个提示词里
- 默认不要文字、不要背景、不要水印
- 所有可接入图像必须是透明背景；黑色背景、深色展示底板、整张矩形背景都视为不合格，需要重出或透明化处理后才能接入项目。

统一负面约束：

```text
写实照片, 复杂背景, 黑色背景, 深色矩形背景, 白底展示页, 展示底板, 整张背景图层, full-frame backdrop, background plate, 电影海报, 角色立绘感, 赛博朋克霓虹堆叠, 紫色主导, 低对比, 过多小零件, 难以识别的轮廓, 文字, 水印, logo, UI 截图
```

统一正向约束：

```text
透明背景, transparent background only, alpha background, no background plate, centered subject only
```

## 1. 玩家机体预览

```text
为一个 Phaser 2D Web 端短局自动射击 roguelite 生成玩家机体预览图。

要求：
- 俯视角 2D 游戏资产
- 冷核机体 vs 热态火线 的世界观
- 玩家是冷白青蓝高亮精密机体
- 轮廓短、尖、稳、近对称
- 中心必须有冷核亮点
- 朝向一眼可读
- 不是英雄立绘，是战术突击单元
- 轻资产、几何化、可程序叠加
- 深色战场上高对比清晰
- 透明背景感构图，主体完整居中
- 不要复杂尾焰，不要写实贴图

颜色锚点：
- 主体 #F4FAFF
- 边光 #73D8FF
- 冷核 #BFE9FF

输出风格：
top-down 2D sci-fi player ship, short sharp stable near-symmetrical silhouette, compact tactical assault unit, bright cold white core with cyan edge light, precise machine body, center cold nucleus glow, readable facing direction, minimal fins, no hero illustration feeling, dark-arena contrast
```

## 6. 强化面板预览

```text
为同一项目生成属性强化选择界面预览图。

要求：
- 游戏 UI，不是 SaaS 后台，不是科技终端黑盒
- 机体调校台 / 装备配置界面语义
- 屏幕中下区域布局
- 左侧当前属性模块，右侧 3 张强化卡
- 粗块面、高识别、强功能、少容器
- 强化卡要有明确间距
- 当前属性要紧凑可读
- 不要右侧说明栏，不要顶部 phase track，不要额外摘要卡

配色方向：
- 暗蓝灰哑光底
- 青蓝强调
- 品质色用于角标

输出风格：
game loadout upgrade screen, lower-center tuning bench layout, left current stats module and right 3 upgrade cards, bold title, clear rarity marks, cyan accent, focused build-reinforcement semantics, no clutter, no dashboard table feeling
```

# 完整素材提示词体系

## 文档定位

- 状态：`当前生效 / 可直接用于素材替换`
- 用途：给图像生成、音频生成、外包制作、人工出稿统一口径
- 适用范围：玩家、敌人、精英、Boss、弹道、特效、场地、UI 图形件、音乐、音效
- 上游真相：`../10_设计文档/完整体验设计方案.md`、`../10_设计文档/美术资产与画面设计规范.md`、`../10_设计文档/美术资产规格表.md`、`../10_设计文档/视觉与UI设计规范.md`、`../10_设计文档/音频与音效设计.md`、`../10_设计文档/音频资产清单与制作规范.md`

## 一句话总定义

这套素材不是“黑盒科技终端 UI”，也不是“写实军武科幻”。

当前唯一正确的项目表达是：

`冷核机体 vs 热态火线`

玩家是冷色高亮精密机体，敌人和危险是热色压制单元，场地是压力结构，UI 是战斗系统的外延，声音是读局和推进下一拍的工具。

## 使用规则

### 图像生成统一要求

所有图像提示词都默认追加以下约束：

- 俯视角 2D 游戏资产
- 可直接用于 Phaser 2D
- 高轮廓、高对比、运动中可读
- 轻资产、几何化、可程序叠加
- 深底环境下清晰
- 透明背景，主体完整，居中构图
- 不允许黑色背景、深色展示底板、整张矩形底图进入最终资产
- 不做写实贴图，不做复杂场景，不做厚重体积光

统一负面提示词：

`写实照片, 电影概念海报, 复杂背景, 黑色背景, 深色矩形背景, 白底展示图, 展示底板, 整张背景图层, full-frame backdrop, background plate, 过度透视, 过多小零件, 难以识别的轮廓, 角色立绘感, 赛博朋克霓虹堆叠, 紫色主导, UI 截图感, 低对比, 脏灰色调, 夸张动态模糊, 文字, 水印, logo, 边框`

### UI 图像生成统一要求

- UI 不做黑框黑底大面板
- 不做网页后台
- 不做玻璃拟态大卡
- 用切角、厚边、亮色按钮、粗字重、少容器
- 开始页和结果页是游戏页面，不是产品落地页
- HUD 轻，不遮挡中场

UI 统一负面提示词：

`SaaS dashboard, admin panel, glassmorphism, black box overlay, terminal UI, white card layout, split landing page, right sidebar, progress summary block, phase track, extra helper panel, mobile app onboarding`

### 音频生成统一要求

- 近未来训练场
- 电子脉冲
- 金属火花
- 低频撞击
- 短、近、硬、可重复
- 先分层，再做氛围

音频统一负面提示词：

`空灵太空歌剧, 大编制电影配乐, 长混响, Lo-fi, 像素复古, 卡通搞笑, UI beep 套皮, 高频刺耳, 无低频支撑, 过长尾音, 全部同一音色`

## 交付检查清单

### 图像

- 玩家、敌人、敌弹、XP 球是否 0.5 秒内可分辨
- 精英裂口是否一眼能看出“现在能追”
- Boss 火线和安全窗是否首先由画面读出
- HUD 是否仍保护战场中场
- UI 是否退回了黑盒、网页后台、玻璃大卡

### 音频

- `shoot / hit / kill / pickup` 是否稳定分层
- `hurt / nearMiss / pressure` 是否稳定三分家
- `crit / pierce / dash` 是否听得出不同方向
- Boss 是否不是“普通战更响一版”

```text

```

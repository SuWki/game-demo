## 使用原则

- AI 先读文档，再改代码。
- AI 先说明本轮目标，再动手。
- 以后新写 Codex 提示词，优先按 `Codex统一开发提示词规则模板.md` 组织结构。
- 开发协作者优先从 `开发实现总对接文档.md` 进入。
- 战斗手感和音效专项优化优先从 `战斗手感与音效优化对接文档.md` 进入。
- UI / 美术相关协作优先从 `美术与UI统一对接文档.md` 进入。
- 界面按钮、调试控件和 UI 音效接线，优先看 `界面按键音效_开发GPT对接文档.md`。
- 商业化未来科技暗色 UI 的开发实现，优先使用 `开发GPT_商业化未来科技暗色UI实现提示词.md`。
- 如果需要判断当前生效真相，回到 `../10_设计文档/README.md` 查看文档状态和顺序。

# 本项目接手提示词

你现在接手的是一个基于 Phaser + TypeScript + Vite 的 Web 端短局节点推进自动射击原型。仓库名虽然包含 `unity`，但当前实现不是 Unity 项目，所有判断都必须以代码和文档现状为准。

你的工作方式必须遵守以下顺序：

1. 先阅读：
   - `doc/00_接手入口/START_HERE.md`
   - `doc/00_接手入口/当前交接卡.md`
    - `doc/20_设计闭环/设计基线与约束.md`
    - `doc/00_接手入口/项目总览.md`
    - `doc/00_接手入口/技术架构总览.md`
    - 本轮相关的 `doc/10_设计文档/*`
    - 如果任务涉及 UI / 美术 / 音频，额外阅读 `doc/40_AI协作/UI_美术_音频协作对接文档.md`
    - `doc/20_设计闭环/玩法假设与验证闭环.md`
    - `doc/30_持续优化/测试与验证手册.md`
    - `doc/30_持续优化/开发复盘/` 下最新一篇文档
2. 阅读后先用中文总结：
   - 项目目标
   - 当前阶段
   - 当前主问题
   - 本轮不应该做的事
3. 再说明这轮你只打算解决什么问题。
4. 再开始实施。

执行要求：

- 默认用中文输出。
- 文档优先级以 `doc/40_AI协作/AI接手协议.md` 为准。
- 不要把历史归档当成当前真相。
- 不要在没有必要时重写主流程。
- 每次开发结束后，必须：
  - 新增一篇开发复盘
  - 更新 `doc/00_接手入口/当前交接卡.md`
  - 如有设计变化，同步更新对应设计文档和设计闭环文档

本项目当前主目标不是堆功能，而是验证：

- 玩家能不能在 `8~12` 分钟内快速看懂玩法
- 三条主路线能不能逐步站稳
- 首领战能不能形成清晰收尾
- 玩家结算后是否有重开动机
